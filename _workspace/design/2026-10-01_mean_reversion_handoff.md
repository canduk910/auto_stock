### 용어 풀이 (보고서에도 같은 말을 쓴다)

| 용어 | 쉬운 뜻 |
|---|---|
| 평균회귀 | 고무줄처럼, 평소 수준에서 멀어진 가격이 다시 돌아온다는 가정 |
| OU 과정 | 그 고무줄의 당기는 힘(θ)·중심(μ)·흔들림(σ)을 숫자로 적는 수학 모형 |
| 반감기 | 벌어진 간격이 절반으로 줄어드는 데 걸리는 날수(= ln2/θ) |
| ADF 검정 | 「이 시계열이 정말 고무줄에 묶여 있나, 그냥 떠도나」를 가리는 통계 검정 |
| 시장 잔차 | 종목 로그가격에서 시장(KODEX 200 등) 움직임 몫(β×시장)을 뺀 나머지 = 「시장 대비 얼마나 더 빠졌나」 |
| z | 지금 값이 평균에서 표준편차 몇 칸 떨어졌는지 |
| Leung 최적 경계 | 거래비용·할인율을 넣고 「언제 사고 언제 팔면 기대값이 최대인가」를 푼 진입·청산 가격(최적 정지 문제의 해) |
| walk-forward | 과거 창으로만 추정 → 다음 며칠에 적용 → 창을 밀어 다시 추정. 미래 정보를 안 쓰는 검증 방식 |
| 룩어헤드 | 그 시점엔 몰랐을 미래 데이터를 신호 계산에 섞는 실수 |

### 3.3 신호 계산 (walk-forward, 룩어헤드 금지)

각 종목·각 날짜 t 에 대해 **t 이하 데이터만** 쓴다.

1. 입력 `X_t = log(P_t) − β_t · log(B_t)`, `B` = 시장 구분에 맞는 기준 ETF, `β_t` = 직전 60봉 OLS(1봉 늦춘 창). 비교용으로 `X_t = log(P_t)`(가격 모드)도 같이 돌린다.
2. 재추정 주기 5영업일, 창 60봉. 창 안에서:
   - ADF(상수항, 시차 = AIC 자동, `statsmodels.tsa.stattools.adfuller`) → p 값
   - AR(1) OLS `X_{s+1} = a + b·X_s + e` → θ = −ln b, μ = a/(1−b), σ = std(e)·√(2θ/(1−b²)) (정확한 이산→연속 변환), 반감기 = ln2/θ
   - **편향 보정판도 함께**: Kendall 근사 `b_adj = b + (1+3b)/T` 로 반감기를 다시 계산해 둘 다 보고한다.
   - 무효 조건(신호 없음 + 사유 기록): ADF p ≥ 0.05 · b ≤ 0 · b ≥ 1 · σ ≤ 0 · 반감기 ∉ [1, 5] · 데이터 부족. `log1p`/`expm1` 로 b≈1 의 수치 불안정을 막는다.
3. z_t = (X_t − μ) / σ_stat, σ_stat = σ/√(2θ).
4. 체결 규약: **t 일 종가로 신호 → t+1 일 시가 체결**(우리 일봉 전략이 아침 매수 창에서 사는 것과 같은 모양). 청산 신호도 같은 규칙. 손절은 아래 3.4.
5. **대조군**: 같은 절차를 (a) 각 종목 일간 수익률을 무작위로 섞어 다시 쌓은 가격 (b) 같은 길이의 랜덤워크 합성 가격에 돌린다. 「진짜 회귀」 통과율 = 실제 통과율 − 대조군 통과율.
6. **다중검정 보고**: 5일마다 재검정하므로 종목당 「한 번이라도 통과」 비율과 「연속 통과」 비율을 따로 보고한다.

### 3.4 시뮬레이션 규칙 (롱 전용 · 운영 제약 반영)

- **진입**: 경계 아래(z ≤ 진입 경계, 또는 Leung 진입 구간 안) **그리고** 그날 시장 유닛 ≠ 0(D5, `market_unit.classify` 를 t 일 기준 069500 종가 열로 호출). 시장 유닛 데이터가 없으면 **진입하지 않음**과 **진입함** 두 가지로 돌려 차이를 보고한다(§7 결정 Q2 의 근거).
- **청산 3종(D6)** + 이익 청산:
  1. 이익 청산: z ≥ 청산 경계(또는 Leung 청산 경계)
  2. **재난 손절**: 진입가 대비 −X% 또는 z ≤ 진입 z − k (둘 중 먼저). X ∈ {5, 7, 10}, k ∈ {1.0, 1.5, 2.0} 격자로 민감도 측정. 손절은 일봉 저가가 손절가를 건드리면 그 가격(갭 하락이면 시가)에 체결로 본다
  3. **회귀 깨짐 청산**: 보유 중 재추정에서 ADF p ≥ 0.05 이거나 반감기가 범위를 벗어나거나 b ≥ 1 → 다음 날 시가 청산
  4. **타임스톱**: 영업일 보유일 > ceil(진입 시점 반감기 × 2) → 다음 날 시가 청산
- 같은 종목 보유 중 추가 매수 금지(물타기 금지). 청산 당일 같은 종목 재진입 금지.
- **자금 제약 시뮬레이션(D7)**: 전략 예산 = 순자산 × `cash_usage_ratio` × 0.05. 순자산 500만·`cash_usage_ratio` 0.95 → 약 23.75만 원. 슬롯 수 1·2·3 각각으로 돌리고, **1주도 못 사는 신호는 「자금 부족 미체결」로 세어** 보고한다(1주 폴백 없음). 사지 못한 비율이 결과의 핵심 지표다.
- 비용: 왕복 0.28% / 0.38% / 0.48% 세 단계. 트랙 C 가 실측값을 내면 그 값을 네 번째 단계로 추가한다.

### 3.5 Leung 최적 경계 구현 (D8)

- 기준 문헌: Leung & Li (2015), "Optimal Mean Reversion Trading with Transaction Costs and Stop-Loss Exit", *International Journal of Theoretical and Applied Finance* 18(3) — 책 『Optimal Mean Reversion Trading』 2장과 같은 모형.
- 구조(문헌 그대로 구현하고, 문헌의 식 번호를 코드 주석에 단다):
  - OU 생성자의 증가·감소 기본해 `F(x)`, `G(x)`(적분 표현 또는 포물선 원주 함수)
  - 청산 문제: `V(x) = sup E[e^{−rτ}(X_τ − c)]` → 청산 경계 b* 는 value matching + smooth pasting 조건 `F(b) = (b − c) F'(b)` 의 근
  - 진입 문제: `J(x) = sup E[e^{−rν}(V(X_ν) − X_ν − ĉ)]` → 진입 경계 d* (손절 L 을 넣는 판본은 진입 구간이 [a*, d*] 로 닫힐 수 있다)
  - 근 찾기 = `scipy.optimize.brentq`, 적분 = `scipy.integrate.quad`
- 우리 상황에 맞추는 점: X 는 로그가격(또는 잔차)이라 문헌의 선형 보상 `X − c` 는 **로그수익률 근사**다. 비용 c 는 로그 단위(≈ 비율 비용)로 넣는다. 이 근사를 보고서에 명시한다. 할인율 r 은 연 3.5%를 일 단위로 바꿔 쓰고 {0, 3.5%, 10%} 민감도를 본다.
- **검증 필수**:
  - (a) 문헌의 수치 예(논문 표·그림의 θ, μ, σ, r, c)로 b*, d* 를 재현해 오차를 보고한다
  - (b) 몬테카를로(OU 경로 1만 개 이상)로 「b*, d* 규칙」의 기대 할인 이익이 주변 격자 경계보다 크거나 같은지 확인한다
- 실패 처리: 근이 없거나 검증 (b) 를 통과하지 못한 추정 창은 **비용조정 z 경계로 대체하지 않고** 「Leung 신호 없음」으로 센다(대체하면 두 방법 비교가 섞인다). 실패율을 따로 보고한다.
- 🔴 **이름 정직성**: z 경계 코드에 Leung 이라는 이름을 붙이지 않는다. 문헌 재현 (a) 를 통과하지 못하면 결과 표에 「Leung(미검증)」으로 표시한다.

### 3.6 z 경계 vs Leung 판정 규칙 (D8 — 연구 착수 전에 고정)

- z 경계 후보: 진입 z ∈ {−1.5, −2.0, −2.5}, 청산 z ∈ {−0.5, −0.25, 0}, 그리고 비용 조건 `(|진입z| − |청산z|) × σ_stat > 왕복비용` 을 만족하는 조합만.
- **파라미터 고르기와 성과 재기는 기간을 나눈다** — 앞 60% 로 z 조합 1개를 고르고, 뒤 40% 에서 z(고른 것) 대 Leung(파라미터 고르기 없음)을 비교한다. 같은 기간에서 고르고 재면 z 쪽이 부풀려진다.
- **Leung 채택 조건(전부 만족)**:
  1. 뒤 40% 에서 비용 0.38% 기준 거래당 순기대값이 z 보다 높고, 그 차이의 블록 부트스트랩(종목·주 단위, 2,000회) 90% 구간 하한 > 0
  2. 솔버 실패율 < 10%
  3. 문헌 재현 (a) 통과
  4. 최대 낙폭이 z 대비 1.2배 이하
- 하나라도 못 넘으면 z 경계를 쓴다. 판정 표를 보고서에 그대로 싣는다.

### 3.7 기존 전략과의 상관

- 기존 7전략의 **평가 기준 일별 수익률**을 다시 만든다: `trade_history` 의 COMPLETED 매수·매도로 종목별 보유 구간을 만들고, 보유일마다 `stock_master_daily` 종가로 평가손익을 매긴다. 전략별 ÷ 그날 전략 예산(없으면 투입 원금).
- 평균회귀 시뮬레이션 일별 수익률과 20일·60일 rolling 상관, 전체 상관을 구한다.
- **장세를 두 축으로 나눈다** — 방향과 추세의 곧음은 다른 축이다.
  - **방향 축 = 시장 유닛** 1 / 0.75 / 0.5 / 0. 각 국면의 상관과 두 쪽 평균 수익. 「하락장에서 둘 다 잃는가」를 직접 보여 준다. **시장 유닛 1 의 평균회귀 성과를 따로 강조한다** — 상승장의 눌림 매수가 평균회귀가 가장 잘 통하는 전형이라, 효과가 있다면 여기서 드러난다.
  - **추세 곧음 축 = 효율비율(ER, Kaufman Efficiency Ratio)** — `069500` 일봉 종가로 `ER_t = |C_t − C_{t−20}| ÷ Σ_{i=t−19..t} |C_i − C_{i−1}|`(t 일 종가까지만 사용, 신호용이면 직전 영업일 봉 기준). 1 에 가까우면 한 방향으로 곧게 간 추세장, 0 에 가까우면 제자리에서 흔들린 횡보장. 전체 기간 ER 의 삼분위로 하위(횡보) · 중위 · 상위(추세)를 나눈다. 🔴 삼분위 경계는 **앞 60% 기간에서만** 정하고 뒤 40% 에 그대로 적용한다(경계 자체가 룩어헤드가 되지 않게).
  - 두 축을 교차한 표(시장 유닛 4 × ER 3)도 싣는다. 칸당 표본 수를 함께 적고, 10건 미만 칸은 「표본 부족」으로 표시한다.
  - ER 은 **연구 분류용**이다. 진입 규칙에 넣을지는 결과를 보고 따로 결정한다(§7 Q7).

## 6. 연구 통과 뒤 설계 메모 (이번에는 구현하지 않음)

- **선행**: 리팩터링 1단계 · ETF 추세 전략 shadow 착수 · 트랙 C 가동.
- **형태**: `src/engine/strategies/mean_reversion_ou.py`(`StrategyBase` 서브클래스) + 순수 leaf `src/engine/ou_estimator.py`(numpy 만. ADF 는 MacKinnon 근사 임계값 표를 직접 구현하거나, 연구에서 ADF 가 통과율 개선에 기여하지 않았으면 빼고 AR(1) 계수 조건만 쓴다. Leung 채택 시 적분·근 찾기는 numpy 로 다시 구현하고 연구 구현과 수치 대조 테스트로 묶는다).
- **신호 계산 시점**: 아침 부팅 뒤 `daily_bar_finalize` 가 끝난 다음의 `prepare`. 20:30·21:00 미리보기에서는 계산하지 않는다(잠정 종가).
- **매수**: 일봉 전략이므로 틱 매수 평가 제외(`risk.py:87`, 8영역 승인). 시장 유닛 0 = `check_buy_signal` 에서 `Signal.NONE`(신호 단계 차단, 수량 0 반환 금지 — 900초 「투자금 부족」 오귀인). `buy_paused` 게이트·종목상태 게이트 공통 적용. ETF 제외(`is_etf_like`).
- **수량**: `sizing_mode` 는 고정% 손절 계열(`position_ratio`)로 시작 — 재난 손절이 % 기반이면 터틀 유닛을 쓰지 않는다(함정 #1). 1주 폴백 금지 여부는 K_ρ 축과 함께 결정. `position_ratio × max_positions ≤ 1.0`.
- **청산**: 재난 손절 = `Signal.STOP_LOSS`. 회귀 깨짐·타임스톱은 전용 사유 마커(`[mr_exit] reason=regime_break|timeout`)를 남긴다 — 지금 `Signal` 에 시간 청산 값이 없어 손절로 섞인다.
- **DEFAULT_PARAMS 신규 키**는 전부 매매 행위 → 승인 + domain-consult 선행. 리스크 정체성 키(재난 손절·타임스톱 배수)는 `PARAM_RANGES`/`INT_PARAMS` 편입 금지 검토.
- **shadow** = 비중 0 이 아니라 `buy_paused=true` + 신호·가상 청산 기록으로 할지, 별도 shadow 모드 키로 할지 결정 필요(비중 0 은 `enabled=False` 자동 토글이라 shadow 로 쓸 수 없다 — 루트 CLAUDE.md 금기). ETF 전략의 shadow 방식과 맞춘다.
- **enforce 전환(D7)**: kojiro 0.40→0.35, 평균회귀 0→0.05, 한 번의 `PUT /api/strategies/weights`. 전제 = kojiro 보유 매수금액 ÷ 총자산 ≤ 0.35(아니면 거부됨, §2-12). 장외에 실행하고 사전·사후 API=DB 확인. kojiro 랏이 약 12.5% 줄어든다(입금 후 `q` 10.11 → 약 8.8, 여전히 5주 이상).
- **퇴출 규칙(사전 고정)**: 청산 25건 또는 도입 후 3개월 시점에 비용 뺀 평균 ≤ 0 → 비중 0(VB 시한부 규칙과 같은 모양). 퇴출 전에 보유 0 확인.
