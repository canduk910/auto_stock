## 2. 트레이더 시각 — 무엇이 망가져 있었나

### 2.1 시장 가설

대순환 랭킹의 목적은 한 문장이다 — **"오늘 6→1 로 태어난 추세들 중 어느 놈의 태동이 가장 힘찬가."**
원설계는 그것을 세 각도로 잰다.

| 성분 | 트레이더 어법 | 정량 |
|---|---|---|
| ① MACD3 기울기 | "띠가 벌어지는 **속도**" | 3봉 스팬 MACD3 변화를 **봉 수와 주가로 나눈 값** = 하루당 주가의 몇 % |
| ② 띠폭 확장률 | "띠가 최근 평소보다 **얼마나** 벌어졌나" | 현재 띠폭 ÷ 직전 5봉 평균 띠폭 − 1 |
| ③ 진입 신선도 | "태어난 지 며칠 됐나" | 짧을수록 좋다 |

셋 다 **무차원**이어야 종목 간 비교가 성립한다. 4,720원짜리와 405,500원짜리를
같은 자로 재려면 자에서 '원' 단위가 사라져 있어야 한다. 원설계는 성분①을 종가로,
성분②를 자기 자신의 과거 평균으로 나눠 그것을 달성한다.

**포팅본은 그 두 나눗셈을 모두 잃었다.** 그래서 성분①은 '원' 단위로 남았고
(= 비싼 주식이 이긴다), 성분②는 분모가 단일봉으로 바뀌어 하필 그 값이
**구조적으로 0 근처인 지점**(6→1 교차 = EMA20 이 EMA40 을 뚫는 순간, 정의상 띠폭≈0)에
놓였다(= 잡음이 만점을 가져간다).

### 2.2 실전 감각으로 다시 말하면

- **성분①의 고장**: "이 종목은 3일 만에 띠가 1,403원 벌어졌다" 와 "930원 벌어졌다" 를

  **"며칠 새 몇 % 벌어졌나"** 를 묻는다. 그게 `/close` 다.
- **성분②의 고장**: 6→1 직후 후보의 3봉 전 띠폭은 교차 직전이라 거의 0 이다.

  움직인 것이다. 호가 한두 틱짜리 잡음이다. 그 잡음이 min-max 에서 만점을 가져가고
  나머지 후보 전부를 0 근처로 눌러 버린다. **사용자가 벌하고 싶어했던 "좁은 정배열"을

## 3. 정량 권고 — 복원 식의 확정

### 3.1 성분① — `/close` 이다. `/ATR` 이 아니다. `/3` 은 포함한다

```python
macd3_slope = (float(m3.iloc[li] - m3.iloc[pi]) / _RANK_LOOKBACK) / close
#   close = float(enriched["close"].iloc[-1])   ← D-1 완성봉 종가(= prepare 의 prev_close 와 동일 값)
```

**(가) 분모는 종가다 — 원설계 `screener.py:118` `macd3_slope / last["close"]`.**
도메인 근거를 덧붙인다(원설계가 왜 옳은가):

- `macd3 = EMA20 − EMA40` 은 **가격의 차**다. 가격으로 나눠야 차원이 사라진다.
  ATR 로 나누면 "**추세 속도 ÷ 변동성**" 이라는 **다른 지표**가 된다(리스크조정 모멘텀).
  그건 원설계에 없는 발명이다.
- 게다가 ATR 정규화는 **이중 계산**이다 — 이 전략은 이미 진입 자격에서
  `atr_ratio = ATR/종가 ∈ [1%, 6%]`(`kojiro.py:151-152`)로 변동성을 걸러 놓았다.
  랭킹에서 다시 ATR 로 나누면 같은 축을 두 번 쓰는 셈이고, 저ATR 종목에 점수를
  몰아준다(분모가 작으므로) — **저변동 종목 편중**은 cycle242/245 가 사이징에서
  막으려던 바로 그 방향이다.
- ⇒ **`/close` 확정. `/ATR` 는 채택하지 않는다.**

**(나) `/3`(= `/ _RANK_LOOKBACK`) 은 포함한다.**

- 순위·점수 영향 = **정확히 0**. 양의 상수 `c` 로 나누면
  `(v/c − lo/c) / (hi/c − lo/c) = (v − lo)/(hi − lo)` — 정규화값이 문자 그대로 같다.
  U-C §3.1 의 증명·실측(최대 점수차 `0.0`)을 재확인했다.
- 원설계 `screener.py:113` 에 있다. **사용자 지시는 "원래 설계로 복원"이다.
  영향이 0 인 항을 빼는 쪽이 재해석이지, 넣는 쪽이 재해석이 아니다.**
- 실익 = shadow 로그의 `slope_pct` 가 **"하루당 주가의 몇 %"** 라는 읽을 수 있는 단위를
  갖는다. 나중에 임계 논의(카드 ①/②)를 하려면 그 단위가 있어야 한다.
  실측 분포(합성 코호트): p01 `+4.55e-4` · p50 `+2.30e-3` · p99 `+4.70e-3`
  = **하루 0.05% ~ 0.47%** 로 띠가 벌어지는 속도. 사람이 읽을 수 있는 수다.
- ⚠️ **판독 규칙(못 박을 것)** — 배포 후 순위가 바뀐 것을 **`/3` 탓으로 귀인하면 전부 오독**이다.
  순위 변화는 100% `/close` 와 `exp5` 몫이다.
- 클램프 주의: `pi = max(0, li − _RANK_LOOKBACK)` 이 걸리는 경우(`len(m3) < 4`)에는
  실제 스팬이 3이 아니라 `/3` 불변성이 깨진다. 프로덕션은 `KOJIRO_MIN_REQUIRED = 80` 이라
  **도달 불가**이고, 도달하는 테스트 스텁에서는 값이 **과소평가**(스팬 < 3 인데 3으로 나눔)
  → 순위가 **내려간다** = 워밍업 부족 종목이 후순위로 밀리는 **보수적 방향**이다. 수용한다.

### 3.2 성분② — 분모는 직전 5봉 평균. **하한을 발명하지 않는다**

```python
band_prev = float(bw.iloc[-6:-1].mean())              # 원설계 표현 그대로
band_expansion = (float(bw.iloc[-1]) / band_prev - 1.0) if band_prev > 0 else 0.0
```

질문은 "`1e-9` 대신 어떤 하한 — ATR 비율? 밴드폭 중앙값?" 이었다. **답 = 어느 것도 아니다.
5봉 평균 그 자체가 하한 기구다.** 이유:

- `band_width = |EMA20 − EMA40|` 은 항상 ≥ 0 이고, **단일 봉**은 교차 순간에 구조적으로 0 근처다.
  그러나 **5봉 평균**이 0 근처가 되려면 다섯 봉 **전부**가 0 근처여야 한다 —
  그건 "띠가 일주일째 죽어 있다" = **진짜로 추세가 없다** = 낮은 점수를 받는 것이 **옳다**.
- 즉 원설계의 5봉 평균은 잡음 억제 장치이면서 동시에 **의미 있는 하한**이다.
  별도 엡실론이 필요 없는 이유가 이것이고, 그래서 원설계에는 `> 0` 이라는
  **정직한 이분법**(계산 가능하면 계산, 아니면 중립 0.0)만 있다.

**실측으로 확인한 하한 효과**(합성 코호트 N=1,031, 게이트 통과 후보만):

| | 현행 분모 `bw[-4]` | **복원 분모 `mean(bw[-6:-1])`** |
|---|---|---|
| 분모/ATR **p01** | **0.00215** | **0.03632** (≈ **17배** 두꺼워진다) |
| 분모/ATR p10 | 0.0271 | 0.0789 |
| 분모/ATR p50 | 0.118 | 0.167 |

**그 결과 확장률의 꼬리가 사라진다:**

| 확장률 | min | p50 | p90 | p99 | **MAX** | `>10` 인 후보 |
|---|---|---|---|---|---|---|
| `exp1`(현행) | −1.00 | +1.37 | **+10.33** | **+136.8** | **+2,252** | **109 / 1,031 (10.6%)** |
| **`exp5`(복원)** | −1.00 | +0.86 | +2.04 | **+2.95** | **+4.53** | **0 / 1,031 (0.0%)** |

> **읽는 법**: 현행은 후보 **10 개 중 1 개**가 "확장률 1,000% 이상" 을 받는다.
> 그 한 종목이 min-max 만점을 가져가고 나머지를 전부 0 근처로 압축한다.
> 복원 후에는 그런 후보가 **0 건**이다. 이게 `1e-9` 를 없앤 것의 실체다.

**압축 손실의 정량**(13종목 풀 400회 추출, 성분② 정규화값):

| | 현행 | 복원 |
|---|---|---|
| 2위 종목의 정규화값(평균) | 0.482 | **0.875** |
| 정규화값 ≥ 0.10 인 종목 수 | **5.7 / 13** | **10.4 / 13** |
| 풀 내 Spearman(`exp1`, `exp5`) | — | **+0.853** |

핵심 뉘앙스 — **성분②의 피해는 "순서 뒤바뀜"이 아니라 "해상도 손실"이다.**
두 식의 순서 자체는 ρ=+0.85 로 꽤 일치한다. 문제는 현행이 13개 중 7개를
**변별 불가능한 0 근처로 눌러 버린다**는 것이다. 복원은 순서를 뒤집기보다 **눈금을 되살린다**.

### 3.3 성분③ 신선도 — **비복원 권고**(현행 유지)

- 원설계 `norm(−fresh_days)` ↔ 현행 `norm(within − dist61)`.
  6→1 전환 후 스테이지가 계속 1이면 `fresh_days = dist61 + 1` 이므로
  `within − dist61 = (within − 1) + (−fresh_days)` — **기울기 +1 의 양의 아핀 변환**.
  min-max 는 아핀 불변 ⇒ **정규화값·점수·순위 전부 동일**하다.
- 유일한 발산: 창 안에서 `6→1→2→1` 처럼 되돌아온 코호트. 원설계는 마지막 1-런만 세어
  "가장 신선"으로 보고, 현행은 6→1 전환까지 거슬러 "덜 신선"으로 본다.
  **트레이더 판단: 현행이 옳다.** 정배열이 한 번 무너졌다 돌아온 종목은 "출생 3일차"가
  아니라 "한 번 실패한 출생"이다. 원설계 쪽이 오히려 그것을 새것으로 착각한다.
- ⇒ **복원 이득 0, 회귀 위험만 있다. 손대지 않는다.** (U-C §2.4 와 동일 결론, 근거 하나 추가)

### 3.4 가중치 0.4 / 0.3 / 0.3 — **무접촉 확인**

합성 코호트에서 전환 후 경과봉 `d`(0 = 당일 전환)와 각 성분의 관계:

**읽는 법** — `bw[-6:-1]` 창은 d=0 후보에서는 **교차 이전**(EMA20 이 EMA40 **아래**였던 구간)을
덮는다. `band_width` 는 절댓값이라 그 시절의 **하락 추세 이격**이 분모에 들어가고,

즉 **성분②는 오래된 전환(d=2~4)에 상 주고, 성분③은 신선한 전환(d=0)에 상 준다.**
가중치가 0.3/0.3 으로 같으니 둘은 서로를 거의 지운다 —
**남는 실질 결정권은 성분①(0.4) 이다.**

> 이것은 **원설계에도 있던 성질**이고 복원이 만든 것이 아니다(현행 +0.706 → 복원 +0.813 로

> **성분①이 망가져 있었다는 사실이 곧 랭킹 전체가 망가져 있었다는 뜻이다.**

## 5. shadow 관측 `[kojiro_band_observe]` 설계

U-C §6 을 정본으로 채택하고, 도메인 관점에서 **필드 근거·판독 규칙·행위 무영향 증명**을 확정한다.

### 5.1 왜 이 관측이 필요한가 (셋)

1. **복원 전후 대조** — `exp1`·`exp5`, `slope_raw`·`slope_pct` 를 **한 행에 함께** 남겨야
   "복원이 실제로 무엇을 바꿨나"를 사후에 오프라인으로 재계산할 수 있다.
2. **F-3 stale 일봉 탐지** — `bar` 필드. K1 §2.2 각주가 `004690`(삼천리) 일봉 헤드
   4거래일 stale 을 잡았고, **삼천리는 보유 종목이며 그 ATR 이 2ATR 손절선의 입력**이다.
   `role=held` 행을 남기는 첫째 이유가 이것이다 — **손절 입력의 신선도를 매일 잰다.**
3. **밴드폭 관문(카드 ①/②) 논의의 원자료 적립** — `bw_close_pct`·`bw_atr` 를
   **동시에** 쌓는다. 한 척도만 쌓으면 나중에 척도를 바꿀 수 없다.

### 5.2 한 행

```
[kojiro_band_observe] ticker= name= role= rank= bar= close= atr= atr_pct=
                      bw= bw_close_pct= bw_atr= bw_prev1= bw_prev5=
```

- 전 필드 **D-1 완성봉 기준**(`enriched.iloc[-1]`) — `prepare` 의 `prev_idx` 규약과 동일

## 8. 반례 / 한계 (자문 규약 — 가설이 깨지는 시나리오)

1. **"복원이 더 번다"는 이 사이클이 주장할 수 없다.**
   종결 표본 N=17, 검정력 없음. 근거는 **설계 정합(원설계 문언) + 기전(무차원화·분모 하한)**
   이지 손익이 아니다. §4.5 는 "반론의 부재"일 뿐 "효과의 증명"이 아니다.
2. **주가 편향이 유동성 프록시였을 가능성** — 고가 대형주가 실제로 추세가 깨끗할 수 있다.
   §4.5 실측이 이를 지지하지 않았지만(고가군 평균 −643 vs 저가군 −634), N=17 에서
   그 차이를 낼 검정력이 애초에 없다. **shadow 로그 3개월 누적 후 `close` × 실현손익
   재검정을 후속으로 예약한다.**
3. **성분②↔③ 상쇄가 복원 후 조금 더 강해진다**(Spearman(d, exp) +0.706 → +0.813, §4.6).
   원설계에도 있던 성질이지만, 결과적으로 랭킹의 실질 결정권이 성분① 하나에 더 쏠린다.
   **이번 범위 밖**(가중치 = 사용자 결정 항목). shadow 의 `dist61`·`exp5` 가 실데이터로
   이 상관을 재확인시켜 줄 것이고, 그때 별도 카드로 올린다.
4. **`exp5` 도 이론상 폭발할 수 있다** — 다섯 봉 전부 띠가 죽어 있다가 급확장하는
   "코일 스프링" 케이스. 합성 1,031건에서 `>10` 은 **0건**이었으나 0 이 불가능을
   뜻하지는 않는다. **윈저라이즈·클램프는 원설계에 없으므로 넣지 않는다** —
   대신 S4 서명이 그것을 매일 감시한다. 실제로 관측되면 그때 데이터로 논의한다.
5. **합성 코호트의 한계** — `enrich` 는 진짜지만 가격 시계열은 GBM 합성이다.
   실제 한국 시장의 갭·상하한가·거래정지·테마 동조가 없다. 밴드/ATR 중앙값이
   실측 0.128 대비 0.227 로 **약간 넓어** 폭발 통계가 보수적(과소)이다.
   §4.3 의 순위 변화 폭(1위 유지 23%)도 실데이터로 반드시 확인해야 한다(§4.4 ⚠️).
6. **stale 일봉이 전후 비교를 오염시킨다** — F-3 삼천리(4거래일 stale) 같은 종목이
   섞이면 §5.1 표의 순위 변화가 복원 때문인지 오염 때문인지 구별되지 않는다.
   **배포 전 재계산 시 `bar` 열을 먼저 확인**하는 것이 판독 규칙 3의 이유다.
7. **`role=held` 행의 결측은 정보다** — held 스탬프는 ATR 밴드·스테이지 판별을 통과한
   뒤에 찍히므로, 밴드 밖으로 나간 보유 종목은 행이 없다. **"보유인데 행이 없다"가
   곧 "그 종목이 오늘 지표 파이프라인 밖에 있었다"** 는 신호다. 결측을 0 으로 읽지 말 것.
