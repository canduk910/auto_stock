## 핵심 재프레이밍 — "RR 은 멀쩡하다, 승률이 레짐에 눌렸다"

가장 중요한 한 줄. **kojiro 의 손익비(RR)는 깨지지 않았다. 깨진 것은 승률이고, 그 승률은 레짐이 눌렀다.**

- 사용자 프레임: "승률 11% 에서는 필요 RR 8.0, 실제 3.2 → 한참 부족." → 맞다. 하지만 이건 **관측 승률을 상수로 고정한** 프레임이다.
- 반대 프레임(내 권고): **RR 3.2 를 상수로 두면 손익분기 승률 = 1/(1+RR) = 23.8%.** 오염 보정 후 RR 3.6~3.8 이면 손익분기 승률 **≈ 21%**. 관측 11% 는 그 절반. **이 10%p 갭이 곧 "레짐 세금"이다.**
- 정상 추세추종 환경(승률 33~40%)에서 RR 3.7 이면 기대값 = 0.35×3.7 − 0.65×1 = **+0.65 유닛/트레이드** → 강한 양(+)의 기대값. **즉 이 전략은 정상 승률에서 이미 흑자 구조다.** 지금 적자로 보이는 유일한 이유는 승률이 레짐(defensive)에 절반으로 눌렸기 때문.

이 재프레이밍이 아래 모든 권고의 뿌리다. **RR 을 건드리는 처방(샹들리에 조임 등)은 전략의 엣지를 갉아먹으므로 금기.** 처방은 승률(레짐 대응) + 이익반납(브레이크이븐 플로어)에 집중한다.

### 왜 승률이 11% 인가 — 레짐 × 진입의 상호작용

- 스테이지1(EMA 5>20>40 신선 정렬)은 **약세/횡보장에서 페이크 돌파의 온상**. 방어장에서 강세 스택은 dead-cat 반등 위에 잠깐 서다 되말린다 = 추세추종 휩소의 교과서.
- **바이모달 결과(대박 1 + 소액 다패)는 추세추종의 지문 그 자체.** 슈프리마(+19.9%, 21일 보유)가 유일하게 진짜 추세를 잡았고 나머지는 2~8일 내 실패. 정상장이면 N=9 에 2~3 승을 기대하나 방어장은 1승으로 눌렀다 — 분산의 불운/레짐억압 쪽 끝.
- **슈프리마 +19.9% 는 H-1(고점영속) 시정의 수혜.** 08-06 시정 전이었으면 매일 아침 고점 리셋 → 샹들리에가 매수가로 초기화 → 조기 청산 → 유일한 승이 소액승/패로 붕괴. **즉 청산 인프라 품질이 fat-tail 포착 여부를 직접 게이팅한다** — 이익반납 처방(브레이크이븐)을 진입/비중보다 우선해야 하는 강력한 근거.

### 위험 시나리오 (현 상태 유지 시)

- Σ오픈리스크 캡(4.5% × 예산 70만 ≈ 31,500원)이 **스냅샷 시점의 동시 오픈 리스크는 묶지만, 순차 왕복 실현손실의 누적은 안 묶는다.** 방어장이 몇 달 지속되면 왕복마다 ~1유닛씩 새는 출혈이 캡을 우회해 누적. 이게 weight 유지의 진짜 리스크이고, 단발 3청산(recency)이 아니라 **레짐 지속 확인** 시 대응할 사안.

## 정량 권고

### Q1 판정 — (i) 레짐억압 정상분산 + (iii) 이익반납 갭, (ii) 아님

지배 순위:
1. **레짐 역풍(방어장이 돌파 후속을 죽임)** — 승률(11%)의 지배 요인.
2. **청산 이익반납 갭(이익보호 장치 전무)** — 반납의 심각도(#7/8/9)를 좌우하는 **가장 가시적·가장 고칠 수 있는** 레버.
3. **오염(3건 -8% 증폭)** — avg_loss 크기를 부풀렸으나 08-04 이미 forward-fix 완료.
4. **진입 품질** — **결함 아님.** funnel 작동(0→3~9), 슈프리마가 신호 유효성 입증, N=9 로 진입을 탓할 근거 없음.

**결론: "kojiro 는 깨졌다"가 아니다.** RR 엣지는 온전, 표본은 레짐억압 + 오염증폭. 오염 보정 시 -2.98%→-2.2~-2.5%, RR 3.6~3.8, 손익분기 승률 ~21% 로 "재앙"이 "레짐세금 + 고칠 수 있는 이익반납"으로 완화.

### Q2 재튜닝 테이블 우선순위 (N=10 도달 시)

**1순위 — (b) 청산: 브레이크이븐 플로어 이식 (donchian P1 선례).** 최고 EV.
- #7/8/9 반납(-7,720)을 breakeven 근처로 전환 → 현실 회복 +5,000~6,000. 검증된 패턴(donchian 라이브)이라 회귀 위험 낮음.
- **구현 필수 규약: 플로어이지 트레일이 아니다.** `실효손절 = max(브레이크이븐 플로어, 샹들리에 트레일, 백스톱)`. 가격이 계속 오르면 샹들리에가 위에서 끌고, **완전 왕복했을 때만** breakeven 으로 떨어진다. "승격 후 breakeven 이 곧 하드청산"으로 구현하면 fat-tail 을 절단하는 오구현(아래 반례).
- **샹들리에 2.5 는 유지(조이지 마라).** 조이면 RR 하락 = 엣지 훼손, 슈프리마를 조기 절단했을 것. 반납보호는 플로어가, 추세연장은 넓은 샹들리에가 각자 담당.
- 부분익절(+1.5N/+2N)은 **2순위 옵션** — fat-tail payoff 를 깎고 P&L 표본을 더 흐린다. 플로어 먼저 측정 후 재검토.

**2순위 — (c) 비중 0.60.** 방향은 레짐 × 표본해상도에 종속. **exit 패키지와 묶어 재결정**, 선행 단독 조정 금지. 굳이 지금 움직여야 하면 0.4(0.2 아님).

**3순위/보류 — (a) 진입(밴드/신선도/랭킹).** FREEZE 보호, funnel 검증 미완, 지금 건드리면 축적 중 표본 파괴. **단 하나 테이블에 올릴 진입 인접 항목 = 레짐 인지 진입 억제**(dkstock defensive 시 스테이지1 신규진입 보류) — 파라미터가 아니라 게이트이며 지배 손실요인(레짐)을 직격. 다만 사이클 I 가 레짐을 관찰전용화했으므로 **단일 전략용 레짐 게이트 재도입은 정책 변경 → 사용자 사인오프 필요**. 토론 항목으로 상정.

**FREEZE 해제 범위: 청산 구조(브레이크이븐 플로어)만.** 진입 파라미터 동결 유지. 비중은 진입동결과 별개 레버.

### Q3 AI weight 0.2 — **지금 채택 반대, N=10 재튜닝에서 exit 패키지와 함께 재결정. 강제 시 0.4.**

반대 근거:
1. **AI 입력이 오염데이터.** 평균손실 -7.87% 는 2ATR 결함기 3건이 부풀린 값. 보정 후 avg_loss ~-6%, 누적 -2.2%. 전제가 부분적으로 stale.

3. **표본 해상도 훼손.** 0.60 집중(08-04 결정)은 1주 양자화 노이즈 위로 해상도를 올리려던 것. 0.2(예산 ~23만, 종목당 ~38K)면 다수 종목이 1주/0주 → **표본이 더 시끄러워짐** = 축적 목표 역행.

### Q4 스테이지3 0발화 — **설계 의도대로. 결함 아님(계산 정상 확인됨).**

- 대순환 스테이지가 3(하락 초입)으로 롤오버하는 건 **MA 스택 확정 = 매우 늦은 신호.** 그 전에 샹들리에/2ATR/백스톱이 선행 발화하는 게 정상이고 건강하다. 스테이지3 이 자주 걸리면 오히려 다른 손절이 너무 헐겁다는 뜻.
- 스테이지3 = "다른 모든 게 실패한 저변동 완만 하락(grind-down)"의 catch-all longstop. 관측 표본엔 그런 케이스가 없었을 뿐(전부 샤프 하락 또는 트레일 왕복).
- **결함 아님의 증거: 08-18 recompute 가 stage 2/1/1 을 정상 산출** = 스테이지 계산 코드가 실제로 돈다(silent no-op 아님). 0발화는 진짜로 stage 3 미도달 탓 → 설계대로 확정.
- 후속 점검(경량): stage 분포를 주기 로깅해 **stage 3 이 도달 가능한 임계인지** 장기 확인(수개월 내 어떤 포지션/후보도 stage 3 미도달이면 임계 unreachable 의심). 지금은 결함 근거 없음.

## 현 코드와의 정합성

- **충돌 없음(권고 1순위).** 브레이크이븐 플로어는 donchian P1(08-09) 라이브 선례 존재 = 축적 중 exit 개선이 리스크 저감·검증된 패턴이면 허용됨(H-1·_effective_atr 도 축적 중 exit 시정). `max(플로어, 샹들리에, 백스톱)` 은 `_position_stop_price`/샹들리에 산식(사이클 H-1 F2)과 정합.
- **FREEZE 와의 긴장(명시):** 브레이크이븐 이식은 exit **구조 변경**이라 P&L 표본의 정상성을 흔든다. 그러나 FREEZE 의 보호 대상은 **진입신호(funnel) 표본**이지 exit 이 아니다. P&L 흑자 여부는 명시적으로 "미확정, 축적 중". **해소: N=10 트리거에서 의도적 패키지로 이식 + "pre-fix 9왕복과 post-fix 왕복은 다른 exit 레짐"임을 문서화하고 이후 분리 분석.** 반응적 즉시 패치(now)는 지양 — deliberate·triggered·packaged 가 FREEZE 존중.
- **비중 0.60 유지 시 충돌 없음** — Σ리스크 캡이 하방 통제. `position_ratio 0.166 × max_positions 6 = 0.996 ≤ 1.0` 불변식 유지.

## 반례 / 한계 (각 권고가 깨지는 시나리오)

1. **브레이크이븐 플로어 이식이 깨지는 경우:** 진짜 fat-tail 강세장에서 +1.5N 도달 후 정상 눌림에 breakeven 터치 → 절단 → 이후 +50% 랠리를 놓침. **플로어의 엣지 절단.** 완화 = 반드시 `max(플로어, 샹들리에)` 레이어드 + 스택 재정렬 시 재진입 허용. 또 **익일아침 청산 갭**(08-18 실측 -160~-428원 하회) 때문에 breakeven 도 갭다운 클러스터에선 하회 체결 → +5,000~6,000 회복은 **상한**이지 보장 아님. 현 방어장 표본에선 순이익처럼 보이나 이는 반납多 표본에 대한 **selection** — 추세장에선 오히려 비용일 수 있음.
2. **weight 0.60 유지가 깨지는 경우:** 방어장이 지속 약세장으로 심화 → 4 오픈 전량 반전 + 반복 휩소 진입이 왕복마다 ~1유닛씩 실현손실 누적(Σ캡은 스냅샷만 묶고 순차 누적은 못 묶음) → 계좌 슬로우 블리드. **이때는 blunt 축소가 아니라 레짐 인지 진입억제(Q2 3순위)가 정답.** 즉 "레짐 지속 확인" 이 트리거이지 단발 3청산이 아님.
3. **AI 0.2 거부가 깨지는 경우:** 오염 보정이 틀렸거나(시정 후에도 -8% 백스톱이 여전히 binding) + 방어장 수개월 지속 + exit 이식이 갭으로 저성과 → 그러면 0.60 유지가 오판이고 AI 의 blunt 디리스크가 옳았다. AI 권고는 불확실성하 합리적 prior — 거부는 오염보정 + 리스크캡 + 해상도 논거 삼박자가 모두 성립한다는 베팅.
4. **스테이지3 설계판정이 깨지는 경우:** stage 계산이 silent 오류(EMA 기간 오설정/비교 버그로 3 도달 불가)면 0발화가 dead path 를 가리는 것. 08-18 stage 2/1/1 정상산출이 계산 작동을 방증하나, **stage 3 이 애초 도달가능 임계인지** 장기 로깅으로 확인해야 완전 배제.

한계: N=9 는 통계적 판정에 여전히 작다. 오염보정치(-5~-6%)는 추정이며 실제 08-04 이후 손절 실측이 쌓여야 확증. 08-18 3청산은 시장성 동시발화라 kojiro 고유 성과로 오귀인 금지.

## 후속 검증 권고 (tdd-engineer / tester)

- **tdd-engineer:** 브레이크이븐 플로어 이식 시 회귀 테스트 합성 시리즈 = (a) +1.5N 도달 후 완전왕복 → breakeven 청산 확인 (b) +1.5N 도달 후 계속 상승 → 샹들리에가 플로어 위에서 트레일(breakeven 절단 안 됨) 확인 (c) 익일아침 갭다운 → 플로어 하회 체결 계약 확인. `max(플로어, 샹들리에, 백스톱)` AST 가드로 레이어 순서 봉인.
- **tester:** stage 분포 주기 로깅 후 stage 3 도달 가능성 라이브 확인. Σ오픈리스크 캡이 순차누적을 안 묶는다는 사실을 운영 모니터에 명시(캡 green 이어도 누적 블리드 가능).
- **재튜닝 자문 재호출:** N=10 도달 즉시 exit 패키지(브레이크이븐 플로어 + 샹들리에 유지 + 부분익절 보류) + weight 재결정 + 레짐게이트 정책질의를 묶어 domain-consult 재요청.
