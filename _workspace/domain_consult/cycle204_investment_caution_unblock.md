# 자문 — 시장경고/투자주의 계열 플래그 차단 완화 (사이클 204)

## 질문 요약

급등하면 투자주의(투자주의종목)로 지정되는데, 그 차단이 돌파전략의 표적 급등주를 매수 유니버스에서 제거한다. 사이클 203(iscd_stat 과차단 제거)에 이어, 투자주의 계열을 어느 코드/플래그까지 풀지 확정한다.

## 1. KIS 정본 코드값 (mrkt_warn / mrkt_alrm 00~03)

### KIS MCP 확인 결과 — 부분 확인 (enum 미공개)

- `mrkt_warn_cls_code` = FHKST01010100(주식현재가 시세) 응답 필드. KIS 공식 chk 파일(`chk_inquire_price.py`) COLUMN_MAPPING 에서 **한글 라벨 "시장경고코드"** 확정. 필드 존재·의미(시장경고 계열) 확정.
- **그러나 KIS 는 "00"/"01"/"02"/"03" 의 코드값 열거(enum)를 API 예제·docs 에 공개하지 않음.** 로컬 `docs/kis/domestic-stock-quote.md` 도 샘플값 "00" 만 존재. → **API 스펙 단독으로 "01=투자주의" 를 KIS 문서로 확정 불가.** (사이클 203 iscd_stat 과 동일한 "KIS 코드값 의미 미배포" 상황.)

### KRX 제도 정본 매핑 (외부 지식 + 운영 DB 실측 삼각검증)

KRX 시장경고 3단계는 제도상 **투자주의 → 투자경고 → 투자위험** 순 강도 상승. 코드값과의 매핑을 운영 DB 실측으로 확정:

| 코드 | KRX 제도 단계 | 강도 | 운영 DB 실측 (전체 / index 348) |
|------|--------------|------|------------------------------|
| `00` | 정상 (해당 없음) | — | 3,515 / 337 |
| `01` | **투자주의** | 약(mild) | 30 / **9** |
| `02` | **투자경고** | 중 | 14 / 0 |
| `03` | 투자위험 | 강 | 0 / 0 (실측 부재) |
| `null` | 미입수 | — | 17 / 2 |

**단조 강도 + 빈도 분포(01 이 02 보다 흔함)가 "01=투자주의(가장 약·가장 흔함)" 매핑과 정합.** master_raw `mrkt_alrm_cls_code` 도 동일 코드체계 — 실측상 index 9종목이 `mrkt_warn=01` ↔ `mrkt_alrm=01` **1:1 일치** = 두 필드 동일 3단계 코드계 확정.

**"01=투자주의" 는 KIS API 문서로는 미확인, KRX 제도 + 운영 실측 삼각검증으로 실질 확정.** (자문 메모에 미확인 사실 명시 의무 준수.)

## 2. 트레이더 시각 — 사용자 통찰 타당성 + pump-and-dump 위험

### 결정적 증거 — 차단되는 9종목의 정체 (운영 DB 실측)

`mrkt_warn="01"` 로 현재 유니버스에서 배제되는 index 9종목:

> **에스엘 · 에스원 · 삼성카드 · 제일기획 · CJ ENM · 한국항공우주 · 미스토홀딩스 · 클래시스 · RFHIC**

이 목록이 결론을 만든다. **삼성카드·한국항공우주·제일기획·에스원·CJ ENM 은 코스피200 대형 우량주**다. 작전주·잡주가 **아니다**. 투자주의(01)가 우량 대형주에 붙는다는 것은, 투자주의가 **소수계좌 집중·단기 상한가 근접·특정일 회전율 급증 같은 "그 날의 미시적 이상"에 KRX 가 자동 부여하는 mild 경보**이지, pump-and-dump 신호가 아니라는 결정적 방증이다.

### 급등 ↔ 투자주의 인과 — 사용자 통찰 타당

투자주의 지정 트리거(KRX 시장감시):
- 소수지점·소수계좌 거래집중
- 종가 급변 / 단일계좌 대량 상위
- **단기(당일~수일) 주가 급등**

돌파전략(BFB/VB/LTV/VCP/momentum)이 **표적으로 삼는 "거래량 터지며 장대양봉 급등"** 이 바로 위 트리거를 자연히 발생시킨다. **투자주의는 급등 돌파의 부수효과이지 원인 리스크가 아니다.** 사용자 통찰 정확.

### pump-and-dump 위험 평가

투자주의(01) 단독은 pump-and-dump 전조로 보기 **약하다**. 근거:
- 투자주의는 KRX 3단계 중 **최약** 경보 — "지켜본다" 수준. 매매 제한(신용·증거금 강화)은 **투자경고(02)** 부터.
- 진짜 작전주 위험은 **별도 전용 플래그가 이미 커버**: 단기과열(short_over) / 공매도과열(ssts_hot) / 이상급등(stange_runup) / 관리종목(mang) / 정리매매(sltr). 이들은 유지된다.
- 실측상 index 9종목 전원이 `short_over=N`, `ssts_hot` 공백, `stange_runup=N` — **투자주의만 붙고 과열/이상급등 플래그는 안 붙은 순수 mild 케이스**.

### 위험 시나리오 (반례) — 완화가 깨지는 경우

- **코스닥 초소형 급등주에서 투자주의가 pump 초입**일 수 있다. 그러나 그 경우 대개 short_over/stange_runup 이 **동반** 되며, 그건 유지되므로 차단된다. 투자주의 **단독** 급등주만 통과.
- **투자경고(02)로 승격 중인 종목의 01 단계**를 매수하면 익일 02 승격 + 신용/증거금 강화로 유동성 급감 위험. → 하지만 돌파전략은 당일·수일 청산 구조(VB 15:20 일괄, LTV 익일)라 02 승격 전 이탈. 보유 지속 위험은 donchian/VCP 멀티데이만 — 이건 4번 항목의 손익비 논의로 흡수.

## 3. 관련 플래그 판단

### (a) `invt_caful_yn` (투자유의, FHKST) — **함께 해제**

- KRX "투자유의" 제도 = 소액·저유동성·불건전 요주의. 라벨은 다르나 **투자주의(01)와 같은 "약한 예방적 경보" 계열**.
- 실측: index 유니버스에서 `invt_caful=Y` 는 **0종목** (9종목 전원 N). → 해제해도 **당장 추가 통과 종목 0** = 완화 리스크 0, 일관성만 확보.
- 판단: **투자주의(01) 해제와 같은 논리로 함께 해제.** (mild 예방 경보를 돌파 유니버스에서 일괄 정렬.) 리스크 없음 + 미래 우량주 부수지정 대비.

### (b) `invt_alrm_yn` (투자주의환기, KOSDAQ 전용) — **유지**

- **이름이 비슷해 헷갈리나 완전히 다른 제도.** "투자주의환기종목"은 KOSDAQ **상장폐지 실질심사 사전 경보** = 재무·지배구조 부실 신호(횡령·배임·감사의견·자본잠식 등). **급등과 무관, 펀더멘털 부실.**
- 실측: index 유니버스 `invt_alrm=Y` **0종목** (해제해도 통과 0).
- 판단: **유지.** 급등주와 인과 없음 + 부실 종목 진입 차단은 손익비상 명백히 유지. 해제 이득 0, 위험만 있음.

### (c) `mrkt_alrm_cls_code >= "02"` (master, 이미 주의 허용) — **그대로 유지 (정합)**

- 이미 투자주의(01) 허용, 투자경고(02)/투자위험(03)만 차단. **완화 후 raw 분기와 정확히 정렬됨** (raw 도 02 이상 차단으로 통일).
- 판단: **변경 없음.** 이게 정답 기준선이었고, raw 를 여기 맞추는 것이 이번 완화의 본질.

## 4. 급등 플래그 유지 확인

| 플래그 | 성격 | 판단 | 근거 |
|--------|------|------|------|
| `short_over_yn` (단기과열) | 급등의 **극단** — 회전율·변동성 임계 초과, 3일 냉각 단일가 위험 | **유지** | 단기과열은 익일 단일가매매 전환 리스크 = 슬리피지·유동성 급변. 돌파의 "정상 급등"과 "과열"의 경계선 = 손절 페이크 급증 구간. 유지가 손익비 우위 |
| `ssts_hot_yn` (공매도과열) | 공매도 집중 = 하방 압력 신호 | **유지** | 돌파 매수 직후 공매도 물량 대기 = 상단 저항. 롱 돌파에 역방향 |
| `stange_runup_yn` (이상급등) | KRX 이상급등 공식 지정 = 작전 의심 최고강도 | **유지** | pump-and-dump 정면 신호. 절대 해제 불가 |

**투자주의(01)만 풀고 과열/공매도과열/이상급등은 유지 = 손익비상 정확.** 이유: 투자주의는 "급등했다"는 사후 라벨(부수효과)이고, 과열 3종은 "급등이 비정상 영역에 진입했다"는 실질 리스크(원인). 돌파전략은 전자를 원하고 후자를 피해야 한다. **경계선을 투자주의(허용)와 과열(차단) 사이에 긋는 것이 트레이더 본능과 정합.**

## 반례 / 한계

1. **KIS enum 미공개** — "01=투자주의" 는 KIS API 문서 단독 미확인. KRX 제도 + 운영 실측 삼각검증. KIS 가 향후 코드 재정의 시 재검증 필요(가능성 낮음 — KRX 제도 안정).
2. **투자주의 단독 코스닥 초소형 급등주** = 이론상 pump 초입 통과 가능. 단, 실제로는 short_over/stange_runup 동반 확률 높음(유지 플래그가 흡수). 잔존 위험 = 순수 투자주의 단독 소형주 극소수.
3. **02 승격 직전 01 매수** = 멀티데이(donchian/VCP) 보유 시 익일 신용/증거금 강화 유동성 위험. 당일·익일 청산 전략(VB/LTV/momentum)은 노출 미미. 운영 2주 후 `mrkt_warn=01` 진입 종목의 익일 02 승격률 실측 권고.
4. **완화 실효 규모** = 즉시 9종목(대부분 우량주라 오히려 안전). 급등주 유입 폭증은 아님 — 이번 완화 본질은 "우량주 오차단 복구" 지 "잡주 유니버스 확대"가 아님.
