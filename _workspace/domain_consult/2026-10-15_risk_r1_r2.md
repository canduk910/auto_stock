# 자문 — 리스크 권고 R1·R2 적용 전 차단 사유 점검 (2026-10-15)

## 질문 요약
사용자가 `_workspace/risk/2026-10-15_weekly_risk.md` 의 R2(`cash_usage_ratio` 0.95→0.75)와 R1(`etf_trend` `market_unit_mode` shadow→enforce)을 채택했다. 10-16 개장 전 적용을 막을 사유가 있는가, 적용 뒤 무엇을 확인하는가.

## 결론 — 둘 다 적용 가. 차단 사유 없음
단 R1 에 대한 리스크 보고서의 전제 하나는 틀렸다(아래). 결론은 바뀌지 않는다.

## 운영 DB 실측 (10-15 조회만)
- `system_config`: `cash_usage_ratio=0.95`, `auto_regime_adjust=false` → 사람이 넣은 0.75 가 매크로 자동 조정에 덮이지 않는다.
- 터틀 5전략: kojiro `risk_pct` 0.005 · donchian 0.012 · BFB/VCP/etf_trend 0.01, `max_lot_units` 전부 2.0, ρ축 2.5(VCP 1.5). `market_unit_mode` = etf_trend 만 `shadow`, 나머지 `enforce`. 다섯 다 `shadow_mode=false`·`buy_paused=false`.

## R2 — `cash_usage_ratio` 0.95 → 0.75
전략 예산이 모두 ×0.789 가 된다. 「1주 언저리라 특정 전략이 전면 무매매가 되는가」를 1유닛 금액(예산 × risk_pct)으로 따졌다.

| 전략 | 1유닛 금액 0.95 → 0.75 | 1주 폴백이 살아 있는 ATR 상한(K=2) 0.75 기준 | 판단 |
|---|---:|---:|---|
| kojiro | 6,910 → 5,455 | 10,911 | 전면 무매매 아님. 오늘 053450(3,630원)은 ATR 수백 원이라 여유가 많다 |
| donchian | 13,822 → 10,911 | 21,822 | 무매매 아님 |
| BFB | 9,213 → 7,274 | 14,548 | 무매매 아님 |
| VCP | 9,213 → 7,274 | 14,548 (ρ 상한 가격 약 36만 원) | 무매매 아님 |
| etf_trend | 2,302 → 1,818 | 1주 폴백 없음(L5) | 가장 얇다. ATR 이 1,818원을 넘는 고가 ETF(지수 6,000선의 200 추종 ETF는 ATR 2% 대면 경계선)는 `rounds_to_zero`. 단 지금은 코스피 m=0 이라 어차피 안 산다 |

- 줄어드는 것은 「1유닛이 1주도 안 되는 고ATR 고가 종목」 쪽 진입뿐이다. 이것은 리스크 보고서가 이미 적은 부작용(「투자금 부족」 귀인 증가)과 같은 것이고 새 위험이 아니다.
- 보유 0 이라 기보유 손절 규약·캡이 바뀌는 문제가 없다. 지금이 바꾸는 비용이 가장 낮은 날이다.
- 적용 경로는 `PUT /api/strategies/system/cash-usage-ratio {"ratio":0.75}`(또는 Settings 슬라이더)다. DB 를 직접 UPDATE 하지 않는다. 다음 영업일 `_boot()`(10-16 07:45)부터 반영된다.

## R1 — `etf_trend` `market_unit_mode` shadow → enforce
**리스크 보고서 전제 정정**: 보고서는 「코스피 m=0 인 지금 이 전략만 1배 수량으로 산다」고 적었다. 코드상 사실이 아니다. `etf_trend.check_buy_signal`(src/engine/strategies/etf_trend.py:187~196)은 모드가 `off` 가 아니면 shadow 에서도 `view.m <= 0` → `zero_state` 로 매수를 거른다(모듈 독스트링 L4: 「shadow 에서도 거른다」). 그래서 **m=0 인 지금은 R1 을 적용하든 말든 신규 매수 0 은 같다**.

- R1 이 실제로 바꾸는 것은 코스피가 m=0.5/0.75 로 다시 열릴 때뿐이다. 그때 랏을 줄이고, 줄인 랏이 0 이면 거른다(`_market_unit_blocks_entry`). 다른 터틀 4전략과 같은 규칙이 되므로 방향은 맞다. 막을 이유는 없다.
- 시장 판정: m≤0 게이트는 `_market_unit_view()` 를 종목 없이 불러 **항상 코스피**다. 랏 축소 게이트는 종목별 `stock_master.excg_dvsn_cd` 를 쓰고, `03`(코스닥)이 아니면 코스피다. 국내 ETF 는 유가증권 상장이라 두 경로 모두 코스피 = 0001 로 판정된다. 둘이 갈릴 일은 사실상 없다.
- R2 와 겹치면(예산 18만 원 × m 0.5~0.75) 재개 초기의 etf_trend 는 고가 ETF 를 거의 못 산다. 비중 0.05 를 고른 결과이며 손실 위험 쪽 문제는 아니다.
- 적용 경로: `PUT /api/strategies/etf_trend/params {"params":{"market_unit_mode":"enforce"}}` — 즉시 반영. 보유 0 이라 장중에 적용해도 무방하다.
