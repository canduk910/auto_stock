## 트레이더 시각 — 3개 전략은 근본이 다르다

먼저 셋업의 성격을 갈라야 한다. **셋 다 "0신호"라고 한 통에 묶으면 오판한다.**

- **donchian = 시장 상태 종속 (market-state dependent).** 20일 신고가는 "시장이 오르면 흔하고, 옆으로 기면 드물다." 셋업 빈도가 시장 국면에 **선형 종속**. 0이 나오는 건 전략 잘못이 아니라 시장이 안 만든 것.
- **VCP = 설계상 희소 (by-design rare).** 미네르비니 VCP는 원래 "며칠에 한 종목" 나오는 정밀 셋업이다. 25~75일 베이스 + 2~4회 점진 수축 + 거래량 고갈 + EMA 정배열을 **동시 충족**하는 종목은 상승장에서도 전체 유니버스의 1~3%. 0이 자주 나오는 게 정상.
- **BFB = 대비가 진단의 핵심.** "폴은 3~8개 잡히는데 플래그가 0~1개." 이건 시장 탓이 아니다. **폴 다음 단계의 임계가 한국 미시구조와 안 맞는다는 강력한 신호.** 셋 중 유일하게 "구조적 엄격" 의심이 실측으로 뒷받침된다.

### 한국 시장 미시구조 상수 (판정 근거)

1. **±30% 상하한가.** 미국(제한 없음) 대비 한국은 하루 변동이 잘림. → 강한 폴(급등)이 미국보다 짧고 가파르다. 3~10일에 +15%는 한국 중소형주에선 "하루 상한가 한 방 + 이틀 눌림"으로도 충족 가능 = **폴은 흔하다** (BFB 실측 폴 3~8개와 일치).
2. **눌림(플래그)의 얕음.** 한국 급등주는 눌림이 **얕고 빠르다.** 상한가 다음날 "쩜상 → 눌림 → 재급등"이 반나절에 끝난다. 플래그 조정폭이 폴의 38.2% 이내 + 3~10일 지속 + 거래량 60% 미만을 **동시** 요구하면, 한국 급등주의 "2~3일 얕은 눌림 후 즉발 재상승" 리듬과 어긋난다. → **플래그 검출 0의 진짜 원인.**
3. **20일 신고가의 국면 종속성.** KOSPI200∪KOSDAQ150 350종목에서 횡보장(지수 ±2% 박스) 20일 신고가 갱신 종목은 통상 5~15%. 여기에 **60일 EMA 우상향 + 거래대금 1.5배** 3중 AND를 걸면, 횡보장에서 55종목→0~1은 **과하지 않다.** 신고가 후보 55는 "전일종가>0 + 일봉 fetch 통과"까지의 잔존일 뿐, 진짜 20일 신고가 돌파는 그 안에서 소수.

### 실전 사례 / 통계 감각

- **상승장 대비.** 2020년 3~8월, 2023년 초 2차전지 랠리 같은 국면에선 donchian 20일 신고가가 하루 20~40종목씩 쏟아진다. 지금 0은 "전략이 망가진 게 아니라 시장이 신고가를 안 만드는 국면"이라는 정직한 신호다. **donchian이 0을 내는 건 오히려 전략이 국면을 정확히 읽고 있다는 방증.**
- **VCP 희소성.** 미네르비니 본인도 "하루 스캔 수천 종목에서 관심종목 5~10개, 실제 매수 0~2개"라 했다. 350종목 유니버스에서 0~2/일이 정상 상한. 7월초 0은 이상하지 않다.
- **BFB 폴↔플래그 붕괴.** 폴 5개 → 플래그 0. 이 붕괴율(100%)이 4일 연속이면 통계적으로 "우연한 희소"가 아니다. 한국 급등주 리듬(얕고 빠른 눌림) 대비 flag_lookback_min=3일 + retracement 38.2% 조합이 너무 좁다는 실증.

### 위험 시나리오 (가설이 깨지는 경우)

- **donchian 완화 오판 위험.** 만약 "신고가 0이 과하다"고 donchian_period를 20→10으로 낮추면, 횡보장 박스 상단을 신고가로 오인해 **박스권 페이크 돌파에 연속으로 잡힌다.** 횡보장에서 신고가 완화 = EV 악화. donchian은 **손대면 안 되는 대표 케이스.**
- **VCP 완화 = 셋업 정의 파괴.** pullback_count_min을 낮추거나 수축 조건을 풀면 "VCP가 아닌 것"을 VCP로 잡는다. 저품질 진입 폭증. 미네르비니 VCP의 승률(60~70%)은 정밀함에서 나온다.
- **BFB만 완화 여지.** 단, 플래그 조건을 풀 때도 flag_volume_ratio(거래량 고갈)는 절대 건드리면 안 된다. 거래량 고갈은 "눌림이 진짜 눌림(매물 소화)이지 하락 전환이 아님"을 증명하는 핵심 필터. 여기 풀면 하락 초입을 플래그로 오인.

### 권고 수치 (BFB 단독, 나머지 2개는 변경 0)

AI 자문의 "min_trade_amount↓ / volume_mult↓ / max_scan_stocks↑" = **C-1 판정에 동의 — 역효과.** 거래대금/시총 필터는 350종목→16~36까지 이미 통과했고, 0으로 떨어지는 지점이 아니다. 여기 손대면 **후보 풀만 늘고 패턴은 여전히 0** + 저품질 종목만 유입. **AI의 필터 완화 권고는 폐기.**

완화가 정당한 유일한 지점 = **BFB 플래그 검출의 시간창.** 한국 급등주 눌림이 3일보다 짧게 끝나는 것이 원인이라면:

| 파라미터 | 현재 | 권고 | 근거 |
|----------|:---:|:---:|------|
| `flag_lookback_min` | 3 | **2** | 한국 급등주 얕은 눌림이 2일에 끝나는 경우 포착 (상한가 익일 눌림 → 3일차 재돌파 리듬). 절대 건드리지 말 것 = flag_retracement_max(0.382)·flag_volume_ratio(0.60). |
| `flag_retracement_max` | 0.382 | **0.5 (선택)** | 피보나치 38.2% → 50%. 한국 급등주는 폴이 가팔라 조정폭도 상대적으로 큼(변동성 잘림 없는 강한 폴). 단 50% 초과는 추세 훼손이라 상한. **이건 2순위 — flag_lookback_min=2 먼저 관찰 후 판단.** |
| `pole_min_return` | 15.0 | **변경 0** | 이미 사이클 48에서 20→15로 완화됨. 폴은 3~8개 잘 잡히므로 병목 아님. **더 낮추면 폴 오검출.** |

**핵심: `flag_lookback_min` 3→2 단일 변경부터.** 두 파라미터 동시 완화 금지 (효과 분리 불가). retracement 완화는 별도 관찰 후.

### 근거 (백테스트 / 운영 로그 / 시장 통계)

- **C-1 funnel 4일 실측** (요청 문서): BFB 폴 3~8 → 플래그 0~1. 붕괴 지점이 명확히 "플래그 검출" 단계로 특정됨 = 완화 대상이 파라미터 수준에서 국소화됨.
- **후속 검증 필수** (아래 §후속 검증 권고): 실제 완화 전, EC2에서 `tools/measure_bfb_pole_flag.py`(사이클 50 신설, 실측 스크립트) 로 flag_lookback_min=2 가정 시 플래그 검출 수를 **먼저 측정** — 0→몇 개로 늘어나는지 확인 후 채택.

## 반례 / 한계

1. **표본 4일 = 단면.** 7/6~7/9는 전부 횡보장. "완화가 필요하다"는 결론을 내리기엔 국면 편향. 상승장 1주만 붙어도 3개 전략이 자연 발화하면 완화는 불필요했던 게 된다. → **선택지 B(관찰 연장)가 안전한 default.**
2. **BFB 완화의 역설.** flag_lookback_min=2로 낮추면 "폴 다음날 하루 눌림"도 플래그로 잡는데, 이게 진짜 눌림인지 **폴의 되돌림(급락 초입)** 인지 2일 데이터로는 구분이 어렵다. → flag_volume_ratio(거래량 고갈) 필터가 이 오판을 막는 유일한 안전장치. **거래량 필터를 절대 함께 완화하지 말 것.**
3. **VCP 0이 "정상"이라는 판정의 한계.** VCP는 원래 희소하나, **effective_ema_long≈75(사이클 48/173)** 로 축소된 상태다. 진짜 120EMA 원설계로 복원(사이클 174 인계)하면 추세필터 통과 종목이 달라질 수 있다. 현재 VCP 0을 "순수 패턴 희소"로만 볼지, "EMA 축소로 인한 추가 탈락"이 섞였는지는 **funnel step5(EMA 정렬) 생존 수를 별도 확인**해야 정밀 판정 가능. C-1 표는 step5를 안 보여줌.
4. **횡보장 무매매 = 손실 회피 = 이득.** 잊지 말 것. 3개 전략이 0을 낸 4일 동안 손실 0. VB만 -7,000원. **돌파 전략이 횡보장에서 안 사는 건 버그가 아니라 기능이다.** "신호를 억지로 만드는" 방향의 완화는 트레이더 관점에서 최악의 튜닝. 셋업이 없으면 안 사는 게 정답.

2. **[VCP 정밀 판정] funnel step5(EMA 정렬) 생존 수 노출** — E-1(리포트에 funnel 노출, C-1 최우선) 구현 시 VCP step5 카운트를 반드시 포함. EMA 축소(≈75)로 인한 탈락과 순수 패턴 희소를 분리 판정.
3. **[donchian/VCP 변경 0 회귀 가드]** — 만약 BFB만 완화하는 TDD 사이클을 돌린다면, donchian·VCP DEFAULT_PARAMS diff 0 을 AST 가드로 고정(다른 전략 무변경 증명).
4. **[BFB 완화 시 회귀 테스트]** flag_lookback_min=2 채택 시: (a) 얕은 2일 눌림 + 거래량 고갈 = 검출 성공 (b) 2일 급락(거래량 유지) = 검출 실패(오판 차단) 두 케이스를 합성 시리즈로 Red 작성. flag_volume_ratio가 (b)를 거르는지가 핵심 가드.
5. **[관찰 연장 옵션]** 선택지 B 채택 시 코드 변경 0 — 대신 E-1 리포트로 상승장 전환 시 3개 전략 자연 발화를 2~3주 모니터링. 발화하면 완화 논의 자체가 종결.
