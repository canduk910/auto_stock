## 결론 — **매트릭스 NO-GO / 경량 VWAP·RVOL veto 조건부 GO(별도 사이클)**

제안된 "일봉 스테이지 × 15분봉 스테이지 매트릭스"는 kojiro 의 **6→1 신선전환 진입에 가산가치가 거의 없다**. 대신 09:05~09:30 창의 단일틱 비붕괴 게이트를 **당일 VWAP 위치 + 개장 RVOL 의 얇은 veto** 로 업그레이드하는 것이 "장중 확증"이 실제 해야 할 일을 지연 없이·정확히 한다. 단 정량 임계는 운영 표본(`trade_history`/`daily_log_reports`) 축적 후 백테스트 캘리브레이션 선행 → **별도 사이클**. 현 사이클은 연구 종결(코드 변경 0).

## 근거 1 — 정보 중복 (직교 아님)

- **데이터 창 포함관계**: KRX 정규장 15분봉 ≈ 26개/일 → 15분 EMA40 span ≈ **1.5영업일**(워밍업 포함 3~5일). 반면 일봉 6→1 전환은 일봉 EMA5 가 밀어올려 발생 = 최근 **5~10영업일** 가격이 동인. 즉 15분 스테이지가 보는 창은 일봉 6→1 을 만든 창의 **부분집합** → 상관 높음 → 중복.
  - (원설계문서·초기 가정의 "40봉≈10영업일"은 오류 — 실제 ≈1.5일. **정정은 중복 결론을 강화**: 창이 짧을수록 최근 상승과 겹침 ↑.)
- **직교가 되는 유일 케이스 = 다이버전스**(일봉 stage1 인데 15분 stage4 롤오버). 그러나 **6→1 신선전환 직후엔 이 케이스가 구조적으로 배제**(방금 정배열로 튼 종목의 최근 장중이 이미 꺾여 있을 확률 낮음). 매트릭스가 정보력을 갖는 셀이 kojiro 가 진입하는 상황에서 비어 있음.
- 스테이지(MA 순서)는 장중 분산(강세 마감이나 내부 매도소화) 포착에 **무딘 도구** — 그건 EMA 배열이 아니라 VWAP 대비 종가·거래량-가격이 낫다.

## 근거 2 — 기회비용 (역선택)

추세추종 엣지 = 팻 우측꼬리(20~50%+ 소수 거래, 승률 30~40%·PF 중심). 확증필터는 **역선택** 유발 — 가장 강한 날은 확증을 기다려주지 않고 갭업·질주 → 필터가 이들을 우선 지연/기각하고 약하고 눌린 날을 통과시킴. 15분 스테이지판은 봉 축적 대기 → 진입 09:30+ 로 밀림 → 첫 창 엣지 잠식. **얇은 정보이득 < 실질 기회비용 → 상쇄 안 됨.**

## 데이터 조달 (참고 — GO 시에도 분봉 스테이지는 불채택)

우리 코드에 분봉 계층 **전무**(KIS 분봉TR 미통합 + 틱 자체집계 없음 + 적재 테이블 없음). 조달 경로:
- **(A) KIS 분봉 TR**: `FHKST03010200`(당일 30봉/호출·당일만) + `FHKST03010230`(일별 120봉/호출·과거 1년). `_QUOTE_ALLOWED_PATHS`(base.py) 추가 필요.
- **(B) 틱 자체집계**: 이미 수신 중 H0STCNT0 틱을 handler/scanner OHLC 버퍼로 15분봉 집계.
- 어느 쪽이든 **다일 연속 15분봉**이라야 스테이지 성립(09:05 당일 봉 0~2개) → "당일 실시간 확증"이 아님(근거 1의 중복 원인). VWAP/RVOL 대안은 **경로 B(이미 있는 틱피드) + `stock_master_daily`(RVOL 베이스라인)** 로 조달 가능 → 분봉TR 신규 통합 불필요.

## 경량 대안 설계 (조건부 GO, 별도 사이클)

09:05~09:30 창 유지 + 첫 창 미지연 원칙. 전부 **비대칭 veto**(명백한 실패 개장만 제거, 팻테일 보존):
- **Tier 1 (최소·권장)**: 단일틱 비붕괴 → **당일 VWAP 홀드**(진입평가 시점 현재가 ≥ 세션 VWAP, 소밴드 허용). 갭업≥5%/갭다운≤-4% 게이트 유지.
- **Tier 2 (선택)**: **개장 RVOL 하한**(개장 거래량 ≥ 평시 동시간 배수, 초기 0.8~1.0×). 죽은 돌파 제거, 지연 0.
- **Tier 3 (백테스트 검증 시만)**: 첫 5분봉 저가 미붕괴.
- **주의**: veto 를 강한 다조건 게이트로 키우면 다시 팻테일을 깎음 → 반드시 얇게. 강한 갭업 질주일은 시초부터 VWAP 위라 veto 거의 안 걸림(정상).

## 조건부 재검토 트리거

kojiro 가 향후 **6→1 외 stage 2/3 연속진입·피라미딩**을 도입하면, 그때는 다일 15분 스테이지의 다이버전스 veto 가 직교정보를 가짐(눌림 추가매수에서 장중 롤오버 감지) → **매트릭스 재검토**. 현 6→1 전용 설계에선 no-go.

## 후속 (별도 사이클, 착수 승인 후)

1. VWAP/RVOL veto Tier 1(+2) 설계 → domain-consult 정량 임계 → tdd-engineer 합성 회귀(중복 케이스 무용 입증 / 갭업질주 통과 / 개장페이드 차단) → 백테스트 역선택 측정(상위 10% 수익거래 진입 성사율 전/후).
2. 데이터: VWAP = H0STCNT0 틱 세션 누적(가격×거래량/거래량), RVOL 베이스라인 = `stock_master_daily`. 분봉TR 신규 통합 불요.
