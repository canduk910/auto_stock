## 트레이더 시각

### VB (volatility_breakout) 매매 영역 영구 영속

**VB의 본질 영역 영구 영속**: 전일 Range × K값 시가 돌파 영역 영구 영속 = 단순 영역 영구 영속 변동성 돌파 영역 영구 영속. 운영자가 의사결정 영역에서 가장 가치 있는 가시화 영역 영구 영속:

1. **K값 분포 영역 영구 영속**: K값 = noise / range 비율 영역 영구 영속 = 종목 영역 영구 영속 변동성 특성 영역 영구 영속 직접 영구 영속. K값 1.0 미만 영역 영구 영속 = "전일 범위 좁다" 영역 영구 영속 = 돌파 신호 영역 영구 영속 빈도 높음 / 진폭 작음. K값 1.5+ 영역 영구 영속 = "전일 범위 넓다" 영역 영구 영속 = 돌파 신호 영역 영구 영속 빈도 낮음 / 진폭 큼 영역 영구 영속.

2. **거래대금 분포 영역 영구 영속**: 거래대금 200억 이상 영역 영구 영속 = 작전주 차단 영역 영구 영속 + 유동성 영역 영구 영속 확보 영역 영구 영속.

3. **시총 분포 영역 영구 영속**: 시총 1,000억 이상 영역 영구 영속 = 우량주 영역 영구 영속 한정.

### LTV (long_tail_volatility) 매매 영역 영구 영속

**LTV의 본질 영역 영구 영속**: VB + 전일대비 5% 이상 영역 영구 영속 등락률 영역 영구 영속 + 연속 상한가 2일 이상 영역 영구 영속 제외 영역 영구 영속. LTV 특화 영역 영구 영속:

1. **연속 상한가 검출 영역 영구 영속**: VB에 없는 LTV 단독 영역 영구 영속. 직전 N영업일 영역 영구 영속 등락률 영역 영구 영속 30% 도달 횟수 영역 영구 영속 추적.

2. **상한가 모드 영역 영구 영속**: 매수 후 당일 상한가 도달 영역 영구 영속 → 익일 청산 모드 영역 영구 영속 진입 영역 영구 영속. funnel 영역 영구 영속에서 직접 노출 의무 영역 영구 영속 = **아님** (prepare() 영역이 아닌 check_buy_signal/check_exit_signal 영역 영구 영속).

3. **PRE_NXT / MAIN / POST_NXT 3 보드 영역 영구 영속**: VB는 MAIN 단독 영역 영구 영속. LTV는 야간 매수 + 연속 상한가 익일 청산 모드 영역 영구 영속 보유.

### funnel 단계 정의 영역 영구 영속 = 운영자 가치 vs 코드 복잡도 영역 영구 영속

**도메인 전문가 권고 영역 영구 영속**: BFB / VCP / donchian 영역 영구 영속 8단계 영역 영구 영속 답습 영역 영구 영속 = VB / LTV 영역 영구 영속 **과도 영역 영구 영속**. 이유 영역 영구 영속:

- BFB 영역 영구 영속 = 폴 + 플래그 자동 검출 영역 영구 영속 = 복잡 영역 영구 영속 (8단계 영역 영구 영속 자연 영구 영속)
- VCP 영역 영구 영속 = 베이스 + Pullback + ATR ZigZag 영역 영구 영속 = 복잡 영역 영구 영속 (8단계 영역 영구 영속 자연 영구 영속)
- donchian 영역 영구 영속 = 60일 EMA + 20일 신고가 + 거래대금 영역 영구 영속 = 다단계 영역 영구 영속 (8단계 영역 영구 영속 자연 영구 영속)
- VB 영역 영구 영속 = 시총 + 거래대금 + K값 영역 영구 영속 = 단순 영역 영구 영속 (5단계 영역 영구 영속 적정 영역 영구 영속)
- LTV 영역 영구 영속 = VB + 연속 상한가 영역 영구 영속 = 약간 복잡 영역 영구 영속 (6단계 영역 영구 영속 적정 영역 영구 영속)

**권고 6단계 영역 영구 영속**:

| 5 | 연속 상한가 필터 통과 | `consecutive_limit_pass` = 직전 N영업일 (DEFAULT 2일) 영역 영구 영속 등락률 30% 도달 횟수 영역 영구 영속 미만 영역 영구 영속 | **LTV 핵심 가치 영역 영구 영속** = 연속 상한가 종목 영역 영구 영속 운영자 가시화 영역 영구 영속 (위험 종목 영역 영구 영속 제외 영역 영구 영속) |

**구현 영역 영구 영속**: `_scan_universe()` 영역 영구 영속 (1~2단계) + `prepare()` for loop 영역 영구 영속 (3~6단계) 6 hook 호출 영역 영구 영속.

### 의제 3 — funnel 영역 운영자 가치 vs 코드 복잡도 평가

**도메인 전문가 평가 영역 영구 영속**:

**(a) 운영자 가치 영역 영구 영속 (HIGH)**:
- 사용자 보고 verbatim "2, 3, 4가 0으로 표시 + 유니버스 후보에서 바로 최종대상 됨" 영역 영구 영속 = 운영자 진단 영역 영구 영속 가시화 영역 영구 영속 결핍 영구 영속 직접 영구 영속 표현 영역 영구 영속.

- `risk.on_tick` / `order_engine` / `realtime/` / `auth/` 변경 0 영역 영구 영속.
- 매도 / 익일청산 / 15:20 강제청산 / 손절 hot path 무관 영역 영구 영속.

**권고 영역 영구 영속**: 운영자 가치 HIGH + 코드 복잡도 LOW~MEDIUM + 매매 안전성 무영향 영역 영구 영속 = **진행 권고 영역 영구 영속**.
