## 트레이더 시각 — 브레이크이븐 승격의 본질

브레이크이븐 승격은 트레이더가 손으로 하던 "본전 스탑 올리기"의 코드화다. 셋업이 먹혀서 초기 리스크(1R) 이상 벌어졌으면, "최소한 손해는 안 본다" 선까지 스탑을 끌어올려 **승자→패자 전환만 차단**하는 것. 폭(trail width)은 건드리지 않는다 — 추세는 그대로 끝까지 태우되, 바닥이 매수가 밑으로 못 내려가게만 막는다.

이번주 096770(+15.8%→-9%)이 정확히 이 레이어의 부재로 발생한 손실이다. 반면 089860 kojiro(+6.3%→-5.1%)는 선행 자문에서 "2.5ATR 폭은 의도된 설계, 레짐 문제"로 판정됐다 — 즉 **폭 조이기는 기각, 승격은 별개 레이어**라는 게 이번 확산의 정당한 논리다. 이 구분은 옳다. 승격은 폭을 안 건드리므로 089860 판정과 모순되지 않는다.

**중요한 사실 하나**: 승격은 `max()` 연산이라 손절선을 **올리기만** 한다. 리스크 관점에서는 단조적으로 안전하다 — 어떤 시나리오에서도 손실을 늘리지 못한다. 이 성질이 아래 판정 전체의 바탕이다.

## Q1. kojiro FREEZE 충돌 판정 (핵심)

### 판정: **(b) 청산 행위 변경 = 검증 표본 오염 → 8월 하순까지 보류** (기본), 단 의식적 override 경로 명시

**근거 (왜 (a) 안전 레이어 예외가 아닌가)**:
FREEZE 의 목적은 "리스크 통제"가 아니라 **"진입 재튜닝(밴드 4.5→6.0, 신선도 3→5)이 수익나는 라운드턴을 만드는지 검증"**이다. 검증 지표 = 라운드턴 손익 분포. 그런데 승격은 바로 그 **라운드턴 손익을 바꾼다**. 089860 같은 -5.1% 청산이 승격 하에서는 ~0%(본전)로 바뀐다. 즉 승격 전 표본과 승격 후 표본은 **서로 비교 불가능한 다른 분포**가 된다. 이건 정의상 표본 오염이다.

승격이 리스크 관점에서 안전(tighten-only)한 것과, 검증 방법론 관점에서 오염인 것은 **별개의 축**이다. FREEZE 는 리스크 제약이 아니라 실험 방법론 제약이므로, "안전하니까 예외"라는 (a) 논리는 성립하지 않는다.

**표본 별도 태깅 절충의 성립 여부 — 부분적으로만 성립, 타임라인은 구제 못 함**:
승격 발화 트레이드에 `promoted=true` 플래그를 달아 사후 귀속(attribution)하는 것은 **관측 가치는 있다**. 그러나 검증 목표인 "≥20 라운드턴 확보"를 앞당기지는 **못한다**. 이유:
- 현재 청산 표본 N≈1. 20까지 갈 길이 먼데, 태깅은 이 표본을 다시 `promoted` / `non-promoted` 두 하위집단으로 **쪼갠다**. 각각이 통계적 유의성에 도달하려면 오히려 더 오래 걸린다.
- 승격은 "승자→패자 전환" 케이스에서만 발화하는 **부분집합 이벤트**다. 20개 라운드턴 중 승격 발화는 소수(경험칙 20~35%)뿐 → 태깅된 하위집단은 4~7개 수준에서 정체.

**결론**: 태깅은 "나중에 승격이 얼마나 기여했나 되짚어보는" 용도로는 유효하나, FREEZE 를 8월 하순보다 앞당기는 근거는 못 된다.

## Q2. 전략별 승격 임계 + ATR 정의 차이

### ATR 정의 차이가 임계에 미치는 영향

| 전략 | ATR 정의 | 보유기간 성격 | 트레일 폭 |
|------|----------|--------------|-----------|
| donchian | 단순평균(14), **entry_atr 스냅샷**(진입 시 원자 고정) | 멀티위크 추세 | 2.0N (샹들리에) + P1-A 1.8N 폴백 |
| kojiro | Wilder ewm(1/20) — 더 매끄럽고 유효 lookback ~20 | 멀티데이~멀티위크 대순환 | **2.5N** (의도적 광폭) |
| vcp | 단순평균(14), `_candidates`에 live 저장 | 멀티데이 베이스 돌파 | 2.0N + 50일EMA |
| bfb | 단순평균(14), `_candidates`에 live 저장 | **최대 5영업일** | 2.0N + measured-move 전량 |

**핵심 관찰**: donchian 은 `entry_atr`(진입 순간 고정값)를 쓰지만, 나머지 3전략은 `_candidates[ticker]["atr"/"atr14"]`에 **매일 prepare/recompute 로 갱신되는 live ATR**을 쓴다. donchian 을 그대로 이식하면 승격 임계 `buy + 1.5×atr` 의 atr 이 **날마다 움직인다**.

이게 왜 위험한가 — **un-latch 병리**: 승격 조건이 `high_since_buy >= buy + k×atr_live` 인데, 나중에 변동성이 커져 `atr_live` 가 팽창하면 `buy + k×atr_live` 가 `high_since_buy` 위로 올라가 **조건이 다시 거짓**이 될 수 있다. 그러면 본전으로 올려놨던 손절선이 `buy - stop×atr` 로 **다시 내려간다**. tighten-only 취지에 정면 위배.

**정량 권고 — 이식 시 반드시 LATCH 처리**:
- 전략마다 `_breakeven_promoted: dict[str, bool]` 를 두고, 조건이 **한 번 참이 되면 True 래치**. 이후엔 atr 이 어떻게 움직여도 승격 유지. `on_position_closed` 에서 pop (kojiro `_stop_floor`/`_held_stage3` 정리와 동일 site).
- 이렇게 하면 donchian 의 entry_atr 고정 효과를 (별도 스냅샷 인프라 없이) live ATR 로도 재현. kojiro 는 이미 `_stop_floor`(tighten-only floor)가 있어 래치와 결이 완전히 같다 — 조합이 매우 깨끗하다.

### 전략별 권고 승격 임계

| 전략 | 권고 k (승격 임계) | ATR 소스 | 근거 |
|------|-------------------|----------|------|
| donchian | 1.5N (현행 유지) | entry_atr | 터틀 정본 2N 트레일 대비 0.75배 지점 본전 잠금. 검증된 값 |
| **vcp** | **1.5N** | `_candidates["atr14"]` live + 래치 | donchian 과 ATR 정의(SMA14)·성격(멀티데이 추세) 유사 → 직접 이식 타당 |
| **bfb** | (채택 시) **1.5N** | `_candidates["atr14"]` live + 래치 | 단 Q3(b) 참조 — 채택 자체를 default-off 권고 |
| **kojiro** | **2.0N** (1.5N 아님) | `_candidates["atr"]` Wilder + 래치 | **트레일이 2.5N 광폭**인 전략에 1.5N 본전 잠금은 너무 이르다. 대순환은 "노이즈에 흔들리지 말고 태워라"가 설계 철학인데, 1.5N에서 본전 잠그면 정상 되돌림에도 본전 스탑아웃(whipsaw) 위험. 트레일(2.5N)의 80% 지점인 2.0N이 설계 철학과 정합. (FREEZE로 어차피 보류) |

**Wilder vs SMA 보정 주(kojiro)**: Wilder(20)는 SMA(14)보다 매끄럽고 lookback이 길어, 변동성 확장 국면에서 순간 range 대비 **작은 N**을 낸다. 즉 kojiro의 1N은 donchian의 1N보다 "가격 기준 더 촘촘"할 수 있다. 이 점이 kojiro에서 1.5N을 더더욱 이르게 만들어 2.0N 권고를 보강한다.

## Q3. 기존 청산 레이어와의 상호작용

### (a) kojiro 스테이지3 청산·2ATR floor 와 승격의 우선순위 — **충돌 없음, 2ATR floor 안에 삽입**

kojiro 현재 순서: ①-8% 고정 → ②2ATR floor(tighten-only) → ③스테이지3 트레일 → ④2.5ATR 샹들리에.

승격은 **②2ATR floor 를 끌어올리는 형태**로 삽입 — `high >= buy+2N` 래치 시 `_stop_floor[ticker] = max(base, buy)`. kojiro 는 이미 `_stop_floor` 라는 tighten-only floor 인프라가 있어 **코드 결합이 가장 깨끗한 전략**이다(승격 = 기존 floor 에 `max(_, buy)` 한 줄 주입).

③스테이지3·④샹들리에는 "추세 소진/트레일" 로직이라 승자에 대해선 보통 **본전보다 위**에서 발화한다 → 승격과 실질 경합 거의 없음. 승격이 무는 경우는 "트레일이 발화하기 전에 가격이 매수가까지 급락"하는 좁은 구간뿐이고, 그게 정확히 승격이 막아야 할 시나리오다. 우선순위 재배치 불필요 — 각 레이어는 조건 충족 시 먼저 걸리는 것이 발화하는 구조 그대로 정합.

### (b) BFB measured-move(전량 익절) + 5영업일 시간청산 vs 승격 — **한계효용 낮음, 롤아웃에서 후순위/default-off 권고**

BFB 는 승격의 최약 후보다:
1. **measured-move 가 승자를 전량 청산**한다(폴폭 투영 타겟 도달 시). "승자가 다 반납"하는 병리의 승리 케이스는 이미 measured-move 가 상당 부분 처리.
2. **최대 5영업일** 보유 → 096770(장기 보유 중 +15.8%→-9% 라운드트립)류의 긴 give-back 창 자체가 구조적으로 짧다.
3. flag_low 구조손절 + -5% 하드가 하방을 이미 촘촘히 캡.

승격이 채우는 갭은 "진입 후 +1.5N 갔다가 measured-target 도달 **전에** flag_low/-5%로 되돌아오는" 좁은 구간뿐. 실재하나 narrow.

**권고**: BFB 는 승격을 넣더라도 `breakeven_promote_atr=0`(default-off)로 배포 + 관측 후 판단. 롤아웃을 BFB 로 시작하지 말 것.

### (c) VCP base_low 구조손절과 승격 — **상보적, 최적 확산 후보**

base_low 는 베이스 하단(횡보 구간 아래) 구조손절이라 보통 매수가(≈base_high 돌파점) **한참 아래**에 위치. 즉:
- base_low = "애초에 안 먹힌" 케이스(즉시 실패) 방어.
- 승격(본전 floor) = "먹혔다가 실패한" 케이스 방어 — 승격 발화 후엔 base_low 보다 **위**에서 먼저 걸린다.

두 레이어가 서로 다른 실패 모드를 커버 → **충돌 없고 순수하게 개선**. VCP 가 donchian 다음 최적 확산 후보인 이유.

## Q4. 승격 임계의 2단계화(ratchet) 검토 — **과최적화, 단일 승격 권고**

"3N 도달 → BE+1N 잠금" 같은 2단계 ratchet 은 **현 시점 과최적화**다:

1. **자유 파라미터 2개 추가**(3N 트리거 + +1N 잠금레벨)를 청산 표본이 얇은(N≈1~2) 전략에 얹는 것 = 검증 불가능한 튜닝. 일주일 증거로 결정할 사안 아님.
2. **트레일과 중복**: donchian/kojiro 의 샹들리에 트레일(`high - kN`)은 이미 **연속 ratchet** 이다 — high 가 오를 때마다 스탑이 따라 오른다. 그 위에 이산(discrete) +1N 잠금을 또 얹는 건 중복. 연속 ratchet 이 이미 도는데 이산 락은 잉여.
3. 이산 락이 유일하게 유효한 경우는 "빠른 갭이 트레일을 뛰어넘어 특정 미실현이익 마일스톤을 훼손"하는 상황인데, 2.5N/2.0N 광폭 트레일에선 marginal.

**권고**: 지금은 단일 1.5N(또는 kojiro 2.0N)→BE. Ratchet 은 **롤아웃 후 데이터가 "본전~트레일 사이 구간에서 승자가 이익을 반납"하는 패턴을 보일 때**(=트레일이 너무 느슨하다는 실증) 재검토할 후속 사이클 사안. 그 전엔 도입 금지.

## Q5. 롤아웃 순서 + donchian GO/NO-GO 신호

### 권고 순서 (프롬프트의 "VCP/BFB 선행"에서 BFB 강등)

```
0단계 (게이트): donchian P1-A 라이브에서 승격 "메커니즘" 정상 발화 확인
1단계: VCP 확산 (1.5N, live ATR + 래치)   ← 최우선, 상보적·정의유사
2단계: BFB (default-off 배포, 관측 후 on 판단)  ← 한계효용 낮음
3단계: kojiro (2.0N) — FREEZE 판정(Q1) 따라: 기본 8월 하순
```

**전체 확산을 donchian 관측에 게이트**할 것. P1-A 는 배포됐으나 라이브 실측 미관측이다. 미검증 레이어를 같은 날 3전략에 퍼뜨리면 blast radius 3배. 단, 승격은 tighten-only=안전 방향이므로 "수익성 완전 입증"까지 기다릴 필요는 없고 **"메커니즘이 올바로 발화하고 whipsaw 병리가 없음"** 확인이면 VCP로 진행 가능.

### donchian 관측 — GO / NO-GO 지표 (tester / log_analysis 에게)

**현실 주의**: 멀티데이 청산은 드물어 문자 그대로의 "D+1"에 수익성 판정은 불가능. D+1 은 **메커니즘 발화** 관측, 수익성은 여러 청산 이벤트(~2주) 필요.

**GO 신호 (메커니즘 — VCP 진행 조건)**:
1. `[donchian_breakeven_promote]` 로그가 +1.5N 도달 종목에서 발화 (트리거 작동 + high_since_buy 품질 충분 확인).
2. **whipsaw 부재**: 승격된 포지션이 정상 되돌림(트레일 허용 범위 내)에서 본전 스탑아웃 당하지 **않음**. 발화 종목의 청산 사유 분포 확인 — 본전스탑 vs 트레일/채널로 더 높은 곳에서 청산.
3. P1-A 동반 레이어(1.8N 트레일 폴백, 10일 채널 청산) 설계대로 발화.
4. high_since_buy recompute 가 온전한 값 산출(096770식 stale freeze 재발 없음).

**NO-GO / 주의 신호 (VCP 확산 보류)**:
1. 승격 직후 본전 스탑아웃 → 이후 그 종목이 상승 지속(=1.5N이 그 진입엔 너무 촘촘, whipsaw). 반복 시 **VCP 도 1.5→2.0N 상향 후 확산**.
2. high_since_buy 여전히 stale → 승격 silent 미발화(로그 부재로 확인). recompute 커버 못 하는 경로 존재 의미.
3. 승격이 기존 스탑보다 아래로 tightening(=`max()` 회귀 버그) — 발생 불가해야 하나 검증.

**관측 지표 (log_analysis_engine 일일 리포트에 추가 권고)**:
- `[donchian_breakeven_promote]` 일일 발화 건수
- 승격 발화 포지션의 청산 사유 분포(본전스탑 / 트레일 / 채널 / 시간)
- 승격 트레이드 실현손익 vs -9% backstop 반사실(counterfactual) 비교
- 승격 후 본전 스탑아웃됐는데 당일 종가는 더 높았던 종목 수 (whipsaw 지표)

## 현 코드와의 정합성

- **CLAUDE.md 안전 규칙 무저촉**: 승격은 `check_exit_signal` 내부 tighten-only 로직 → 더 이른 청산만 유발. 청산 경로는 보드 가드 무관 항상 작동(사이클 38 명문화)이라 정합. 15:20 일괄청산·NXT 좀비 차단·체결통보 구독 등 8금기 무관.
- **⚠️ 충돌 항목 — kojiro FREEZE (project 메모리 `project_kojiro_entry_review`)**: "비중 0.35 FREEZE, 재튜닝 ~8월 하순, 청산 ≥20 라운드턴까지 파라미터 동결". kojiro 승격 즉시 적용은 **이 제약과 정면 충돌**. Q1 판정 = 기본 보류(A), override 시 20-count 리셋(B). team-leader 결정 필요.
- **⚠️ 구현 정합 갭 — high_since_buy recompute**: donchian 은 `recompute_high_since_buy`(일봉 high max 로 stale 복구)를 가지나 **VCP/BFB/kojiro 는 없다**. 이들의 승격 트리거는 `high_since_buy` 의존 → 재시작·시세 stale 시 승격 silent 미발화 위험. 단, 이들의 **기존 트레일(샹들리에)도 이미 high_since_buy 의존** → 승격은 새 위험이 아니라 **기존 잠재 위험에 소비처 하나 추가**. 권고: VCP/kojiro(멀티데이) 확산 시 donchian recompute 를 **동반 이식**(BFB 는 5일 한도라 후순위). 이건 승격과 별개로도 갚아야 할 부채.
- **PARAM_RANGES 제외 의무**: `breakeven_promote_atr`(및 신설 키)는 진입/청산 정체성 상수 성격 → AI 자동튜닝 화이트리스트 **제외**(사이클 198/208/209/212 선례 답습). donchian 이 이미 제외했는지 확인 + 확산 전략도 제외.

## 반례 / 한계

1. **승격이 손해인 유일 시나리오 — 얕은 되돌림 후 재상승(whipsaw)**: +1.5N 찍고 정상 조정으로 본전 근처 왔다가(승격 스탑아웃) 다시 크게 오르는 종목. 승격이 없었으면 트레일로 태워 큰 수익 났을 것을 본전에서 끊음. **이게 승격의 유일한 실제 대가**이고 임계(k)가 낮을수록 커진다 → kojiro 2.0N 권고의 근거. donchian D+1 whipsaw 지표가 이걸 잡아야 함.
2. **표본 얇음**: 멀티데이 전략 청산 N≈1~2. 어떤 정량 결론도 잠정. 본 자문의 임계값은 실전 감각+터틀 정본 기반이며, 롤아웃 후 실측으로 재보정 전제.
3. **live ATR un-latch 병리는 래치로만 봉인**: 래치 미구현 시 VCP/kojiro 에서 승격이 풀리는 버그 발생. 래치는 선택이 아니라 **필수 구현 가드**.
4. **레짐 미반영**: 이번주 손실의 상당 부분이 "레짐 문제"(선행 자문)였다. 승격은 종목 단위 방어일 뿐 레짐 방어가 아니다 — 공포장 전체 하락엔 승격도 무력(본전 스탑아웃 연쇄). 레짐 가드(SOFT/HARD)와 별개 레이어로 병존해야지 대체재 아님.
