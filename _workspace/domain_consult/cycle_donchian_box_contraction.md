# 자문 — donchian_swing "박스 수축 보조 필터" 적정성

## 질문 요약

donchian funnel 에서 ATR 단계까지 통과한 KB금융(105560)·금호타이어(073240) 2종목이 **박스 수축 보조 필터**(사이클 23 P2-4)에서 전량 탈락(step8=2 → step9=0). 이 필터가 (1) "20일 신고가 돌파" 추세추종 정체성과 개념적으로 상충하는가, (2) 한국시장에서 12일 박스 range ≤3.2% 임계가 정당한가, (3) AI 자동튜닝(PARAM_RANGES) 대상으로 부적합한가, (4) 관찰성 step 추가가 필요한가.

## 트레이더 시각

### 1. 개념 정합성 — 이건 "돈치안"이 아니다

돈치안 채널 브레이크아웃(래리 윌리엄스/터틀 트레이딩 계열)의 정의는 명확하다:

> **N일 최고가를 상향 돌파하면 추세 시작으로 보고 진입한다.**

이 셋업의 본질은 "**변동성 확장(expansion)의 시작점을 잡는다**"이다. 신고가를 낸다는 것은:
- 최근 박스권 상단을 **뚫고 나갔다** = 방금 전까지의 박스가 **깨졌다**
- 추세로 상승 중인 종목은 구조적으로 **최근 고가-저가 폭이 넓다** (상승 자체가 range 를 만든다)

여기에 "직전 12일 박스 range ≤3.2%"를 요구하는 것은:

> "신고가를 뚫되, 뚫기 직전까지는 아주 좁게 횡보하고 있었어야 한다"

= **VCP(Volatility Contraction Pattern) / 다바스 박스 / 플랫 베이스 돌파의 정의**다. 이건 미네르비니식 수축 후 돌파이지, 돈치안 추세추종이 아니다.

**두 논리는 교집합이 존재하긴 한다** (좁은 베이스에서 신고가 돌파 = 최고의 셋업). 하지만 그 교집합은 극히 희소하고, 그걸 **필수 게이트**로 걸면 돈치안이 잡아야 할 "**추세 상승 중 눌림 없이 계속 신고가를 경신하는 강한 추세**"를 전량 탈락시킨다. 바로 KB금융·금호타이어가 그 케이스다.

### 2. KB금융·금호타이어의 박스 성격 (도메인 추론)

DB 직접 조회는 마이그레이션 제약으로 보류하나, 두 종목의 시장 성격은 명확하다:

- **KB금융(105560)**: 2025~2026 금융 대형주 강세장의 대표 종목. 밸류업 프로그램 + 금리·실적 모멘텀으로 **꾸준한 우상향 추세**. 이런 종목이 20일 신고가를 냈다는 것은 = 최근 몇 주간 계단식으로 계속 올랐다는 뜻. **직전 12일 동안에도 상승 추세가 진행 중** → 12일 (고가-저가)/평균이 3.2%를 넘는 건 거의 확정적이다. 대형주라도 추세 구간에서 12일 폭 3.2%는 매우 타이트한 조건(하루 평균 변동폭 ~0.27% 수준이어야 함).
- **금호타이어(073240)**: 실적 턴어라운드 + 테마성(타이어/차부품) 변동성이 큰 중형주. 신고가 돌파 시점의 12일 박스는 **더더욱 넓다**. 코스피 중형주가 추세로 신고가 낼 정도면 12일 range 5~10%는 흔하다.

즉 **두 종목 모두 "추세 상승 → 박스 넓음 → 3.2% 필터 상시 탈락"의 전형**이다. 이것이 우연이 아니라 **구조적 상시 0후보 유발**이라는 강력한 증거다.

### 3. 한국시장에서 12일 박스 ≤3.2%의 희소성

한국은 상·하한가 ±30%, 개별 종목 일변동 5~15%가 일상인 시장이다. "12영업일 누적 (고가-저가)/평균 ≤3.2%"를 풀어보면:

- 12일간 최고가와 최저가의 차이가 평균가의 3.2% 이내
- = 12일 내내 등락률 ±1.6% 밴드 안에 갇혀 있어야 함
- 이 정도로 잔잔한 종목은 한국시장에서 **거래대금 죽은 소외주** 이거나, **횡보 눌림 직전의 극단적 압축 상태**뿐

여기서 결정적 모순이 발생한다:
- donchian 파이프라인은 이미 앞단에서 **20일 신고가 돌파 + 60일 EMA 우상향 + 거래대금 1.5×**를 요구한다 = **추세 + 유동성** 필터
- 그런데 마지막에 **3.2% 초압축 박스** = **추세 없음 + 저변동**을 요구한다
- **앞단 필터와 뒷단 필터가 서로 반대 종목을 선호** → 교집합 = 거의 공집합

5.0%(코드 DEFAULT)라도 12일 범위로는 여전히 매우 타이트하다. 3.2%(AI가 조인 운영값)는 **사실상 donchian 을 무력화하는 kill switch** 수준이다.

### 4. VCP/BFB 와의 역할 중복

시스템에는 이미 수축 후 돌파를 전담하는 두 전략이 있다:
- **VCP**: base_depth ≤30% + pullback 점진 수축 + 거래량 수축 = 정통 수축 후 돌파
- **BFB**: 폴(+15%↑) → 플래그(조정 ≤38.2% + 거래량 수축) = 깃발형 수축 후 돌파

donchian 에 박스 수축을 얹는 순간, donchian 은 **VCP 의 열화판**이 된다 (VCP 는 25~75일 베이스 + 점진 수축이라 훨씬 정교, donchian 박스는 단순 12일 range 컷이라 조잡). **포트폴리오 전략 다양성 관점에서도 손해** — 6전략을 두는 이유는 서로 다른 시장 국면(추세/수축/모멘텀)을 각각 포착하기 위함인데, donchian 이 추세추종 슬롯을 비우고 VCP 를 어설프게 흉내내면 **국면 커버리지에 구멍**이 생긴다.

### 위험 시나리오 (제거 반대 논거 검토)

제거를 반대할 수 있는 유일한 논거는 "박스 수축 필터가 **페이크 돌파(신고가 찍고 바로 되밀림)**를 걸러준다"는 것이다. 검토하면:

- **반증 1**: donchian 의 페이크 돌파 방어는 이미 다른 장치가 담당한다 — `max_breakout_extension_pct=3.0%`(과열 추격 금지), `gap_skip_threshold=3.0%`(갭 스킵), ATR×2 Chandelier 트레일링 + -7% 하드손절(진입 후 방어), `breakout_fail_n_days=5`(약한 이탈 시간 청산). 박스 수축이 아니어도 페이크는 걸러진다.
- **반증 2**: 박스 수축 필터가 거르는 건 "페이크 돌파"가 아니라 "**진짜 강한 추세 돌파**"다. 좁은 박스에서의 돌파만 남기는 건 페이크 방어가 아니라 **셋업 종류 자체를 바꾸는 것**.
- **결론**: 페이크 방어 논거로 이 필터를 정당화할 수 없다. 페이크는 진입 후 청산 규칙(트레일링/하드손절)이 잡는 게 추세추종의 정석이다.

## 정량 권고

### (a) 필터 제거 (1순위 권고)

`donchian_swing.py:368-384` 박스 수축 필터 블록 전체 제거. ATR 통과(step8) = 최종 후보(step9)로 직결.

**근거:**
- 개념적 역방향(추세추종 ⊥ 수축요구) — 위 트레이더 시각 1~4
- 상시 0후보 유발 구조 — KB금융·금호타이어 실측이 대표 사례
- VCP/BFB 역할 중복 — 수축 후 돌파는 전담 전략이 있음
- 페이크 방어는 진입 후 청산 규칙이 담당 (제거해도 리스크 관리 무손상)

### (b) 완화 대안 (제거를 원치 않을 경우만)

만약 "고품질 셋업 우선" 성향을 일부 유지하고 싶다면, **필수 게이트가 아닌 소프트 완화**로:

- `max_box_volatility_pct`: **3.2% → 12.0%** (5.0 복원도 부족 — 12일 range 기준 최소 10% 이상이어야 추세 종목을 안 죽임)
- `box_contraction_period`: **12 → 10** (코드 DEFAULT 복원. 기간을 늘릴수록 range 커져 컷 강화 = 역효과. 짧게)
- 실질 효과: 12%면 사실상 "극단적 과변동(급등급락 톱니)만 배제"하는 안전판 수준 = 정상 추세 종목 통과

단, 이 완화안조차 **개념 모순은 잔존**한다(추세 종목에 저변동 요구). 12%는 "죽이지 않는" 값일 뿐 순기능은 미미하다. **1순위는 제거**임을 명확히 한다.

### (c) PARAM_RANGES 처리 — **제외 강력 권고**

`recommendation_engine.PARAM_RANGES` 에서 `box_contraction_period (5,30)` / `max_box_volatility_pct (1.0,15.0)` 2키 제외 + `INT_PARAMS` 에서 `box_contraction_period` 제외.

**근거 (사이클 198 flag_lookback_min 선례와 동형):**
- **AI 과적합 증거**: DEFAULT 5.0 → 운영 3.2 하향은 AI 자동튜닝이 소표본 손익 데이터에 반응해 "더 조이면 승률 올라감"으로 오판한 결과로 강하게 의심된다. 실제로는 후보를 0으로 만들어 **거래 자체를 소멸**시킨 것 — 승률이 아니라 표본 자체가 사라진 것을 AI 가 "안전"으로 해석.
- **시장 리듬 상수**: 박스 폭 임계는 손익비 튜닝 파라미터가 아니라 "어떤 셋업을 잡을 것인가"라는 **전략 정체성 상수**다. K값·손절률처럼 손익 피드백으로 최적화할 대상이 아니다. flag_lookback_min(사이클 198)과 동일 성격.
- **일방향 하향 위험**: `auto_apply_recommendations` 가 "감액만/보수적"으로 자동 적용하면 이 필터는 계속 조여지기만 한다(3.2 → 2.x → ...) = donchian 영구 무력화 편향.

**주의**: 제거를 채택하면 두 키는 코드에서 사라지므로 PARAM_RANGES/INT_PARAMS 엔트리도 함께 제거. 완화 대안을 채택하면 키는 남기되 PARAM_RANGES/INT_PARAMS 에서만 빼고 **수동 상수**로 유지.

### (d) 관찰성 funnel step — **제거 시 불필요**

현재 파이프라인 구조:
```
step7 거래대금 → step8 ATR(14)>0 → [박스 수축, step 없음] → step9 최종후보
```

- ATR>0 는 사실상 항상 통과(정상 종목은 ATR 양수) → **step8 통과 = 박스 필터 직전 = 잠재 후보 확정**. 박스 필터가 유일한 실질 게이트라서 step8→step9 격차가 곧 박스 탈락이다.
- **제거하면**: step8(ATR) 통과 = step9(최종) 로 직결. step8=최종후보수 가 되어 funnel 이 자연스럽게 명확해진다. 별도 step 추가 불필요.
- **완화 대안 채택 시에만**: 박스 필터가 여전히 종목을 거르므로, "박스 수축 통과"를 step8.5(또는 step 재번호)로 노출할 가치 있음 — 몇 종목이 박스에서 걸리는지 운영자가 봐야 튜닝 판단 가능. 이 경우 `_scan_stats["box_contraction_pass"]`(이미 존재)를 funnel step 으로 승격.

사용자 의향("제거하면 step 추가 불필요")과 정합 — **제거를 택하면 step 작업 없음**이 맞다.

## 현 코드와의 정합성

- **충돌 없음** — 제거는 `donchian_swing.py:368-384` 블록 삭제 + `_scan_stats` 의 `box_contraction_pass` 키 및 관련 카운터 정리(선택). DEFAULT_PARAMS 2키 제거, PARAM_RANGES/INT_PARAMS 2키 제거.
- **안전 규칙 무저촉** — 박스 필터는 `prepare()` 내부(매수 진입 *전* scanner/prepare 영역, 사이클 38 명문화)라서 `check_exit_signal`/청산/손절/트레일링 hot path 와 무관. 제거해도 매매 안전성 8영역 diff 0.
- **멀티데이 보유 무영향** — donchian 은 `_MULTIDAY_STRATEGIES` 멤버(`is_next_day` 항상 False). 필터 제거는 진입 후보 확대만, 보유 청산 로직 불변.
- **운영 DB 정리 필요** — 운영 `strategy_config.donchian_swing.params` 에 `box_contraction_period=12` / `max_box_volatility_pct=3.2` 가 저장돼 있으므로, 제거 후에도 DB 잔존 키가 무시되도록 코드가 `params.get(...)` 을 더 이상 참조 안 하는지 확인(제거하면 자연 무시). 완화 대안 채택 시엔 DB UPDATE 로 3.2 → 12.0 동행 갱신 권고(다음 _boot 반영).

**충돌 항목 (명시)**: 없음. 단 **DB 운영값(3.2)이 AI 튜닝으로 재조여질 수 있는 구조**가 근본 리스크 — PARAM_RANGES 제외로 차단.

## 반례 / 한계

1. **완만한 대형주 장세 국한 반례**: 초저변동 대형주(예: 통신·유틸리티)가 좁은 박스에서 신고가를 내는 경우엔 박스 필터가 "고품질 다바스 돌파"만 남기는 순기능을 낼 수 있다. 그러나 이는 (a) 매우 드문 국면이고 (b) 그 셋업은 VCP 가 더 정교하게 잡는다. 순기능 대비 상시 0후보 비용이 압도적.
2. **DB 실측 미확보**: KB금융·금호타이어의 실제 12일 박스 %는 도메인 추론이며 stock_master_daily 직접 조회로 확정 못 함. **D+1 실측 권고** — 마이그레이션 복구 후 두 종목의 12일 (고가-저가)/평균 실측치를 확인하면 "3.2% 대비 얼마나 초과했는가"로 결론을 정량 봉인 가능.
3. **완화 대안 12% 근거의 데이터 부재**: 12%는 "한국 중형주 추세 구간 12일 range 5~10% + 안전 마진"이라는 도메인 추정. 정밀값은 백테스트 스윕(3/5/8/12/15% × 후보수·손익비)으로 검증 권고. **1순위 제거를 택하면 이 검증도 불필요**.
