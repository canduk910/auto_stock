### 결함 #2 영역 영구 영속 매매 안전성 평가

**결함 #2 영역 영구 영속**: scheduler가 "트레일링 모드 진입" 메시지만 emit + LTV strategy 후성 *미동기화*.

**LTV `check_exit_signal` 영역 영구 영속 분기 영역 영구 영속**:
- **상한가 모드 + 익일 시가 갭률 ≥ `gap_up_threshold`**: 트레일링 영역 영구 영속 (`pos.high_since_buy` 추적 + `trailing_stop_rate` 임계)
- **상한가 모드 + 익일 시가 갭률 < `gap_up_threshold`**: NEXT_DAY_CLEAR (즉시 청산)
- **상한가 모드 + 익일 손절**: STOP_LOSS (`overnight_stop_loss` 임계, 갭률 무관)
- **당일 모드 (상한가 미도달)**: STOP_LOSS (`intraday_stop_loss` 임계)

**결함 #2 영역 영구 영속의 silent 결함 영역 영구 영속**:
1. scheduler가 트레일링 모드 진입 영역 영구 영속 결정 → 메시지 emit
2. LTV `check_exit_signal` 영역 영구 영속이 `_limit_up_reached` 미등록 → **당일 모드 진입** (`intraday_stop_loss=-3%` 임계 영역 영구 영속)
3. 트레일링 영역 영구 영속 분기 미발화 → -1.2% 하락 감지 못함 → **매도 silent 미발화**

**위험 등급 영역 영구 영속**: **HIGH (매도 hot path 직결 silent 결함 영역 영구 영속)**.

### VB 단순성 vs LTV 3보드 영역 영구 영속 도메인 원인

**VB의 단순성 영역 영구 영속**:
- `DEFAULT_TRADABLE_BOARDS = ("main",)` = MAIN 단독.
- 15:20 강제 청산 = 표준 영역 영구 영속.
- 익일 청산 = 비상 안전망만 (`_execute_next_day_clear` 트레일링 분기 영구 영속 의미 약함).
- **결함 #1+#2 영역 영구 영속 모두 미해당**.

**LTV의 복잡성 영역 영구 영속**:
- `DEFAULT_TRADABLE_BOARDS = ("pre_nxt", "main", "post_nxt")` = 3보드.
- 상한가 모드 + 일반 모드 분기 영역 영구 영속.
- 익일 청산 트레일링 = **주요 영역 영구 영속** (사이클 38 명세 영역 영구 영속).
- **결함 #1+#2 영역 영구 영속 모두 직접 해당**.

**도메인 원인 영역 영구 영속**: VB 단순성 → 결함 회피 영역 영구 영속. LTV 3보드 영역 영구 영속 + 상한가 모드 영역 영구 영속 도입 시 scheduler 영역 영구 영속과 strategy 영역 영구 영속 동기화 영역 영구 영속 명세 영역 영구 영속 부재 → silent 결함 영역 영구 영속.
