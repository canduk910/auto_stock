## 0. 먼저 바로잡을 전제 하나

메인 세션 메모의 「터틀이면 `position_ratio` 는 ρ축(1주 폴백)에만 작용한다」 는 **절반만 맞다.**
터틀 랏 산식 `compute_unit_qty_guarded`(`src/engine/turtle_sizing.py`)는

```
랏 = min( floor(예산 × risk_pct ÷ ATR),   ← 터틀 유닛
          잔여예산 // 가격,
          int(예산 × position_ratio) // 가격 )   ← 명목 상한 (여기서도 position_ratio 가 쓰인다)
```

이다. 그래서 **ATR/가격 < `risk_pct ÷ position_ratio`** 인 종목은 터틀 유닛이 아니라 `position_ratio` 명목 상한이 랏을 정한다.
- VCP(`risk_pct` 0.01 · `position_ratio` 0.20) 문턱 = **ATR 5.0%**. VCP 후보의 ATR14 중앙값이 **4.44%**(09-28~10-08 funnel 최종 생존 28종목)라 **18/28 종목이 명목 상한에 묶인다.** → VCP 에서는 `position_ratio` 가 랏 크기를 실제로 바꾼다.
- 고지로(`risk_pct` 0.005 · `position_ratio` 0.166) 문턱 = **ATR 3.0%**. 고지로 후보 ATR20 중앙값 **4.97%**(114종목 중 112종목이 문턱 위) → 고지로에서는 `position_ratio` 가 거의 아무것도 바꾸지 않는다.

측정 문서(result.md §3)의 「0.20→0.33 이면 랏 313,000원」 은 **비중 방식 전제의 최대치**다(문서도 「랏이 정확히 비율만큼 커지지는 않는다」 고 적었다). 손절 충격 0.38% 는 터틀 스탬프 랏 기준으로 맞고, 0.44% 는 스탬프 없는 비중 낙하 랏(−7% 손절) 기준이다 — 아래 §1.3 에서 다시 잰다.

### 1.2 실제 매수 3건으로 본 랏 (로그 `[market_unit]` + 일봉 ATR14 재계산)

| 종목 | 매수가 | ATR14 | 그때 랏을 정한 쪽 | 실제 수량 | 0.33 이었으면 |
|---|---:|---:|---|---:|---:|

### 1.3 바꾸면 무엇이 달라지나 (예산 934,946원 · 후보 28종목 · 정수 절삭 포함)

| 항목 | 지금 (5칸 · 0.20) | 3칸만 (3칸 · 0.20) | 3칸 · 0.33 |
|---|---|---|---|
| 랏 평균 (예산 대비) m=1 / m=0.75 | 14.9% / 10.2% | **같음** | 17.8% / 12.6% (**+19~24%**) |
| 동시 보유 상한 | 5 | 3 | 3 |
| 실제 보유 평균 1.2종목일 때 예산 사용 m=1 / 0.75 | 18% / 12% | **같음** | 21% / 15% |
| 칸이 다 찼을 때 예산 사용 상한 m=1 / 0.75 | 75% / 51% | 45% / 31% | 53% / 38% |
| 손절 1회 최대 (스탬프 랏) | 예산 1.8% = 16.8천원 = 순자산 0.34% | 같음 | 예산 2.0% = 18.7천원 = **순자산 0.38%** |
| 저ATR 종목(ATR<3%) 손절 1회 | 예산 1.0% | 같음 | 예산 1.65% |
| 동시 손절 최악 (스탬프 랏 전부) | 5 × 1.8% = 예산 9% = 순자산 1.7% | 3 × 1.8% = 예산 5.4% = 순자산 1.0% | 3 × 2.0% = 예산 6% = **순자산 1.13%** |
| 1주 폴백 랏 상한 (m=1 날만 열린다) | 2.5 × 0.20 × 예산 = 46.7만원 | 같음 | 2.5 × 0.33 × 예산 = **77.1만원** |

읽는 법:
- **손절 1회 최대는 `risk_pct` 가 지킨다** — 스탬프 랏의 손실은 `수량 × 손절폭 ≤ 예산 × risk_pct × 2` 라 `position_ratio` 를 올려도 2% 를 넘지 않는다. 늘어나는 것은 「원래 명목 상한에 걸려 덜 사던 저ATR 종목」 의 손실뿐이다(1.0% → 1.65%).
- **3칸만 바꾸면 랏은 1주도 안 바뀐다.** 바뀌는 것은 동시 보유 상한과 동시 손절 최악뿐이다. VCP 는 10일 중 칸 찬 날이 0, 장중 최대 보유가 3(10-07 하루)이라 **3칸만은 실전에서 거의 아무 일도 하지 않는다** — 위험 상한만 낮춘다.
- **0.33 을 같이 올려도 예산 사용은 18% → 약 21% 정도다.** VCP 의 진짜 병목은 칸도 랏도 아니고 **신호 수**(10일에 매수 3건, 평균 보유 1.2)다. 측정이 기대한 「랏 65% 증가」 는 터틀에서는 일어나지 않는다.
- 그래도 0.33 이 의미 있는 이유(트레이더 시각): VCP 의 본령은 **수축이 깊게 된 저변동 베이스**다. 지금은 바로 그 종목들이 0.20 명목 상한에 걸려 설계 리스크의 절반(예산 1.0%)만 걸린다. 0.33 은 「좋은 셋업일수록 덜 사는」 역설을 푸는 쪽이다.

### 1.4 위험 — 1주 폴백 상한이 커진다

장세가 m=1(60일선 위·상승)로 돌아오면 「터틀 0주 → 비중 낙하 0주 → 1주 폴백」 경로가 다시 열린다(지금 m=0.75 enforce 에서는 닫혀 있다 — 10-07 140860(310,000원)이 `no_fallback` 으로 걸렀다).
이 1주 랏은 **스탬프가 없어 −7% 손절**이고 상한은 ρ축 `K_ρ × position_ratio × 예산` 이다. 0.33 으로 올리면 상한이 46.7만원 → **77.1만원**(예산의 82%)으로 커져, 30만~77만원대 종목 1주를 사면 손절 1회가 최대 5.4만원(순자산 1.1%)이 된다. 지금은 3.3만원(0.66%).
→ **`max_lot_ratio_mult` 를 2.5 → 1.5 로 같이 내리면** 상한이 1.5 × 0.33 × 예산 = 46.3만원으로 **지금과 같아진다.** ρ축은 스탬프 터틀 랏·비중 낙하 랏에는 닿지 않으므로(명목 상한 0.33×예산 < 0.495×예산) 다른 행위는 바뀌지 않는다.

### 1.5 권고

사용자 의도가 측정 결정 카드 2(「정원 5→3·비율 0.20→0.33」)를 고른 것이라고 본다. 그 의도(예산을 덜 놀리기)에 맞는 최소 변경 + 부작용 봉인:

```
PUT /api/strategies/vcp_breakout/params
{"params": {"max_positions": 3, "position_ratio": 0.33, "max_lot_ratio_mult": 1.5}}
```

- **반드시 한 요청으로** 보낸다 — `validate_params` 가 병합 결과로 예산 불변식을 검사해, `position_ratio` 만 먼저 보내면 0.33 × 5 = 1.65 로 **422** 다. 0.33 × 3 = 0.99 는 통과.
- `max_lot_ratio_mult` 1.5 를 빼고 두 키만 보내도 된다. 그때 늘어나는 위험은 §1.4 의 1주 폴백 상한(m=1 날만)뿐이다.
- 되돌리기 = `{"params": {"max_positions": 5, "position_ratio": 0.2, "max_lot_ratio_mult": 2.5}}` (한 요청 · 즉시).
- 시점 = 지금(주말)~10-13 개장 전 아무 때나. `buy_paused` 중이라 반영 시점에 매수가 없다.
- 기대 효과를 정직하게 적으면: **예산 사용 18% → 약 21%**, 저ATR 셋업 랏 +40~50%, 동시 손절 최악 순자산 1.7% → 1.13%. 「예산을 많이 쓰게 된다」 는 기대라면 이 변경은 작다 — VCP 는 신호가 드문 전략이다.
- 의도가 「위험 축소」 였다면 `{"max_positions": 3}` 한 키로 충분하다(랏 불변 · 동시 손절 최악 1.7% → 1.0%).

입금 전(비교 기간) 68% 였던 것도 같은 산식으로 설명된다 — 그때는 예산이 절반이라 터틀 유닛이 0주로 떨어지는 종목이 많았고, 그 종목들이 **설계 랏 전액인 비중 낙하/1주 폴백**으로 샀다(1주 비율 52%).

### 2.3 측정 이후 이미 바뀐 것 두 가지

1. **10-07 비중 0.42 → 0.30** — 측정의 「유휴 110만원」 은 대부분 옛 예산(약 198만원) 기준이다. 지금 예산 141만원에 같은 보유 6종목이면 **사용률 68% · 유휴 약 46만원**이다. 「남는 돈을 다른 전략으로」 는 사실상 이미 했다.
2. **10-02 시장 유닛 enforce** — 장세 m=0.75 동안 새 랏은 ×0.75. 정수 계산으로 랏 평균이 예산의 **6.4%**(설계의 39%), 6칸 상한 약 38%. 후보 114종목 중 10종목은 0주라 **신호 단계에서 거른다**(10-02 014680 281,500원 실례). 장세가 m=1 로 돌아오면 52% 로 돌아간다.

### 2.4 「예산을 다 쓰게 만드는 것」 이 목표로 맞나 — 트레이더 의견

맞지 않다고 본다.
- 추세추종에서 돈을 얼마나 넣느냐는 **「한 번 틀렸을 때 얼마를 잃을 것인가」** 에서 거꾸로 나온다. 고지로는 지금 손절 1회 ≈ 예산의 0.8%(약 1.1만원 = 순자산 0.23%), 6칸 동시 손절 ≈ 예산 4.8%(순자산 1.4%)로 짜여 있다. 예산 사용률은 이 설계의 **결과**지 목표가 아니다.
- 「다 쓰게」 만드는 유일한 방법은 종목당 리스크를 키우는 것이다(`risk_pct` ↑). 그러면 ATR 5% 종목 기준 손절 1회가 1.6배가 되고, 4.5% 오픈리스크 상한이 칸보다 먼저 막는다(아래 표).
- 성과 근거가 아직 없다 — 08-01 이후 청산 21건 실현손익 **−32,530원**, 보유 6종목 10-08 종가 평가 **+34,000원**. 합쳐 0 언저리다. 기대값이 확인되지 않은 전략에 노출을 늘릴 이유가 없다.
- 계좌 차원의 「현금이 놀고 있다」 는 문제는 전략 하나의 리스크를 키워서가 아니라 **전략 간 배분**으로 푸는 것이 맞다(사용자는 10-11 「각 전략에 배정된 것」 이라며 계좌 공용화를 보류했고, 비중 이동은 10-07 에 이미 했다).

- **C** — 6칸을 다 쓰려면 오픈리스크 상한도 같이 올려야 한다. 전략 최대 오픈리스크가 예산 4.5% → 7%(순자산 1.3% → 2.0%). 고지로 후보는 중소형 추세주라 급락일 상관이 1 에 가깝다 — 상관군 캡 없이 상한만 올리는 것은 strategies/CLAUDE.md 규약(「`max_open_risk_pct` 를 올리는 것은 상관군 캡이 전제」)에 걸린다. **권하지 않는다.**

- **F** — 이미 10-07 에 0.42 → 0.30 으로 했다. 추가 이동은 이 자문 범위 밖(전략 비중은 사용자 결정 항목).

### 2.6 권고

**고지로는 바꾸지 않는다(A).** 예산 미사용은 `risk_pct` 0.5% 라는 위험 설계의 결과이고, 측정 이후 비중 0.30 으로 유휴가 110만원 → 약 46만원으로 이미 줄었다. 장세 m=0.75 동안은 사용률이 더 낮은 것이 의도다.
사용자가 그래도 노출을 늘리고 싶다면 **B(`risk_pct` 0.005 → 0.0065) 한 키**가 가장 덜 위험한 선택이다 — 단, 고지로 청산이 20건 이상 더 쌓여 기대값이 양수로 확인된 뒤가 맞다.

관찰 하나(새 처방 아님): 지금 고지로 보유 중 가장 큰 오픈리스크는 **005930 1주(약 2.3만원 = 예산 1.6%)** 다. 09-28 shadow 시절 터틀 0주 → 비중 낙하로 산 랏이다. enforce m<1 인 날엔 이런 랏이 생기지 않지만, m=1 로 돌아오면 같은 경로가 다시 열린다(1주 폴백은 K축이 `floor(2 × 예산 × 0.005 ÷ ATR) ≥ 1` 일 때만 허용 — 예산 141만원이면 ATR 14,147원 이하).

## 5. 반례 / 한계

1. **VCP 신호가 늘면 3칸이 병목이 된다** — G안(09-19)으로 후보가 1→8 로 늘었고 10-13 재개 뒤 신호가 잦아질 수 있다. 10-07 하루는 장중 3종목을 들었다. 3칸이 2주 안에 자주 차면 5칸 · 0.2 로 되돌리는 것이 맞다(되돌리기 한 줄).
2. ATR 분포는 funnel 최종 생존 종목(VCP 28 · 고지로 114, 09-28~10-08)을 일봉으로 재계산한 값이다. 실제 `_candidates` ATR 과 정의(단순/와일더)가 조금 다를 수 있다 — 매수 3건(VCP)·8건(고지로)은 로그 값과 수량이 맞았다.
3. 손절 위험 계산은 손절선에서 정확히 체결된다는 가정이다. 국내 갭은 손절선을 관통한다 — 10-08 003350 은 −9% 밴드에서 −9.2%, 10-01 035760 은 −8% 에서 −8.35% 로 끝났다.
4. 고지로 오픈리스크 추정(4.4만원)은 10-08 종가 기준으로 4선 손절을 재구성한 근사다. 실제 `_stop_floor`·당일 ATR 과 다를 수 있다.
5. 성과 표본이 작다 — 고지로 청산 21건(08-01~), VCP 청산 1건. 기대값 판단은 아직 못 한다.
