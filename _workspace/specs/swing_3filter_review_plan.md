# 검토 계획 — 재무퀀트·RS·RSI 3종 필터를 스윙군(donchian·kojiro·VCP)에 적용

- 사용자 지시(2026-09-06): "검증결과 확인 후 별로라면, 필터 3종을 돈치안·고지로·VCP 의 필터에 적용하는 방안도 검토." → **착수 조건 = RS 강세 반사실(`scratchpad/vbreview/rs_strong/`) 결과가 VB 에 대해 부정적일 때.** 결과가 긍정이면 사용자에게 먼저 보고하고 지시를 받는다.
- 이론적 근거: 상대강도·재무 퀀트는 **몇 주~몇 달 보유**를 전제로 만들어진 지표다. VB(당일 청산)·LTV(당일/익일)와는 지평이 어긋났지만, donchian(20일 신고가 스윙)·kojiro(대순환 스윙)·VCP(베이스 돌파)는 지평이 맞다. 신호가 존재한다면 여기서 나와야 한다.

## 데이터 제약(착수 전 확인)
1. **훅이 없다.** step7/8/9 관찰 훅은 VB 전용이다. 세 전략의 funnel 스냅샷에는 점수가 없으므로 **오프라인 계산**한다 — RS·RSI 는 `stock_master_daily`, F-Score/마법공식은 `stock_master_financial` + 시총.
2. ⚠️ **재무 데이터가 멈춰 있다** — `stock_master_financial` 08-12 이후 갱신 0, 347종목(자문 결정 항목 7). 퀀트 필터 검정의 표본이 이 한계 안에 있고, 결측 종목의 fail-open 처분이 결과를 좌우한다.
3. **룩어헤드**: 저장 funnel 행은 저녁 캡처다. 스윙군은 성과일이 D+1 이후라 VB 만큼 치명적이지 않지만, 풀 선택 자체가 D 활동성 조건부인 것은 동일하다 → 적격 부분집합 + D-1 재구성 풀 병기.
4. **실체결 표본**: donchian 20 매도(−20,740) · kojiro 14(−32,220) · VCP 0(체결 없음) · BFB 1(−3,400). 후보-레벨이 주 경로이고 실체결은 대조용이다. VCP 는 실체결 0 이라 후보-레벨만 가능하다.

## 검정 설계
- 성과 정의 = 후보 확정 다음 거래일(D+1) 시가 진입 가정, 보유 3·5·10·20 거래일 및 각 전략 실제 청산 규약 근사(donchian: ATR 트레일·돌파실패 N일 / kojiro: 대순환 단계 이탈 / VCP: 손절 −7%·max_hold_days). 비용 28bp 차감 병기.
- 점수 버킷 = F-Score(0-2/3-4/5-7/결측) · 마법공식 순위 4분위 · RS 4분위와 부호 · RSI 구간(<30/30-50/50-70/70-85/>85).
- 주 검정은 사전 정의 대비만(고·저 구간 차이), 격자 탐색은 "탐색" 라벨. 일별 클러스터 표준오차, 다중비교 보정 명시, 검정력(필요 거래일 수) 계산.
- 반사실: 각 필터를 실제로 걸었을 때 (i) 후보 수 감소율 (ii) 성과 개선폭 (iii) 실체결(donchian·kojiro)에 적용 시 손익 변화. **슬롯 대체 효과**(max_positions donchian 3·kojiro 6·VCP 5)를 반드시 고려 — 한 종목을 거르면 다른 후보가 그 자리를 채운다.
- 전략별 특수성: kojiro 는 이미 `sizing_mode=turtle` + 단계 필터가 있고, VCP 는 베이스·수축 조건이 이미 강한 필터다. **기존 게이트와 신규 필터의 중복도**(상관)를 먼저 재고 나서 증분 효과를 본다.
