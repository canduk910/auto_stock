## 1. 기본 원리

### 1.1 평균회귀
고무줄처럼, 평소 수준에서 멀어진 값이 다시 돌아온다는 가정이다. 매매로 옮기면 「많이 빠진 것을 사서 평균으로 돌아오면 판다」 이다. 이 연구는 롱 전용이다(D2 — 숏·헤지 없음).

### 1.2 OU(Ornstein–Uhlenbeck) 과정
고무줄을 숫자로 적는 모형이다. ⚠️ 이 보고서의 기호는 **θ = 회귀 속도, μ = 중심**이다. Leung & Li 문헌은 반대로 θ = 중심, μ = 속도로 쓴다(§7.3 의 문헌 수치는 문헌 표기 그대로다).

    dX = θ(μ − X)dt + σ dB

- θ = 당기는 힘(회귀 속도, 일 단위), μ = 중심, σ = 흔들림.
- 일봉에서는 AR(1) 회귀 `X_{s+1} = a + b·X_s + e` 로 추정한다. 변환식(코드 `ou.fit_window`):
  - θ = −ln b (코드는 `−log1p(b−1)` 로 계산해 b≈1 의 자릿수 손실을 막는다)
  - μ = a/(1−b)
  - σ = sd(e)·√(2θ / (1−b²)) (정확한 이산→연속 변환, `1−b²` 는 `−expm1(2 ln b)`)
  - σ_stat = σ/√(2θ) — 정상 상태 표준편차
  - sd(e) = √(SSR/n) (자유도 보정 없음)

### 1.3 반감기
벌어진 간격이 절반으로 줄어드는 날수 = ln2/θ. 짧을수록 빨리 돌아온다.
- 작은 표본에서 AR(1) 의 b 는 아래로 치우친다 → 반감기가 짧게 나온다. 보정판 = Kendall 근사 `b_adj = b + (1+3b)/T`(T = 창 길이 − 1).
- 코드는 두 값을 다 계산해 보고하지만, **필터와 타임스톱에는 보정 전 값**을 쓴다(§10 R12).

### 1.4 ADF 검정
「이 시계열이 고무줄에 묶여 있나, 그냥 떠도나」를 가리는 검정이다. 귀무가설 = 단위근(떠돈다). p < 0.05 면 「묶여 있다」로 본다.
- 코드 = `statsmodels adfuller(x, regression="c", autolag="AIC")` 를 numpy 로 다시 쓴 것(`ou.adf_c_aic`). 최대 시차 = ceil(12·(n/100)^0.25), AIC 로 시차 선택. p 값 = MacKinnon 근사(상수항, 변수 1개) 계수 표.
- 단위 테스트가 adfuller 와 통계량·p 값을 1e-9 안에서 대조한다(`tests/unit/replay/test_mr_ou.py`).

### 1.5 시장 잔차
종목 로그가격에서 시장 움직임 몫을 뺀 나머지다. `X_t = log P_t − β·log B_t`. 「시장 대비 얼마나 더 빠졌나」 를 재려는 것이다.
- 기준 B: 5년 보관소 구간 = KOSPI 근사 지수(전 종목 공통) · DB 1년 구간 = KOSPI 종목은 `069500`(KODEX 200), KOSDAQ 종목은 `229200`(KODEX 코스닥150).
- β 는 **로그가격 수준(level)끼리의 OLS 기울기**다(수익률 회귀가 아니다). §3.2·§10 R1.

### 1.6 z
지금 값이 중심에서 σ_stat 몇 칸 떨어졌는지. `z_t = (X_t − μ) / σ_stat`. −1.5 면 「평소 흔들림의 1.5배만큼 아래」.

### 1.7 Leung 최적 경계
Leung & Li (2015, IJTAF 18(3), arXiv:1411.5062v3)가 푼 최적 정지 문제다. 비용(c, ĉ)과 할인율 r 을 넣고 「언제 사고 언제 팔면 기대 할인 이익이 최대인가」를 푼다.
- 청산 문제 `V(x) = sup E[e^{−rτ}(X_τ − c)]` → 청산 경계 b*(팔 가격).
- 진입 문제 `J(x) = sup E[e^{−rν}(V(X_ν) − X_ν − ĉ)]` → 진입 경계 d*(살 가격). 손절 L 을 넣으면 진입 구간이 [a*, d*] 가 된다. a* = 진입 구간의 아래 끝이다(이보다 더 빠지면 손절 L 에 너무 가까워 사지 않는다). 이 연구의 L = −2(σ_stat 단위).
- 「안 사는 선택」이 항상 가능하므로 J(x) ≥ 0 이어야 한다. 이 성질이 §10.0 M3 의 판정 근거다.
- 기본해 `F(y) = ∫₀^∞ u^{a−1} e^{yu − u²/2} du`, `G(y) = F(−y)` (a = r/θ, y = 표준화 거리). 코드는 손절판(정리 5.1·5.5, 식 5.5·5.15·5.16)을 쓴다.
- 이 연구의 X 는 로그가격 잔차라 문헌의 선형 보상 `X − c` 는 **로그수익률 근사**다.

### 1.8 walk-forward
과거 창으로만 추정 → 다음 며칠에 적용 → 창을 밀어 다시 추정. 미래 정보를 안 쓰는 검증이다. 이 연구는 추가로 **앞 60% 기간에서 규칙을 고르고 뒤 40% 에서 잰다**.

### 1.9 시장 유닛과 효율비율(ER)
- 시장 유닛(`src/engine/market_unit.py::classify`, 라이브 함수를 그대로 import): 최근 80개 종가로 60일선 위/아래 × 60일선 기울기(20봉 전 대비) 4단계. 위·상승 = 1 · 위·하락 = 0.75 · 아래·상승 = 0.5 · 아래·하락 = 0. 방향 축이다.
- ER(Kaufman) = |C_t − C_{t−20}| ÷ Σ|C_i − C_{i−1}|(21개 종가). 1 에 가까우면 한 방향 추세, 0 에 가까우면 제자리 흔들림. 추세 곧음 축이다. 연구 분류용으로만 썼다.

## 3. 신호 계산 절차 (코드 실제 값)

`tools/replay/strategies/mean_reversion/signals.py::estimate_series` + `ou.py`.

1. **재추정일** = 전역 달력 인덱스 `i % 5 == 0` 인 날(`REEST_EVERY = 5`, 전 종목 같은 위상).
2. **β**(`ou.rolling_beta`, `BETA_WINDOW = 60`) = 재추정일 e 의 직전 60봉(e−60 … e−1)으로 `log P` 를 `log B` 에 회귀한 OLS 기울기. 「1봉 늦춘 창」. 가격 모드는 β = 0.
3. **추정 창** = e−59 … e (`WINDOW = 60`, 그날 종가 포함). 창 안 X = `log P − β·log B`. 창에 halt 가 있거나 X 가 유한하지 않으면 사유 `halt`.
4. **적합**(`ou.fit_window`): 길이 < 30 이면 `short` → ADF → AR(1) → 판정. 사유 우선순위 = `b_range`(0 < b < 1 아님) > `sigma`(sd ≤ 0) > `adf`(p ≥ 0.05) > `half_life`(반감기 ∉ [1, 5]) > `ok`.
5. **적용**: `ok` 면 그 (β, μ, σ_stat, θ, 반감기)를 다음 재추정일 전날까지 고정해 쓴다. 매일 `z_t = (log P_t − β·log B_t − μ) / σ_stat`. `valid_t` = 그날 적용 중인 추정이 ok.
6. **워밍업**: 창 시작 e−59 < 0 이면 `warmup`. 잔차 모드는 β 창 때문에 e < 60 도 `warmup`.
7. **대조군**(`run_mean_reversion._surrogate`, 잔차 모드만): (a) 종목 일간 로그수익률을 무작위로 섞어 다시 쌓은 가격 (b) 같은 표준편차의 정규 랜덤워크. 같은 기준 지수로 같은 절차를 돌리되, β 는 진짜 β 를 쓰지 않고 **대조군 경로에서 다시 추정**한다. 대조군 halt 는 `~isfinite(가격)` 뿐이라 30% 점프·거래량 0 halt 가 빠진다(창 423,121 vs 진짜 416,928, §10.0 M4). 시드 = 20261001 + 종목 열 번호.

## 4. 진입 조건

`execution.simulate_ticker` 4단계 + `signals.entry_z` / `entry_leung`. 판정 시점 = t 일 종가, 체결 = t+1 일 시가.

모두 만족해야 진입:
1. 보유 중이 아니다(물타기 금지).
2. t+1 이 존재하고 `valid_t`(그날 적용 중인 추정이 ok).
3. `eligible_t` — asof 유니버스면 t 일 시총 ≥ 500억(제외 종목은 항상 거짓). DB 는 항상 참.
4. 경계 조건
   - **z 규칙**: `z_t ≤ 진입 z` 이고 비용 조건 `(|진입 z| − |청산 z|)·σ_stat > 왕복비용`(로그 단위). 채택 = 진입 −1.5 / 청산 0. 비용 조건이 거른 신호 수는 따로 기록되지 않았다(비용 단계 사이 건수 차이가 2~3건뿐이라 거의 걸리지 않았다고 **추정**, §8.5).
   - **Leung 규칙**: 그날 경계 (a*, d*, b*)가 있고 `a* ≤ z_t ≤ d*`, 또는 **전날 z > d* 이고 오늘 L < z ≤ d***(이산 관측 교차 보정, L = −2). 교차 보정을 붙인 이유 = 연구 표본에서 a*·d* 가 거의 한 점(약 −1.16)으로 붙어 일봉 z 가 그 사이에 떨어질 일이 드물기 때문이다(§7.2). 경계가 없으면(솔버 실패) 진입 없음.
5. **시장 유닛**(입력 = 보관소는 KOSPI 근사 지수, DB 는 069500 — `run_mean_reversion.py:233`): `m = classify(시장 종가[: t+1])` — 신호일 t 종가까지(체결일 기준 직전 영업일 봉). m = 0 이면 진입 없음(D5). m 결측(워밍업)이면 기본 진입 없음, 변형 `mumiss` 는 진입.
6. **가격제한**: t+1 시가 ≥ t 종가 × 1.29 면 매수 불가.
7. 진입가 = t+1 **수정 시가**. 진입 때 z·반감기·σ_stat·θ·m 을 기록.

## 5. 청산 조건 (4종 + 가격 손절)

하루의 처리 순서(`simulate_ticker`):

**① 시가 — 대기 중 청산 체결.** 전날 종가에 청산 사유가 생겼으면 오늘 시가에 판다. 단 시가 ≤ 전일 종가 × 0.71 **이고** 고가 = 저가(하한가 잠김)면 다음 날로 미룬다.

**② 장중 — 가격 재난 손절(`disaster_pct`).** 손절가 = 진입가 × (1 − X/100), 기본 X = 7.
- 그날 저가 ≤ 손절가면 청산.
- 체결가 = 진입 다음 날 이후이고 시가 ≤ 손절가(갭 하락)면 **시가**, 그 밖은 **손절가 그대로**. 진입 당일에도 저가가 닿으면 손절가에 체결.
- 하한가 잠김 유예를 보지 않는다(§10 R10).

**③ 종가 — 청산 판정(`signals.manage`), 다음 날 시가 체결.** 우선순위:
1. **회귀 깨짐(`regime_break`)**: 오늘이 재추정일이고 새 추정이 ok 가 아니다(ADF·반감기·b 범위뿐 아니라 halt·β 결측 등 모든 실패 포함).
2. **재난 z(`disaster_z`)**: `z_t ≤ 진입 z − k`, 기본 k = 1.5. z 는 **그날 적용 중인 추정**으로 잰다(재추정 뒤면 새 μ·σ_stat).
3. **Leung 손절(`leung_stop`, Leung 규칙만)**: `z_t ≤ L = −2`.
4. **이익(`profit`)**: `z_t ≥ 목표` — z 규칙 = 청산 z(채택 0), Leung = 그날 경계의 b*.
5. **타임스톱(`timeout`)**: `보유일(t − 진입일, 영업일 인덱스) > ceil(진입 시점 반감기 × 2)`.

**④ 같은 날 처리.** 청산 체결일 당일 종가에 새 진입 신호를 낼 수 있다(그러면 다음 날 시가 진입). 코드의 「청산일 재진입 금지」 검사(`last_exit_day != t+1`)는 구조상 걸릴 일이 없다(§9 C10).

**⑤ 기록.** 거래 = 진입·청산 일자와 가격, gross = 청산가/진입가 − 1, 사유, 진입·청산 z, MAE(보유 중 최저가/진입가 − 1), MFE(최고가/진입가 − 1). 순수익 = gross − 왕복비용(단순 차감).

### 10.1 결론에 대한 판단
- **접기의 근거는 T1·T2 다.** T1 실패는 R1~R15·M1~M4 어느 것으로도 뒤집히기 어렵다(gross ≈ 0, 사후 최선 조합도 음수, ↑ 방향 요인 R4·R5 는 크기가 작다).
- T2 의 숫자(4.30%p·3.64%p)는 R1 때문에 해석이 달라진다 — 대조군도 부풀어 「차이」 만 남은 것이다. M4(대조군 halt 차이)는 그 비교 기준을 조금 흔들지만 방향은 모른다.
- T3 는 M1·M2 확정으로 **판정 불가**다. 통과·실패 어느 쪽으로도 쓰지 않는다.
- 다시 돌린다면 먼저 고칠 것: M1·M2(T3 재계산) → R1(수익률 β 또는 Engle–Granger 임계값, β 창을 추정 창과 분리) → M4(대조군 halt 일치) → R3(회귀 깨짐 변형) → M3(Leung 풀이 확인). 문턱은 사후에 바꾸지 않는다.

- ③ = 접기 판정을 거두고 무엇을 시험할지부터 다시 정한다.
- 답 = 「①」/「②」/「③」. 콜아웃과 같은 문구다.
