## 2. 방법 수정 (R1 · R3 · R4)

### R1 — 잔차 ADF 임계값: Engle–Granger(N=2)로 고정

- 고른 것: **잔차 모드(진짜·섞기·랜덤워크 대조군 전부)의 ADF p 값을 MacKinnon(1994/2010) 근사 상수항 N=2(공적분 2변수) 표로 계산**한다. 가격 모드는 β 를 추정하지 않으므로 N=1 그대로.
  - 계수 = statsmodels `adfvalues` 의 `c` 행 두 번째: max 0.92 · min −18.86 · star −2.62 · small (2.92, 1.5012, 0.039796) · large (2.1945, 0.64695, −0.29198, −0.042377).
- 근거: β 는 지시서 §3.3-1 이 「직전 60봉 OLS(1봉 늦춘 창)」로 정했다. 이 창은 ADF 창과 59/60 겹친다 — 「같은 표본에서 β 를 추정한 뒤 잔차를 검정한다」는 Engle–Granger 설정과 사실상 같고, 그 설정의 정당한 임계값이 N=2 표다. 다른 안(β 창을 ADF 창과 겹치지 않게 120~61봉 전으로 미루기)은 지시서의 β 정의 자체를 바꾸고 β 를 60봉 낡게 만든다. 그래서 β 정의는 두고 검정 임계값만 고친다.
- 한계(보고에 적는다): MacKinnon 표는 점근값이고 창은 60봉·AIC 시차라 작은 표본에서 여전히 다소 관대할 수 있다. 랜덤워크 대조군 통과율을 「명목 크기」의 진단으로 함께 보고한다. β 창과 ADF 창이 1봉 어긋나 있다(완전한 같은 표본이 아님).

### R3 — 회귀 깨짐을 두 갈래로 기록 (청산 규칙은 그대로)

- 회귀 깨짐 청산이 난 날의 재추정 사유 코드로 가른다.
  - **통계 탈락** = `adf` · `half_life` · `b_range` · `sigma`
  - **측정 불가** = `halt`(정지·결측·30% 점프 창) · `short`(β 결측 포함) · `adf_fail` · `warmup` · 추정은 ok 인데 그날 z 가 유한하지 않음
- 거래 기록 열 `rb_kind`(0 = 해당 없음 · 1 = 통계 탈락 · 2 = 측정 불가)로 남기고 묶음별 두 갈래 비율을 보고한다.

### R4 — Leung: 문헌 재현 (a) 먼저

- (a) 프로토콜(1차와 같음, 허용 오차를 바꾸지 않는다): 문헌 표 1 GLD–GDX + 그림 7 설명의 θ(중심)=0.5388 · μ(속도)=16.6677 · σ=0.1599 · r = r̂ = 0.05 · c = ĉ = 0.05 · L = 0.4834 로 b*_L · d*_L 을 풀어 문헌 0.5570 · 0.4978 과 **허용 오차 0.002** 로 비교한다.
- 원인 확인(실행 전 점검 — 이미 본 것):
  - **전사**: 표 1 의 값과 그림 7 설명이 같고, L = θ − 2·σ/√(2μ) = 0.5388 − 2 × 0.02769 = 0.4834 로 문헌 L 과 4자리까지 맞는다 → 전사 오류 아님.
  - **첫 근 선택**: 2,000점 격자로 부호 변화를 세면 문헌 점에서 b*_L 방정식 근 1개(0.5674) · d*_L 근 1개(0.5048) · a*_L 근 2개(0.5059, 0.5663 — 두 번째는 d* 위라 탐색 구간 밖). 연구 점(a=5e−4, c/s=0.05)도 같은 꼴 → `_bracket_root` 의 첫 근 선택은 원인이 아니다.
  - **실제 원인**: 문헌 점에서 보상 V_L(x) − x − ĉ 의 최댓값이 −0.0799 로 **어디서도 양수가 아니다**(왕복비용 0.10 > 밴드 b − L ≈ 0.084). 이 경우 정답은 「진입하지 않는다(J ≡ 0)」인데 솔버가 근을 그대로 진입 경계로 냈다 → M3 로 고친다. 문헌 그림 7 수치도 b − d = 0.0592 < c + ĉ = 0.10 이라 문헌 자체의 정의(J ≥ 0)와 맞지 않는다 — **같은 입력으로는 어떤 올바른 풀이도 0.4978/0.5570 을 낼 수 없다**. 독립 확인: r → 0 극한에서 척도 함수로 청산 가치를 직접 최대화한 b = 0.5710(우리 r = 0.05 해 0.5673 과 정합, 문헌 0.5570 과 불일치).
- 판정 규칙: (a) 를 허용 오차 안에서 통과하지 못하면 **결과 표에 「Leung(미검증)」** 으로 적고 §3.6 조건 3 = 실패. 위 원인 확인으로 (a) 통과는 사실상 불가능할 것으로 예상하지만, 실행 결과를 그대로 기록한다.
- (b) MC: 경로 10,000 · dt 0.01 · 지평 60 · 시드 20261001 · 점 4개(1차와 같은 점). 통과 = 우리 경계의 기대값이 **이웃 8개 경계와 「안 사기(0)」** 중 어느 것보다도 2 표준오차 넘게 뒤지지 않음. 문헌 점에서 M3 수정 뒤 솔버가 「진입 없음」을 내면 그 점의 우리 규칙 값 = 0 으로 본다.
