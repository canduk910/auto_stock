## 1. 낙폭 정지 DDP

1. 대상 = 성적표 strategy 그룹 매매 전략 전부: kojiro · donchian · vcp · bfb · vb · etf_trend · mr_band · mr_fkeep(8). 각 전략 단독 계좌(C7) · 씨앗 16 · 성적표와 같은 창(etf_trend 2003-01-02 ~, 나머지 1997-01-02 ~ 2026-10-02).
2. 규칙(계좌 루프 안에서 매일, 거래 단위 재시뮬레이션):
   - 기준 최고치 P = 시작 평가액에서 시작해 매일 종가 평가액 E 로 갱신(P = max(P, E)).
   - 어떤 날 t 종가에 **E_t ≤ 0.8 × P** 이면 → 다음 영업일 t+1 ~ t+30(계좌 달력의 영업일 30일) **신규 매수 금지**. 그 기간 신호는 버린다(밀어 두지 않는다). 보유 랏은 원래 청산 규칙대로 나간다(강제 청산 없음). 정지 중에는 P 를 갱신하지 않고 새 발동도 없다.
   - 재개일 = t+31. 재개일에는 매수를 허용하고 발동 검사를 하지 않는다. **재개일 종가 평가액 E_{t+31} 을 새 P 로 잡는다**(즉시 재발동 방지). 그 다음 날부터 보통 규칙.
   - 구현 = 각 전략 30년 계좌 함수의 「그날 신호 목록을 꺼내는 한 줄」 앞에 관문을 끼운다(관문 입력 = 그 루프가 이미 들고 있는 전날 종가 평가액 `eq_prev`). 신호·청산·사이저·비용·하루 순서는 그대로.
   - 대조: 관문을 끈 같은 경로의 낙관판 곡선이 성적표 `books/*.npz` 와 **원 단위로 같아야** 한다(다르면 실행을 멈추고 원인을 적는다).
3. 낙관·비관 두 판(§0). 대표 곡선 = 씨앗 16 중 최종 평가액 하위 중앙(성적표와 같다).
4. 곡선형 항목(참고 · **근사**): K200 · BL_B0(069500) · SPX · NDX · B1(60/40) · B(7자산 동일 비중) 곡선에 같은 문턱을 곡선 단위로: 종가 낙폭 ≤ −20% 인 날 종가에 전량 현금화(편도 0.19%) → 곡선 달력 30영업일 동안 원화 단기금리 → 30영업일째 종가에 재진입(편도 0.19%) · 재진입 평가액을 새 기준 최고치로. 곡선 모형 안에서의 재배분 비용·체결은 근사이고 거래 단위 시뮬레이션이 아니다.
5. 판정(전략마다, 낙관·비관 각각):
   - **(a) 효과** = DDP 판 − 원판: 연복리 차 · 최대 낙폭 차 · 구간별 연복리 차. 「도움」 = 연복리 차 > 0 **그리고** 최대 낙폭이 얕아짐(두 판 모두에서). 「해」 = 연복리 차 < 0 이고 낙폭도 얕아지지 않음. 그 밖 = 「엇갈림」.
   - **(b) 절대** = 성적표·30년 재검증과 같은 문턱: 연복리 > 0 **그리고** 최대 낙폭 ≥ −35% **그리고** 같은 창 지수 보유(BL_B0) 연복리 이상. 셋 다 = 「통과」, 아니면 「실패」. 성적표 항목의 status 칸 = (b) 의 낙관판 결과(비관판이 실패면 「실패」).
   - 보고: 발동 횟수 · 정지 영업일 합 · 정지로 버린 신호 수(씨앗 중앙).

## 2. 분기 순환 QR (8전략을 함께)

1. 구성 = 현재 시스템 전략 8개의 **단독 계좌 대표 곡선**(§1 원판, 관문 없음)의 일별 수익률:
   - kojiro · donchian · vcp · bfb · vb · etf_trend = 성적표 곡선(낙관) / §0 비관 곡선.
   - momentum · long_tail_volatility = 30년 재현이 없다. 데이터 = 실거래 왕복(`scratchpad/audit/live_trips.json`, 2026-04-29 이후 매수 · 전략 점검 단계 1 표). **근사 곡선** = 매도일에 그 왕복 순수익(0.38% 가정 차감 후) × `position_ratio`(운영 DB 추출본: momentum 0.25 · LTV 0.2) 만큼 평가액이 변한다(복리, 같은 날 여러 건은 합). 낙관 = 비관.
2. **편입 시작일** = 그 전략 곡선의 첫 날짜(kojiro·donchian·vcp·bfb·vb 1997-01-02 직전 시작점 · etf_trend 2003-01-02 · momentum·LTV 2026-04-29). 편입 시작일 뒤 **첫 분기말 리밸런싱부터** 비중을 받는다. 순위에 쓰는 직전 분기 수익은 그 분기 안의 편입 시작일부터 잰다. 편입 전에는 나머지 전략끼리 비중 규칙을 그대로 적용한다(= 재정규화).
3. 리밸런싱 = 매 분기(3·6·9·12월) 마지막 공통 거래일 **종가 뒤**. 직전 분기(직전 리밸런싱 종가 → 이번 종가) 수익률 순위 1위 = **30%**, 나머지 편입 전략 = **70% 균등**. 편입 전략이 1개면 100%. 같은 수익률이면 위 1.의 나열 순서가 앞선 쪽. 첫 분기(직전 분기 없음) = 편입 전략 균등.
4. 분기 안에서는 비중이 수익에 따라 떠다닌다(되돌림 없음). 리밸런싱 회전 비용 = 포트폴리오 평가액 × Σ|새 비중 − 떠다닌 비중| × 0.38%/2, 리밸런싱 날 차감.
5. 판:
   - **QR_TOP30** = 위 규칙(주판).
   - **QR_TOP50** = 1위 50%, 나머지 균등(민감도).
   - **QR_EQ** = 8전략 균등 분기 리밸런싱(비교 기준 1).
   - **QR_OPW** = 운영 비중 고정 분기 리밸런싱(비교 기준 2): kojiro 0.30 · donchian 0.25 · vcp 0.20 · bfb 0.20 · momentum 0.03 · etf_trend 0.02 · vb 0 · LTV 0 → Σ 로 정규화(편입 전 전략 몫은 편입된 전략끼리 재정규화).
   - 각 판 낙관·비관.
6. **근사 한계(결과에 그대로 적는다)**: 곡선 단위 재배분은 전략 계좌를 비중만큼 늘리고 줄인 것처럼 계산한다. 실제 운영에서는 비중 변경이 **신규 매수 예산에만** 영향을 주고 보유분은 그대로이며, 정수 주·슬롯·1주 랏 때문에 작은 비중의 전략은 비례로 줄어들지 않는다. 녹은 단독 계좌(평가액이 시작의 10% 미만)는 그 뒤 수익이 0 근처의 우연한 값이라 순위가 뜻이 약하다 — 1위가 녹은 계좌였던 분기 수를 보고한다.
