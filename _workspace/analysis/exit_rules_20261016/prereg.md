## 2. 측정 (모두 T 에서, V·H 는 보고)

모집단 = 전략마다 V0 m 으로 허가된 신호(m>0)를 **현행 청산**으로 1주씩 걷는 P1 모집단(종목마다 앞 거래 청산 뒤 다음 진입, 예산 무관). 진입가 E · 진입 ATR N(엔진의 `s.N`) · 시장 = 종목 소속(kq) 지수(etf 는 KOSPI).
표준오차는 **달력 월 군집**(같은 달 사건은 상관)으로 낸다. t = 평균 ÷ 군집 SE.

**M1 보유일 표** — 보유 중인 날 d(진입일 ~ 청산 전날)마다 d 종가 기준 상태:
경과 봉 n · 진입 대비 손익 u = c_d/E−1 (와 ATR 단위 (c_d−E)/N) · 고점 되돌림 g = (진입 뒤 최고 고가 − c_d)/N ·
지수 상태(60일선 위치·20봉 기울기 4상태 = 현행 시장 유닛 상태 · 지수 20일 고점 대비 낙폭 DD20 · 지수 5일 수익 · 실현변동성 백분위).
결과 **Y_hold = ln(현행 청산가 / O_{d+1})** = 「내일 시가에 팔지 않고 현행 규칙대로 계속 들고 간 값」. 큰 손실 L10 = 1[현행 청산가/O_{d+1} − 1 ≤ −10%].
Y_hold < 0 이면 그 상태에서 「내일 시가 청산」이 현행보다 낫다.

**M2 첫 닿음(손절 폭)** — 진입 뒤 고가가 E+1.5N 에 닿기 **전**(초기 손절 구간), 저가가 처음 E − z·N 에 닿은 봉 k.
체결 = min(O_k, 선)(진입 봉은 선). 결과 f(z) = ln(c_{k+H} / 체결) (규칙 무관 H봉 보유). 기준 f0 = ln(c_{ti+H}/E) 전 진입 평균. **Δ(z) = f(z) − f0**.
z 격자 {0.5, 0.75, 1.0, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0, 3.5, 4.0}. 같은 방식의 % 격자 x ∈ {2,3,4,5,6,7,8,9,10,12,15}%(선 = E×(1−x)).
H = 그 전략 T 모집단 보유 봉 수 중앙값, [5, 40] 로 자른다.

**M3 되돌림(트레일)** — 고가가 E+1.5N 에 닿은 첫 봉 a 이후, 저가가 처음 (직전 봉까지의 최고 고가 − y·N)에 닿은 봉 k.
결과 ln(c_{k+H}/체결) · 기준 fA = ln(c_{a+H}/c_a) 평균 · **Δ_T(y)** = 차. y 격자 {1.0, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0, 3.5, 4.0}.

**M4 급락 국면** — M1 의 지수 DD20 격자 θ ∈ {−3, −5, −7, −9, −11, −13, −15}% 마다 영역 R(θ) = {DD20_d ≤ θ} 의 Y_hold 평균·t·L10(4 주식 전략 합침 = 주 판정, 전략별 보고).

**M5 정체(시간)** — n 격자 {5, 10, 15, 20, 30, 40, 60} 마다 영역 {n_d ≥ n ∧ u_d ≤ 0} 의 Y_hold 평균·t.

**M6 급락장 손실 분해(질문 2)** — V0 계좌(16씨앗) 급락장 날(R4 정의 = KOSPI 20일 수익 ≤ −10% 인 날 d 마다 [d−19, d])의 묶음(연속 구간)마다,
보유 포지션 값 변화를 나눈다: 구간 시작 **전에 든** 것 / 구간 안에 든 것 × {청산됨: 시작가→청산 순간 가장 높던 청산선(선까지 = 손절·트레일 폭 몫), 그 선→실제 청산가(갭·잠김 몫)} · {구간 끝 미청산 평가손}.
「현행 장치가 막은 비율」 = 1 − (전에 든 포지션 실제 손실 ÷ 같은 포지션을 구간 끝까지 들고 있었을 때 손실). 빠른 급락 2011·2020 국면 따로.

## 3. 공통 판정 문턱

c = 0.25%(왕복 비용 수준) · 「유의」 = t ≤ −2 · 「표본 충분」 = 사건 ≥ 100 ∧ 군집 월 ≥ 12 · 「지속」 = 다음 두 격자점(표본 충분한 것)에서도 Δ ≤ 0.

## 4. 뽑는 규칙 (동결)

**D-S 손절 폭 z\*(ATR)** — M2 의 Δ(z) 에서 「Δ(z) ≤ −c ∧ 유의 ∧ 표본 충분 ∧ 지속」 인 가장 작은 z. 없으면 **현행 유지**.
**D-U 단위 판정** — 진입 ATR%(N/E) 3분위마다 z\*_s 를 같은 규칙으로. 세 z\*_s 가 모두 나오고 폭(최대−최소) ≤ 0.5 → 「ATR 단위」.
아니면 세 분위의 %환산(z\*_s × 분위 중앙 ATR%)이 모두 나오고 폭 ≤ 1.5%p → 「% 단위」. 둘 다 아니면 「단위 불명」.
- 「ATR 단위」 → D\* 손절 = 순수 z\*·N(%선 받침·하한 — kojiro `hard_stop_pct` · donchian `kk_r_floor_pct` · bfb/vcp `turtle_min_stop_pct`·`turtle_backstop_pct` · etf −9% — 을 뺀다)
- 「% 단위」 → D\* 손절 = x\*%(M2 % 곡선에 D-S 와 같은 규칙) 단독, ATR 항을 뺀다
- 「단위 불명」 → %선은 현행 그대로, ATR 배수만 z\*
- z\* 가 현행이고 단위 판정이 %선을 빼라고 하지 않으면 이 축은 「현행 유지」
- donchian 은 R = 손절 폭이 사이징(risk_pct÷R)에도 들어간다 — 운영과 같게 사이저에도 같은 값을 넣는다.

**D-T 트레일 y\*** — M3 의 Δ_T(y) 에 D-S 와 같은 규칙. 없으면 현행 유지. 적용 = kojiro `trail_atr` · bfb/vcp `atr_trail_mult` · etf trail. donchian 은 채널 청산이라 대상 아님(곡선만 보고).

**D-C 급락 시 보유분 θ\*** — M4(4전략 합침)에서 「R(θ) 의 Y_hold ≤ −c ∧ 유의 ∧ 표본 충분」 이 θ 와 그보다 깊은 모든 격자점에서 성립하는 가장 얕은 θ.
**일반성 관문(해외)**: Dset 8지수마다 σ 정규화 문턱(θ\* ÷ KOSPI T 기간 σ250 중앙 × 그 지수 σ250)에서 「DD20 ≤ 문턱인 날 다음 날 종가 → H̄봉 뒤 종가」 로그수익 평균이 무조건 평균보다 낮은 지수 ≥ 5/8(H̄ = 4 주식 전략 H 의 중앙).
둘 다 통과하면 규칙 = 「종목 소속 시장 지수 DD20(전일 종가) ≤ θ\* 로 켜진 국면에서, **국면 시작 전에 든** 포지션을 다음 시가에 청산(하한가 잠김이면 다음 날)」. 국면 끝 = DD20 > θ\*/2. 국면 안에서 든 포지션은 건드리지 않는다. 하나라도 실패 → 급락 규칙 없음.
etf 는 같은 θ\* 를 KOSPI 로 쓴다.

**D-N 정체 n\*** — M5 에서 「Y_hold ≤ −c ∧ 유의 ∧ 표본 충분」 이 n 과 그보다 긴 모든 격자점에서 성립하는 가장 짧은 n. 규칙 = 보유 n\* 봉 이상 ∧ 전일 종가 ≤ E 면 다음 시가 청산. 없으면 규칙 없음.

**D\*** = 전략마다 (D-S/D-U · D-T · D-C · D-N). 전 축이 현행 유지면 계좌 실행 없이 「데이터가 현행을 지지」.
분해(보고, 판정 아님) = 각 축만 바꾼 판 S · T · C · N.
