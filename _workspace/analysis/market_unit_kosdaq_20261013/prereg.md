# 시장 유닛 — 코스닥 포함 여부 사전 등록 (2026-10-13)

결과를 보기 전에 적는다. 동결 시각·sha256 = `prereg.sha256`. 동결 뒤 바꾼 것은 결과 파일 「사후」 절에 적는다.
동결 전에 본 것: 보관소 열 구조 · 두 ETF 의 기간(069500 2002-10-14~ · 229200 2015-10-01~) · cycle376 자문 §2 표(「종목 시장별 ½」 이 코스피 단독 ½ 보다 약했다 — ΔSh +0.14 대 +0.23, 인용·재측정 안 함) · 팀장이 준 10-13 실측(069500 m=0 · 229200 m=0.75).

## 0. 질문

시장 유닛을 「어느 지수로 재는가」 하나. 배수(1/0.75/0.5/0)·창(60·20)·대상 전략은 그대로 둔다.

방식: A 코스피200 단독(현행) · B 종목 소속 시장 · C min(둘) · D max(둘) · E 평균(둘).

## 2. 재는 것

### 2.1 판정 불일치(두 계열 모두)
4×4 교차표 · 상태 일치율 · m 일치율 · m 차이의 방향(코스닥이 강함/약함) 일수 · 불일치 구간의 수와 길이(중앙·최장) ·
핵심 두 칸 = 「코스피 0 ∧ 코스닥 > 0」 · 「코스피 > 0 ∧ 코스닥 0」 의 일수·구간 길이 · 연도별 분포.

### 2.2 방식별 매수 가능일·평균 배수
방식 A~E 각각, 코스피 종목·코스닥 종목 입장에서 m > 0 인 날 비율과 평균 m. 기간 = S-IDX 전체, S-ETF 전체, 최근 5년.

### 2.3 불일치 칸의 돌파 진입 결과(대용 모형)
운영 4전략의 판정식이 아니다. 30년 보관소 `unified/` 의 **단순 돌파 대용**이다.

- 유니버스(그날): 6자리 숫자 코드 · 끝자리 0(보통주) · 이름에 「스팩」 없음 · 시총 > 0 · 그날 전 종목 중 시총 백분위 상위 50% ∧ 20일 평균 거래대금 백분위 상위 50%. 시장 = 그날 소속(KOSDAQ GLOBAL = KOSDAQ).
- 신호(D-1 종가): 수정 종가 > 직전 20봉 수정 고가 최댓값 ∧ 수정 종가 > 60일 단순이평 ∧ 62봉 이상 ∧ 거래 있음. 신호봉 앞 62봉 안에 위반 표시(`meta/unified_jump_flags.csv`) 있으면 제외.
- 진입: D 시가(수정). 시가 ≤ 0·거래 없음이면 진입 없음. 시가 갭 ≥ +5% 면 진입 없음.
- 청산: N = 20봉 평균 TR(D-1 기준). 손절선 = 진입가 − 2N(저가가 닿으면 그 가격, 시가가 아래면 시가) · 종가 < 직전 10봉 저가 최솟값이면 다음 봉 시가 · 120봉째 종가 · 자료가 끝나면 마지막 종가.
- 종목마다 앞 거래가 끝난 뒤에만 다음 진입(겹침 없음). 1주. 시장 유닛은 걸지 않는다(모든 진입을 만들고 사후에 칸으로 나눈다).
- 비용: `meta/regime_costs.csv` 시기별 왕복(진입일 기준) 차감.
- 기간: 진입일 1997-01-02 ~ 2026-10-02(1996 = 워밍업). 창 끝에 열린 거래는 마지막 종가로 닫는다.
- 통계: 칸별 n · 평균 순수익률 · 중앙 · 승률 · 평균 R(순수익 ÷ (2N ÷ 진입가)). 구간 = 진입일 ISO 주 군집 부트스트랩 2,000회 · 씨앗 20261013 · 90%.
- 코스닥 종목은 다시 **대형**(그날 코스닥 시총 순위 ≤ 150) / **중소형**(그 밖)으로 나눈다 — 코스닥150 이 중소형을 대표하는가.

### 2.4 방식별 사후 가중
각 방식의 m 을 진입마다 곱한다. Σ(m·r) ÷ Σm(노출 1단위당 수익) · Σ(m·r) ÷ N(진입 1건당 잡은 수익) · m > 0 진입 비율.
방식 − A 의 차를 같은 주 군집 부트스트랩으로 낸다. 슬롯·예산 경쟁이 없으므로 계좌 낙폭은 재지 못한다(한계로 적는다).

## 3. 판정 기준(미리 정한다)

코스닥 종목의 진입을 칸으로 나눈다: **QQ**(둘 다 > 0) · **K0Q+**(코스피 0 ∧ 코스닥 > 0) · **K+Q0**(코스피 > 0 ∧ 코스닥 0) · **00**(둘 다 0). 주 판정 계열 = S-IDX(길다). S-ETF 는 지속성 확인.

| # | 기준 | 통과 조건 |
|---|---|---|
| C1 | 현행이 버리는 칸이 살 만한가 | 코스닥 종목 K0Q+ 평균 순수익 > 0 ∧ (K0Q+ − 00) 차의 90% 하한 > 0 |
| C2 | B 가 새로 막는 칸이 나쁜가 | 코스닥 종목 (K+Q0 − QQ) 차의 90% 상한 < 0 |
| C3 | 자기 시장 신호가 더 잘 가르는가 | 코스닥 종목에서 (m_kq>0 평균 − m_kq=0 평균) > (m_kp>0 평균 − m_kp=0 평균) ∧ 코스피 종목에서는 그 반대 |
| C4 | 지속성 | C1 의 (K0Q+ − 00) 부호가 1997~2008 · 2009~2019 · 2020~2026 중 2개 이상에서 + ∧ S-ETF(2016~) 에서도 + |
| C5 | 대표성 | 코스닥 중소형에서도 C1 부호가 + (대형에서만 + 면 「코스닥150 은 코스닥 대형에만 맞다」) |

라벨:
- C1 ∧ C2 ∧ C4 통과 → **B(소속 시장) 지지** — 섀도 병행 뒤 전환 권고.
- C1 ∧ C4 통과, C2 실패 → **D(max) 방향 지지**(코스닥이 살아 있을 때 열어 주는 것만 근거가 있다) — 섀도 병행 권고.
- C2 통과, C1 실패 → **C(min) 방향 지지**(더 조이는 쪽) — 섀도 병행 권고.
- 그 밖 → **현행 유지**. 섀도 기록은 선택 사항으로만 적는다.

보고만(판정에 안 씀): 코스피 종목의 같은 칸 표 · 2.4 방식별 가중 · 연도별 · 운영 실거래(표본 수만 세고, 20건 미만이면 판정에 쓰지 않는다고 적는다).

## 4. 한계(미리 적는다)

- 대용 모형이다. 운영 4전략의 진입식·랭킹·슬롯·시장가 체결이 아니다. cycle376 은 「대리 진입 ≠ 운영 진입」 이고 운영 54건이 반대 방향이었다고 적었다(인용).
- 코스닥 종합지수 ≠ 코스닥150. 일치율을 재서 적는다.
- 계좌 수준(낙폭·샤프·가짜 타이밍)은 이번에 다시 돌리지 않는다. cycle376 의 계좌 재현 스크립트는 스크래치와 함께 사라졌다. 「종목 시장별 ½」 수치는 그 문서 인용이다.
- 다중 비교: 방식 5개 × 계열 2개. 주 판정은 C1~C5 다섯 개로 고정한다.
