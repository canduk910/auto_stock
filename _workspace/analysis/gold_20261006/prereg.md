- 시각 정렬 = 미국 자산 관례: KRX 거래일 D 의 금 가격 = **D 보다 앞선 마지막 관측**(미래 정보 차단).
- 금 현지(달러) 일 수익 `GOLD_lret` = 가격 변화만(이자·배당 없음).
- 환노출 원화 수익 `GOLD_ret` = (1 + lret)(1 + fx) − 1, fx = `fx_usdkrw` 일 변화(기존 USD 계열과 같은 환율).
- 환헤지 `GOLD_hret` = lret + (r_kr − r_us)·dt(전일 금리 · 기존 `_hret` 관례 그대로).
- 보수(일반 금 ETF) = **연 0.45%** 근사(국내 금 ETF 총보수 0.39~0.68% 의 가운데) — 기존 `FEE` 표와 같은 방식으로 매일 차감.
- 세금(세후판 보고 전용) = 금 ETF 차익 15.4%(해외·원자재 ETF 와 같음 · 배당 없음).

## 2. 레버리지 (일일 2배 · 기존 `global_alloc_b.lev_returns` 관례)

- 금 2배 환노출 L-U = (1 + 2·lret − r_us·dt − c·dt)·(1 + fx) − 1 · 금 2배 환헤지 L-H = 2·lret − r_us·dt − c·dt + (r_kr − r_us)·dt. c = **연 0.8%**(보수 + 조달 스프레드 · 기존 기본값) · 일반 보수는 따로 빼지 않는다 · 하루 −100% 아래 없음.
- 나스닥100 2배 환노출 = 기존 `lev_returns(df, "U")["LNDX"]` 그대로(= 성적표 `OL_NDX_U` 와 같은 열).
