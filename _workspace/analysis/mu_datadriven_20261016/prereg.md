## 2. 상태 변수 (지수 봉 k 의 종가 c 로 계산 — k 종가까지 알려진 값, k+1 진입에 쓰인다)

- 위치 POS_L = ln(c_k / SMA_L(k)), L ∈ {20, 40, 60, 90, 120, 200}
- 기울기 SLP_{L,lb} = ln(SMA_L(k) / SMA_L(k−lb)), lb ∈ {5, 10, 20, 40}
- 단기 낙폭 DD_w = ln(c_k / max c[k−w+1..k]), w ∈ {10, 20, 60}
- 실현 변동성 백분위 VOLP = 20봉 일간 로그수익 표준편차 σ20(k) 의 직전 1,000봉(최소 250봉) 분포 안 백분위
- 정규화: zDD_w = DD_w / σ250(k), σ250 = 직전 250봉 일간 로그수익 표준편차(그 지수 자신의 평소 변동성). 시장마다 변동성이 달라 절대 % 문턱은 시장 간에 옮겨지지 않으므로 낙폭 문턱은 **σ250 배수**로 뽑는다

## 3. 결과 변수

- **Y_tail(k)** = 1[ min_{j=1..20} ln(c_{k+j}/c_k) ≤ q10 ], q10 = 그 지수 Dset 표본에서 같은 값(20일 경로 최저)의 10% 분위. 기저율은 정의상 10%. **위험 배수 λ = P(Y_tail | 조건) / 0.10**
- Y_ret(k) = ln(c_{k+20}/c_k) — 보고
- 전략 거래 Y_trade = 신호일 gd(진입 = gd 날)의 거래 순수익률. 상태는 그 종목 소속 시장 지수의 gd−1 봉. 4전략을 각 전략 T 평균을 빼고 합친다(탈평균) — E3 의 점검에 쓴다
- 계좌 Y_acct = off 판 계좌의 이후 20영업일 수익(씨앗 평균) — 보고

## 4. 뽑는 규칙 (동결)

**E1 정보 선별(보고)** — 변수 × 지수마다 동일 개수 20구간, 구간 중앙값과 꼬리율의 스피어만 ρ. 지수 간 부호 일치 수 보고.

**E2 기준선 길이 L\* · 기울기 간격 lb\*** — (L, lb) 24조합마다 「아래·하락」 표시 F = POS_L < 0 ∧ SLP_{L,lb} < 0.
지수마다 J = P(F | 꼬리) − P(F | 꼬리 아님)(꼬리 사건을 얼마나 잡고 헛경보는 얼마나 내는가). 8지수 J 중앙값을 medJ.
고원 = { medJ ≥ 0.9 × max medJ }. 고원 안에서 **표시 변경 연 횟수(8지수 중앙)가 가장 적은 조합**, 같으면 L 큰 쪽.

**E3 4상태 배수표** — (L\*, lb\*) 의 4상태(위·상승 / 위·하락 / 아래·상승 / 아래·하락)마다 λ_s = 8지수 위험 배수 중앙.
m_s = clip(2 − λ_s, 0, 1) 을 0.25 단위로 반올림(위험이 평소 이하면 1, 평소의 2배 이상이면 0, 그 사이 선형).
점검(덮어쓰지 않음): 상태별 탈평균 거래 손익 μ_s(T 거래 합침) — μ_s > 0 ∧ t ≥ 2 인데 m_s ≤ 0.5, 또는 μ_s < 0 ∧ t ≤ −2 인데 m_s = 1 이면 「전략 쪽 불일치」로 적는다.

**E4 경계 띠 b\*** — 기준선 L\* 근처 |POS_L\*| < b 인 날에서 RR(b) = 꼬리율(−b < POS < 0) / 꼬리율(0 ≤ POS < b)(8지수 합산).
b 격자 {0.5, 1.0, 1.5, 2.0, 3.0}%. b\* = RR(b') < 1.2 가 b' ≤ b 전부에서 성립하는 가장 큰 b(선 근처에 위험 정보가 없는 폭만큼 띠를 둔다). RR(0.5%) ≥ 1.2 면 b\* = 0(선 근처도 정보가 있다 = 띠 없음).
띠 적용 방식 = 앞 V2 와 같다(직전이 위면 c < SMA×(1−b) 일 때만 아래로, 직전이 아래면 c > SMA×(1+b) 일 때만 위로).

**E5 덮기(급락 장치) 하나 고르기** — 후보 zDD_10 · zDD_20 · zDD_60 · VOLP.
지수마다 구간 꼬리율 곡선에 꺾은선(경첩) 적합: y = a + β·max(θ − x, 0)(VOLP 는 max(x − θ, 0)), θ 는 구간 중앙값 중 양 끝 2개를 뺀 값에서 가중(구간 개수) 오차제곱합 최소, β > 0 일 때만 유효. θ = 유효한 지수들 θ_i 의 중앙값(유효 지수 < 5 면 그 후보 탈락).
덮기 표시 O = (x 가 θ 를 넘음). 증분 ΔJ_i = J(F ∨ O) − J(F). **medΔJ 가 가장 큰 후보, 단 medΔJ ≥ 0.02 ∧ ΔJ_i > 0 인 지수 ≥ 6/8 일 때만 채택**. 아니면 덮기 없음.
덮기 배수 = clip(2 − λ_O', 0, 1) 0.25 반올림, λ_O' = 「O ∧ ¬F」 날의 위험 배수(8지수 중앙). 덮기는 m 을 줄이는 쪽으로만(min).
해제: θ_off = 합산(정규화 단위) 구간 곡선에서 θ 로부터 안전 쪽으로 가며 위험 배수가 처음 ≤ 1.25 가 되는 구간 경계. 켜짐 = x 가 θ 를 넘는 날, 꺼짐 = x 가 θ_off 안쪽으로 돌아온 날.

**E6 안정성 라벨(보고)** — 시장 간: 지수별 J 최대 (L, lb) 가 고원 안에 드는 지수 수 · θ_i 의 사분위폭/|중앙| ≤ 0.5 면 「안정」. 국내 2지수만으로 뽑은 값도 따로 적는다.
걷기 전진: 경계 연도 {2004, 2008, 2012, 2016, 2020} 각각 「그 해 말까지 자료」로 E2~E5 를 다시 돌려 값의 경로를 적는다(2016·2020 은 V 를 포함하므로 **검증에 쓰지 않고 시간 안정성 보고에만** 쓴다). L\*·덮기 선택이 5개 중 4개 이상 같고 θ 가 ±25% 안이면 「시간 안정」.

결정 규칙 **D\*** = (L\*, lb\*) · 배수표(E3) · 띠 b\*(E4) · 덮기(E5). 지수별로 각자 계산, 날 D 의 m = D 보다 앞선 마지막 봉 판정(10일 묵음·판정 불가 = 1.0, 현행과 같다).
**D\* 가 V0 와 원소마다 같으면** 계좌 실행 없이 「데이터가 현행을 지지」로 판정한다.

## 6. 보유분 몫 (m 이 원리상 줄일 수 있는 상한)

- **ORC(신탁 판)** = 미래를 아는 m: 급락장 날 집합(R4 정의 = KOSPI 20일 수익 ≤ −10% 인 날 d 마다 [d−19, d] 합집합)에 두 시장 모두 m = 0, 그 밖 m = 1.
- 급락장 손실 중 m 으로 줄일 수 있는 최대 몫 = (R4_ORC − R4_off) / |R4_off|. 나머지 = 그 창 시작 전에 이미 들고 있던 포지션의 손실(어떤 m 도 못 막는 몫).
- V0·D\* 가 그 상한의 몇 %를 실제로 가져갔는지 = (R4_x − R4_off) / (R4_ORC − R4_off).
- 청산 규칙 변경은 이 연구의 권고 대상이 아니다 — 보유분 몫이 크면 「별도 결정 필요」로만 적는다.
