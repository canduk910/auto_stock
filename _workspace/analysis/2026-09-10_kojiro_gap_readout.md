## 4. 재판정 — 진짜 KRX 시가를 넣으면 판정이 뒤집히는가

판정 규칙은 `src/engine/strategies/kojiro.py::check_buy_signal` 원문에서 옮겼다(인용):

```
:868   gap_rate = (open_price - prev_close) / prev_close * 100
:871   if gap_rate >= gap_up:   → skip_up   + self._bought_today.add(ticker) (:878) = 당일 영구 스킵
:880   if gap_rate <= gap_down: → skip_down + self._bought_today.add(ticker) (:887) = 당일 영구 스킵
:891   if open_price > 0 and current_price < open_price: → collapse (창 내 재시도, 영구 아님)
       그 외 → pass = 매수 확정 + self._bought_today.add(ticker) (:905)
:158   "gap_up_skip_pct": 5.0        # 갭업 ≥5% 스킵     (DEFAULT_PARAMS, PARAM_RANGES 제외 정체성 상수)
```

### 4-a. 갭 게이트 뒤집힘 = **0건 / 4건**

오염 4건의 **진짜** 갭률은 +2.79 / +1.22 / −1.85 / −1.63 % 로, 가장 가까운 경계까지 여유가
각각 2.21%p(+5.0) · 3.78%p · 2.15%p(−4.0) · 2.37%p 였다. 관측된 최대 갭률 오차 2.52%p 와
같은 자릿수라 **"우연히 안 걸렸다" 에 가깝지 "구조적으로 안전하다" 는 아니다**(N=4).

### 4-b. 붕괴 가드 뒤집힘 = **1건 / 2건(창 안 경로 B)**

09-10 `005490`(POSCO홀딩스) 09:05:00.768 — `cur=335,500`.
- 실제: `open=340,000`(프리장) ⇒ `335,500 < 340,000` ⇒ **collapse**(그 사이클 매수 보류)
- 재판정: `open=331,500`(KRX 확정) ⇒ `335,500 ≥ 331,500` ⇒ 붕괴 아님 ⇒ 갭 게이트도 통과(−1.63%) ⇒ **pass = 매수 확정**

즉 이 행에서 오염은 **손실을 만든 방향이 아니라 매수를 놓친 방향**이다(그날 005490 종가 339,000원 =
09:05 현재가 335,500 대비 +1.04%). ⚠️ **반사실은 연쇄된다** — 그 매수가 성사됐다면 kojiro 포지션이
09:05:00.77 에 6개(=`max_positions` 라이브 값 6)로 차서 **09:05:01.94 의 `004990` 체결은 일어나지 않았다.**
단일 행 재판정으로 그날의 매매 결과를 재구성할 수 없다.
