## 3. 성과 변수

- `r` = 페어 `profit_rate`(%) — 세전·비용 전 gross.
- `r_net` = `r − 0.25`(왕복 비용 근사, 운영 회고와 같은 `cost_pct`).
- `win` = `r > 0.25`(운영 회고 손실 정의 `r <= 0.25` 의 여사건).
- `pnl` = 페어 `profit_loss`(원, gross).

## 4. 지표 (전부 S 위에서)

- **M1 (주 지표)** Spearman 순위상관 ρ(score, r). 부트스트랩 95% 신뢰구간(페어 재표집 10,000회, seed 20261011, 백분위법) + 단측 순열검정 p(H1: ρ>0, 10,000회).
- **M2** AUC(score 로 win 을 가르는 능력, Mann-Whitney). 부트스트랩 95% CI.
- **M3** 중앙값 분할 — score ≥ 중앙값 묶음 vs < 중앙값 묶음의 평균 `r_net` 차이, 승률 차이. 차이의 부트스트랩 95% CI.
- **M4** 고정 구간 기술통계 — [1,40] · [41,50] · [51,60] · [61,100] 별 건수·평균 r·중앙값 r·승률·pnl 합.
- **M5 반사실 게이트** — 임계 T ∈ {70(현 설정), 60, 55, 50, 45} 마다 「score ≥ T 만 샀다면」: 통과 건수, 통과분 pnl 합, 차단분 pnl 합, 통과분 평균 r_net. 가정 = 차단된 자금은 다른 매수로 대체되지 않는다(pnl 0). 대체 가능성은 한계로 적는다.
- **M6 층화(기술만)** — 모델별(`model`) · `prompt_version` 별 · 전략별로 M1·M4 요약. n<10 층은 수치만 쓰고 판정에 쓰지 않는다.
- **M7 검정력** — 단측 α=0.05, 검정력 80% 에서 S 크기로 잡을 수 있는 최소 ρ ≈ (1.645+0.842)/√(n−3)(Fisher z 근사). ρ=0.2 를 잡는 데 필요한 n 도 같은 식으로.
- **M8 비용·지연** — 호출 수(행 수), 성공/실패 reason 분포, `cost_usd` 합(−1 = 단가 미등록은 따로 셈), 토큰 합, `latency_ms` 중앙값·p90. 주문 지연 영향은 코드 구조로 판정(평가가 주문 경로를 기다리는가).

## 5. 판정 규칙 (Q1 — 「AI 점수에 수익 예측력이 있는가」)

순서대로 처음 맞는 것 하나:

1. **판단 불가** — |S| < 30, 또는 M1 의 95% CI 가 0 과 +0.15 를 **둘 다** 포함.
2. **역신호** — M1 95% CI 상한 < 0.
3. **의미 있음(enforce 검토 가치)** — M1 95% CI 하한 > 0 **그리고** M2 95% CI 하한 > 0.5 **그리고** M3 평균 r_net 차이의 95% CI 하한 > 0.
4. **약한 신호** — M1 95% CI 하한 > 0 이지만 3 의 나머지 조건 중 하나 이상 실패.
5. **의미 없음** — M1 95% CI 상한 < +0.15 (0 은 포함할 수 있음 — 「있어도 실익 없는 크기」).

Q2(현 설정 게이트)는 별도 판정: 「`min_score`=70 게이트를 켰다면」의 통과분 pnl 합 − 실제 pnl 합(= −차단분 pnl 합)이 **음수면 「현 설정은 해롭다」, 0 이면 「중립」, 양수면 「이롭다」**. 통과 0 건이면 「현 설정 게이트 = 전면 매수 중지와 같다」 고 함께 적는다. 이 판정은 표본 크기와 무관한 산술 사실이지만, 일반화하지 않고 「이 기간에 대해」 로만 적는다.

층별(M6) 결과는 판정을 바꾸지 않는다. 모델 교체(`gpt-5.6-luna` → `gpt-6-luna`, 10-06) 뒤 층만 따로 판정 1~5 를 한 번 더 적용해 「현 모델」 판정으로 병기한다.
