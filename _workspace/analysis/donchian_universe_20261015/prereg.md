## 체결 오차(슬리피지) 가정

비지수 종목(그날 U0 밖)에만 추가 왕복 비용: s0 = 0 · **s1 = 0.5%(판정)** · s2 = 1.0%(내성). 지수 종목은 기존 비용만.

## 판정 기준(판 X vs U0, 시장 유닛 = 종목 소속 시장 종합지수, s1)

- C1 추가 종목 품질: X\U0 신호(그날 지수 밖 종목)의 모집단 거래당 순수익 평균이 T·V 둘 다 > 0
- C2 계좌: X 계좌 연복리 중앙 − U0 계좌 연복리 중앙 > 0 이 T·V 둘 다 ∧ V 같은 씨앗 우위 ≥ 10/16
- C3 낙폭: X 계좌 낙폭 중앙 ≥ U0 낙폭 중앙 − 5%p (T·V)
- C4 내성: s2 에서도 V 계좌 차 > 0
- H: V 계좌 차와 H 계좌 차의 부호가 반대면 「보류」

라벨: C1~C4 모두 통과 ∧ H 비반전 → 확대 권고 / C1 통과 ∧ C2 실패 → 유지(섀도 관찰 선택지) / C1 실패 → 유지.
