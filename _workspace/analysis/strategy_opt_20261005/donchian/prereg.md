## 0. 현행판(기준)

전수 점검 운영 해석판 그대로: 20봉 신고가 종가 돌파 · EMA60(FIR) 상승 ∧ 종가 > EMA60 · (원본 종가×거래량) ≥ 1.5 × 직전 20봉 평균 · 지수 편입(근사) ∧ 거래대금 ≥ 200억 · 62봉 이상 · 진입일 시가 갭 < +3% ∧ 시가 ≤ 돌파선 × 1.04 · R ≥ 0.5 × 가격이면 진입 없음 · 시장 유닛 m ≤ 0 진입 없음 / 랏 × m.
청산: R = max(8% × E, 1.5 × N) · 손절 E − R · 고점 ≥ E + 3R 이면 무장(손절선 ≥ E, 직전 10봉 저가 채널 엄격 이탈) · 20봉째 고점 < E + 1R 이면 종가 · 250봉 종가.
계좌: C7 4,707,820원 단독 풀 · 운영 사이저(브랜치 `d1b91180` 클래스 그대로) · `risk_pct` 0.012 · `position_ratio` 0.15 · `max_positions` 6 · 하루 신규 3 · 씨앗 16.

진입 체결 = 신호 다음 날 **시가**(운영 = 09:05~09:30 시장가). 장중 돌파(매수 스톱)가 아니므로 규약 4의 「BFB 실측 +1.93% 체결가 보정」 은 해당하지 않는다 — 이 전략에는 적용하지 않는다(보정이 필요한 쪽은 돌파선에서 사는 전략이다).

## 3. 선택 규칙 (T 에서만)

- **단계 A·B** = 규약 2 그대로: T 모집단의 비용 0.38% 뒤 거래당 순수익(%)의 90% 하한(전수 점검 P1 과 같은 부트스트랩 — 종목×ISO 주 군집 · 2,000회 · 씨앗 20261005 · 5% 분위)이 최대인 조합. T 모집단 거래 수가 연 30건 미만(T 길이 2.99년 → 90건 미만)인 조합은 제외.
  - 강건성: T1·T2·T3 중 **2개 이상** 평균 > 0 인 조합만 고른다. 강건한 조합이 하나도 없으면 전체에서 고르고 「강건 아님」 으로 적는다.
  - 동률(하한 차 < 1e-9)이면 현행에 더 가까운 쪽(바뀐 요인 수가 적은 쪽).
  - 보고만: 같은 표에 R 배수(거래당 순 R) 90% 하한 기준 순위도 싣는다 — 계좌는 R 로 사이징하므로 % 기준과 R 기준이 갈리면 적는다(선택은 % 기준).
- **단계 C** = 거래당 수익률은 랏 크기·슬롯을 반영하지 못하므로(규약 2 의 지표로는 계좌 요인이 구별되지 않는다) **규약에서 벗어난 추가 규칙**으로 고른다: T 계좌(C7 · 0.38% · 씨앗 16) 연 복리 중앙값 최대, 조건 = 낙폭 중앙값 ≥ −35% ∧ 연 체결 ≥ 12 ∧ 자금 부족 < 50%. 동률이면 현행에 가까운 쪽.

## 4. 판정 규칙 (V 에서, 한 번)

비교 대상 = **고른 판**(A·B·C 전부 반영) vs **현행판**.

1. 전수 점검 동결본 P1~P5 를 고른 판에 그대로(P1 = V 모집단 · P2 = H 부호 · P3·P4 = V 계좌 C7 · P5 = 불리 경로).
2. 규약 3: 고른 판의 V 모집단 거래당 순수익 평균 > 현행판 ∧ 그 차이의 블록 부트스트랩 90% 하한 > 0.
   - 블록 = 진입일의 ISO 주(종목 무관, 두 판 공통 블록). 블록을 복원 추출(2,000회, 씨앗 20261005)해 매 회 (고른 판 평균 − 현행판 평균). 하한 = 5% 분위.
   - Bonferroni: 같은 방식 20,000회로 단측 α = 0.05 ÷ 119 분위(≈ 0.042%)의 하한도 보고 — 「보정 판정」 으로 같이 표기. 판정 자체는 위 90% 하한.
3. 계좌(보고 + 단계 C 판정): V 계좌 연 복리 중앙값 고른 판 > 현행판, 씨앗 16 중 같은 씨앗끼리 고른 판이 높은 씨앗 수. 단계 C 를 바꿨다면 「씨앗 12/16 이상 우위」 일 때만 단계 C 를 채택(아니면 단계 C 는 현행 유지하고 A·B 만 판정).
4. H: 고른 판 − 현행판 모집단 평균 차의 부호와 고른 판 H 평균의 부호만 본다. 차의 부호가 뒤집히면 「보류」.
5. 라벨: 규약 3 통과 ∧ P1~P5 통과 ∧ H 비반전 → **채택 권고** / 규약 3 미통과 → **현행 유지** / 규약 3 통과지만 H 반전 → **보류**.
