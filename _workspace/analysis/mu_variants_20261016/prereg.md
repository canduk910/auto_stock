## 2. 후보 (지수 봉 k 의 종가 c, SMA_L(k) = 종가 L개 평균)

기본 판정: above = c(k) > SMA_L(k), rising = SMA_L(k) > SMA_L(k−lb) (엄격 부등호) → 위·상승 1 · 위·하락 0.75 · 아래·상승 0.5 · 아래·하락 0.

| 후보 | 축 | 정의 |
|---|---|---|
| **V0** | 현행 | L=60, lb=20 |
| **V1a** | 깜빡임 | V0 의 m 이 바뀌려면 **2봉 연속** 같은 새 m 이어야 한다(아니면 직전 유효 m 유지). 내리는 쪽·올리는 쪽 대칭 |
| **V1b** | 깜빡임 | 같은 규칙, **3봉 연속** |
| **V2a** | 깜빡임 | 위/아래 판정에 **±1% 띠**: 직전이 위면 c < SMA60×0.99 일 때만 아래로, 직전이 아래면 c > SMA60×1.01 일 때만 위로(첫 판정은 띠 없음). 기울기 판정은 V0 그대로 |
| **V2b** | 깜빡임 | 같은 규칙, **±2% 띠** |
| **V3** | 급락(덮기) | 지수 20봉 고점 대비 낙폭 dd20 = c/max(c[k−19..k]) − 1. **dd20 ≤ −8% 이면 켜짐 → m=0**, **dd20 > −4% 로 회복하면 꺼짐**. 꺼져 있으면 V0 m. (지수별 각자) |
| **V4** | 급락(덮기) | 20봉 일간 로그수익 표준편차 σ20(k). 직전 1,000봉(최소 250봉, 모자라면 꺼짐)의 σ20 분포에서 **σ20(k) 의 백분위 ≥ 90% 이면 m = min(V0 m, 0.5)** |

- 빠짐 이익·비용 B·K = 각 후보 **자기** 빠짐 구간 기준(앞 재측정 정의) · 순이익 B−K

## 4. 판정 — 「채택 후보」 (계좌 묶음, V0 대비, 동결)

모든 차이는 %p(소수 비율 차 × 100). 「같은 씨앗 짝」 = 16 씨앗 중 후보가 V0 보다 좋은 씨앗 수.

- (G) **위험 악화 없음** — T 와 V **각각**: R1_후보 ≥ R1_V0 − 1.0%p **∧** R4_후보 ≥ R4_V0 − 2.0%p **∧** 연복리_후보 ≥ 연복리_V0 − 1.5%p
- (I) **의미 있는 개선** — V 에서 아래 중 하나 이상
  - (I-깜빡임) K3_후보 ≤ 0.7 × K3_V0 **∧** 씨앗 짝 ≥ 10/16(K3 이 작은 쪽)
  - (I-급락) R4_후보 ≥ R4_V0 + 3.0%p **∧** 씨앗 짝 ≥ 10/16
- 라벨: (G)∧(I) = **「채택 후보」** · (G)∧¬(I) = **「개선 없음」** · ¬(G) = **「기각(위험·수익 악화)」**
- 꼬리표: H 에서 R1·R4 둘 다 V0 보다 각각 1.0·2.0%p 넘게 나쁘면 「(H 반전)」 · 위약 타이밍 T·V 둘 다/한쪽/없음
- 신뢰: 「높음」 = 채택 후보 ∧ 같은 개선(I)이 T 에서도 성립 ∧ H 반전 없음 · 「중간」 = 채택 후보이지만 위 중 하나가 빠짐 · 「낮음」 = 그 밖
- 전략별 라벨은 같은 규칙으로 내되 보조 보고(결정 근거로 쓰지 않는다)

## 5. V6 선정 규칙 (T 결과만 사용, 동결)

- F* = {V1a, V1b, V2a, V2b} 중 **T 에서 (G) 의 T 부분을 통과**한 것 가운데 T 의 K3 가 가장 작은 것(동률 → 연복리 큰 것). 통과 0 → F* 없음
- X* = {V3, V4, V5a, V5b} 중 **T 에서 (G) 의 T 부분 중 R1·연복리 조건을 통과**한 것 가운데 T 의 R4 가 가장 좋은 것(동률 → 연복리). 통과 0 → X* 없음
- 조합: X* 가 V3·V4(덮기)면 m = 덮기(F* 처리한 V0 m) — 덮기는 확인·띠의 지연을 받지 않는다. X* 가 V5a·V5b 면 그 판정에 F* 처리를 입힌다
- F*·X* 중 하나라도 없으면 V6 은 만들지 않는다. V6 의 V·H 는 표본 밖 검증, T 는 표본 안(선정에 쓴 창)이라 T 결과는 판정 (G) 에만 쓰고 (I) 근거로 쓰지 않는다
