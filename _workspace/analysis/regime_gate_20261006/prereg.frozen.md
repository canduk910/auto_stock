### 1.2 「쉰다」

- 개별 전략: 진입 세션 라벨이 쉬는 칸이면 그 신호를 계좌에 넣지 않는다. **보유분은 원래 청산 규칙대로 나간다**(보유 중 전략을 끄면 손절이 멈추는 운영 금기를 그대로 반영). 다른 동작(사이징·슬롯·비용·시장 유닛)은 바꾸지 않는다.
- ETF 자산배분(§1.4): 쉬는 칸이면 원화 현금(단기금리) 100%.

### 1.3 집합 선택 (학습 1997-01-02 ~ 2012-12-28 에서만)

- 후보 = 6칸 중 0~5칸 조합 63개(0칸 = 쉬지 않음). 6칸 전부는 후보가 아니다.
- 자격 = 학습 창 세션 중 쉬는 날 비율 ≤ 70%.
- 점수 = 학습 창 계좌 MAR(= 연 복리 ÷ |최대 낙폭|, 비용 뒤). 씨앗이 여럿이면 **씨앗별 MAR 의 중앙값**. 낙폭 0(거래 없음)인 후보는 MAR 정의 불가 → 제외.
- 최대 점수 1개를 고른다. 동점 = 칸 수 적은 쪽 → 칸 순서(UL·UH·SL·SH·DL·DH) 사전식 앞.
- 고른 집합을 검증 2013-01-02 ~ 2020-12-30 · 보류 2021-01-04 ~ 2026-10-02 에 **그대로** 적용한다. 30년 이어 달린 곡선(1997-01-02 ~ 2026-10-02)도 낸다(성적표용 · 판정 근거 아님).

### 1.4 ETF 자산배분

- 대상 = KOSPI200 보유(B0) · 60/40(B1, KOSPI200 60 · 미국채10년 40, 월말 되돌림) · 7자산 동일 비중(B, 월말 되돌림). 모형 = `global_alloc_b`(원화 총수익 · 보수 차감 · 비용 왕복 0.38% · 결정 i → i+1 종가 집행).
- 결정일 = 기본 결정일(월말) ∪ 쉼/복귀가 바뀌는 날. 쉬는 상태면 현금 100%, 아니면 기본 비중.
- 선택 규칙은 §1.3 과 같다(세전 · 일별 MAR). 세후판은 보고만 한다.

### 1.5 판정

- 차이 = 쉬는 판 − 쉬지 않는 판. 월 수익 계열(씨앗 여럿이면 **씨앗 평균 월 수익**)로 정상 블록 부트스트랩(평균 블록 12개월 · 같은 달 짝 · 5,000회 · 시드 20261006)을 돌려 연 복리 차 · MAR 차 · 샤프 차의 90% 구간(5·95 백분위)을 낸다.
- 라벨(전략마다):
  - **「쉬는 게 낫다」** = 검증 MAR 차 90% 하한 > 0 **그리고** 보류 MAR 차 점추정 > 0
  - **「쉬면 해롭다」** = 검증 MAR 차 90% 상한 < 0
  - **「가려지지 않음」** = 그 밖
  - 고른 집합이 「없음」 이면 = **「학습에서도 쉬는 게 낫지 않았다」**(검증 비교 없음)
- 학습 창 거래가 연 12건 미만인 전략(etf_trend 예상 — 2014 년까지 적격 ETF 0~9개)은 선택 결과에 「표본 부족」 을 붙인다. 규칙은 그대로 적용한다.
- 63개 중 하나를 골랐으므로 학습 창 개선폭은 낙관 편향이다 — 학습 창 차이는 보고만 하고 판정에 쓰지 않는다.

## 2. 60/40 변형 「안정상승 레버리지」 (매개변수 선택 없음 · 30년 전체가 표본)

- 상태 = 종가 t 로 확정된 라벨이 안정상승(UL)인가. 집행 = t+1 종가.
- **V1** 평소 60/40(월말 되돌림) → 안정상승이면 KOSPI200 2배 90% + 현금 10% → 벗어나면 60/40.
- **V2** 평소 현금 100% → 안정상승이면 2배 90% + 현금 10% → 벗어나면 현금.
- **V3**(문장 그대로) 처음은 60/40 → 안정상승이면 2배 90% + 현금 10% → 벗어나면 현금 100%, 다음 안정상승까지 현금.
- 레버리지 상태 중에도 월말에 90/10 으로 되돌린다.
- 2배 모형 = `global_alloc_b.lev_returns`(K200 총수익 × 2 − 원화 3개월 금리 − 연 0.8%) 그대로. 참고판 = 같은 V1~V3 에서 S&P500 2배(지수 2배 + 환 1배, 같은 모형) 90%. 라벨은 그대로 KOSPI 계열.
- 민감도 = 「대부분」 70% · 100%(V1~V3 각각).
- 창 = 1997-01-02 ~ 2026-10-02(1996-12-30 종가 현금 출발). 비용 왕복 0.38% · 세전 · 세후판(`tax=True`).
- 비교 = KOSPI200 보유 · 60/40 · KOSPI200 2배 보유 · S&P500 2배 보유 · 원화 현금. 같은 지표.
- 표 = 지표 전부 · 시대별(5년) 연 복리·낙폭 · 장세 전환(레버리지 진입) 횟수 · 레버리지 보유 일수 비율(전체·시대별). 판정 대신 V1~V3(90%) 의 60/40 대비·KOSPI200 대비 차이 90% 구간(§1.5 와 같은 부트스트랩)을 보고한다.
