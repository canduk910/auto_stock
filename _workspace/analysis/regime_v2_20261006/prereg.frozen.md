## 2. 비교할 판 (네 개 · 사전 고정)

### (가) 현행 라벨 + 현행 해석

라벨 = `market_regime_label`(D4×V4) 그대로. 해석 = 「이름대로」 — 방향 점수 d(상승 +1 · 횡보 0 · 하락 −1), 변동 점수 v(안정 0 · 변동 1), 사다리 칸 = clip(2 + d − v, 0, 3) → 사다리 [0, 0.5, 1, 2].

| 라벨 | 안정상승 | 변동상승 | 안정횡보 | 변동횡보 | 안정하락 | 변동하락 |
|---|---|---|---|---|---|---|
| 노출 M(라벨) | **2** | 1 | 1 | 0.5 | 0.5 | 0 |
| 전략 진입 | 허용 | 허용 | 허용 | 막음 | 막음 | 막음 |

전략 진입 규칙(모든 판 공통의 번역) = **노출 ≥ 1 이면 허용**.

### (나) 한 단계 당긴 해석

순환 순서(하나로 고정): **안정상승 → 변동상승 → 변동횡보 → 변동하락 → 안정하락 → 안정횡보 → 안정상승**.

근거: (1) 조용한 상승이 과열로 변동이 커지고(안정→변동상승), (2) 고점에서 방향이 꺾이며 출렁이고(변동횡보 = 분산), (3) 무너지고(변동하락), (4) 투매가 끝나 변동은 잦아드는데 방향 기울기는 아직 아래(안정하락 — 라벨이 늦어 「하락 끝물」), (5) 바닥을 다지는 조용한 박스(안정횡보 = 매집), (6) 다시 조용한 상승. 와이코프 순환(매집 → 상승 → 분산 → 하락)에 6칸을 얹은 것이고, 사용자 예시(안정상승→변동상승→변동횡보/하락→변동하락→안정하락→안정횡보→안정상승)의 「변동횡보/하락」 을 변동횡보로 정했다(변동하락이 바로 다음 칸이므로).

해석 = 라벨이 X 면 next(X) 의 (가) 행동을 한다.

| 라벨 X | 안정상승 | 변동상승 | 안정횡보 | 변동횡보 | 안정하락 | 변동하락 |
|---|---|---|---|---|---|---|
| next(X) | 변동상승 | 변동횡보 | 안정상승 | 변동하락 | 안정횡보 | 안정하락 |
| 노출 | 1 | 0.5 | **2** | 0 | 1 | 0.5 |
| 전략 진입 | 허용 | 막음 | 허용 | 막음 | 허용 | 막음 |

보조(판정 없음): 학습 T 의 실제 라벨 전이(다른 칸으로 바뀐 순간의 「다음 칸」 최빈값)로 만든 next 표 — 라벨만 보고 정하므로 수익 정보 없음. 순환 가정이 실제 전이와 맞는지 보여 주는 설명용이다.

### (다) 장세별 행동 학습 (학습 T 에서 정하고 고정)

- 지수: 라벨 L 마다 학습 T 에서 그 상태로 「들고 있던」 세션(상태 확정 종가 t → 수익 세션 t+2)의 일 수익으로 노출 e ∈ {0, 0.5, 1, 2} 각각의 평균 로그 성장 mean(log(1 + r_e))를 재고 **가장 큰 e** 를 고른다(동점 = 작은 노출). r_e = e·K200 + (1−e)·현금(e ≤ 1) · `LK200`(e = 2), 보수 차감 · 비용 제외. 학습 세션 < 60 인 칸 = 1.
- 전략: 전략마다 라벨 L 하나씩 「L 에서만 진입 허용」 계좌를 T 에서 돌려(씨앗 16) **연 복리 중앙 > 0 이면 L 허용**. T 에서 그 칸 신호 < 30 이면 허용. (63 조합 탐색은 하지 않는다 — 장세 문 연구가 이미 했다.)

### (라) 새 판단 기준 (라벨 이름 대신 특징 문턱)

특징(모두 종가 t 기준 · 미래 정보 없음):

| 묶음 | 특징 | 문턱 |
|---|---|---|
| 추세 T1~T9 (부호) | T1 C/SMA20−1 · T2 C/SMA60−1 · T3 C/SMA120−1 · T4 C/SMA200−1 · T5 SMA20 20일 기울기 · T6 SMA60 20일 기울기 · T7 SMA120 20일 기울기 · T8 KOSDAQ 종합 C/SMA60−1(229200 대리 — 코스닥150 은 보관소에 없다) · T9 시장 폭 − 0.5 | > 0 |
| 위험 R1~R5 (2문턱씩) | R1 20일 실현변동성(연율) ≥ 16% / 20% · R2 60일 실현변동성 ≥ 16% / 20% · R3 60일 고점 대비 낙폭 ≤ −5% / −10% · R4 250일 고점 대비 낙폭 ≤ −10% / −20% · R5 시장 폭 ≤ 0.3 / 0.4 | |

- C = 판단 지수 계열 종가. 시장 폭 = 그날 `unified` 보관소에서 6자리 숫자 종목(ETF류 이름 제외 = `is_etf_like`) 중 그날 행이 있고 자기 최근 60개 행(그 종목 기준)의 `close_adj` 가 있는 종목의 `close_adj > SMA60(close_adj)` 비율.
- 후보 규칙 = 추세 1개(9) · 위험 1개(10) · 추세×위험(90) · 추세×추세(36) = **145개**(상한 300 안). 칸 = 조건 참/거짓 조합(최대 4칸). 깊이 ≤ 2 의 나무와 같다.
- 칸별 행동 = (다) 와 같은 학습 규칙(학습 T 평균 로그 성장 최대 · 칸 세션 < 60 이면 1).
- **전환 상한**: 학습 T 에서 행동(노출)이 바뀐 횟수가 연 12회를 넘는 후보는 제외.
- 고르기 = 학습 T 지수 계좌(행동 사다리 · 비용 0.38%) **MAR 최대**. 동점 = 칸 수 적은 쪽 → 위 목록 순서. 「앞으로 20·60일 수익을 가장 잘 가르는가」 는 고른 결과로 판정되도록 한다 — 갈림이 수익을 가르면 행동이 달라지고 그것이 MAR 로 드러난다. 고른 규칙과 상위 5개의 앞 20·60일 수익 칸별 평균·분리도(η²)는 설명용으로 낸다.
- 특징 결측(창 시작 전 자료 부족) = 그 조건 거짓.
- 전략 용도 = 고른 규칙의 칸마다 (다) 의 전략 규칙(「그 칸에서만 진입」 T 계좌 연 복리 중앙 > 0 이면 허용).

## 3. 판정

- 각 판 (나)(다)(라) × 용도(지수 1 · 전략 3) × **(가) 대비**.
- 지수: 검증 V 월 수익의 MAR 차 = 판 − (가), 정상 블록 부트스트랩(평균 12개월 · 5,000회 · 씨앗 20261006 · 같은 달 짝). 전략: 씨앗 평균 월 수익으로 같은 방법.
- **우위** = V 의 MAR 차 90% 하한 > 0 **그리고** H 의 MAR 차 점추정 > 0(부호 유지). V 하한 > 0 인데 H 가 음수 = 「검증만」. V 90% 구간이 0 을 품으면 = 「가려지지 않음」. V 상한 < 0 = 「(가) 가 낫다」.
- 다중 비교: 도전 판 3개 — Bonferroni(3) 하한(3.33 백분위)을 보조로 함께 적는다(판정은 90% 하한).
- 시대별 표(6시대 연 복리·낙폭·MAR), 30년 FULL 지표(성적표 `compute_metrics`), 연 전환 횟수, 쉬는 날 비율을 함께 낸다.
- 기준선(설명용): KOSPI200 보유(지수) · 쉬지 않는 판(전략).

## 4. 쉬운 말 질문 두 개의 답 규칙

1. 「한 단계 당기기가 맞나」 = (나) 의 판정. 덧붙여 설명용으로 라벨 X 뒤 20일 수익이 X 보다 next(X) 의 평균에 더 가까운지(T·V·H)를 표로 낸다.
2. 「안정상승·변동상승 에지가 처음 보는 기간에도 있나」 = 상승 두 칸 보유 세션(라벨 = D−1 기준 · 그날 K200 총수익)의 연율 − 나머지 세션 연율. 일 단위 정상 블록 부트스트랩(평균 20세션 · 5,000회). **T 와 V(라벨에게 처음 보는 1997~2020) 모두 90% 하한 > 0 이면 「있다」**, 하나라도 0 을 품으면 「가려지지 않음」, 부호가 반대면 「없다」. H 는 라벨에게 학습 자료라 참고. 안정상승 · 변동상승 각각도 같은 방법으로 낸다.
