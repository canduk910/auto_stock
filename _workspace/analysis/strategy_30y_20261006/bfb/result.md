## 권고

1. **현행 BFB — 실패.** 기본판·낙관판 모두 30년 계좌가 여섯 시대 전부 손실이다. 동결본 C4 대로 **섀도 전환**(보유 0 확인 뒤 `weight 0` + `shadow_mode true`, 보유가 있으면 먼저 `buy_paused true`)을 권한다. 섀도 6개월 재판정은 이번 30년 결과로 보면 기대가 낮다 — 바로 접기(비중 0, 코드 유지)도 선택지로 올린다. 결정은 팀장·사용자.
2. 종가 확인 진입 개조는 상대 개선(약 +1%p)이 30년에서 재현됐지만 개조판도 계좌 음(−)이다 — **BFB 를 살리는 처방이 아니다**.
3. 전략 정체성(깃발 돌파 + 짧은 보유 + 촘촘한 손절) 자체가 비용 이전 거래당 음(−)이다. 고치려면 격자 밖(셋업 자체)의 새 가설이 필요하다 — 이번 범위가 아니다.
