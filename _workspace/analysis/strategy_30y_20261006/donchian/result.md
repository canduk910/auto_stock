### 2.5 과적합 진단

- T → V 격차: 고른 판 +2.18% → +1.18%(−1.00%p) · 현행 +0.28% → +0.08%. 5년 효율화(T 에서 벌린 +5.2%p 가 V 에서 −0.4%p)보다 훨씬 덜 무너졌다 — 16년 T 가 하락장·박스장을 여러 번 품고 있어서다.
- 그러나 단계 A 는 강건 조합이 하나도 없었다(T2 2001~04 · T4 2009~12 는 모든 진입 조합이 음수). 단계 B 의 강건은 단계 A 선택(m=1 만)이 T2 를 덜어 준 덕이 크다.
- 계좌는 개선 폭이 모집단보다 작다(V 거래당 +1.11%p 인데 계좌 +2.7%p/년, 씨앗 10/16). 넓은 R 은 같은 1.2% 위험 예산에서 랏을 줄이고, 연 체결이 48 → 22건으로 반 토막 난다.

## 4. 권고

1. **10-06 21:35 배포는 그대로 둔다(이 연구로 막을 근거 아님).** 배포 결정은 5년 판정 + 사용자 결정(10-03)으로 이미 내려졌고, 30년 결과는 「규칙의 꼬리가 강한 상승장에 몰려 있다」 는 위험을 키워 보여 줄 뿐 실거래 표본(L1)이 대신할 수 없다. 다만 **비중 0.25 의 근거는 약해졌다** — 30년 T·V 계좌가 지수 보유에 6개 시대 전부 졌다. 비중 재논의는 사용자 결정 항목으로 올린다(트레이더 시각: 이 전략은 「상승장 확인 뒤에만 크게 싣는」 위성 전략이지 상시 0.25 짜리 핵심이 아니다).
2. **운영 파라미터 변경 권고 없음.** B 고른 판은 규약 3 은 넘었지만 P3(낙폭) · Bonferroni 에서 실패 — 보류. 다음에 다시 볼 후보 한 줄: 「m = 1 만 진입」(30년 주효과 가장 큼, 코드 변경 필요 — 매매 행위 변경 = 승인 + domain-consult) 과 「손절 넓게·오래 들기」(R 10% · 무장 4R · 시간 30봉 · 채널 30 — DB PUT 만으로 가능, `_KK_SPECS` 범위 확인 필요).
3. H1(채널 20)은 통과했지만 **단독으로 넣을 값이 아니다** — 거래당 +0.25%p 는 비용 변화 수준이고 계좌 개선은 V 한 창뿐이다(H 는 오히려 나빠짐). 2 번 묶음과 함께 새 사전 등록으로만.
4. 실거래 재판정 조건(5년 점검 §5 — 새 규칙 왕복 30건 또는 2027-04-30)은 그대로. 이번 결과로 L1 의 무게가 더 커졌다.
