## 0. 한 줄 요약

**KRX 에 애프터마켓(16:00~20:00 실시간 연속체결)이 새로 생기고, 기존 시간외 단일가(16:00~18:00)는
폐지된다.** 그래서 그날의 거래가 18:00 이 아니라 **20:00** 에 끝난다.

애프터마켓 거래 가능 종목: 606종목(NXT 단독) → **2,459종목**(KRX+NXT, 2026-09-09 기준).

## 1. 확정 사실 (공지 원문 근거)

### 1.1 KRX 시간표

| 구간 | 시각 | 변경 |
|---|---|---|
| 시가 단일가 | **08:20~09:00** | **확대** (종전 08:30~09:00) |
| 장전 시간외 종가 | 08:30~08:40 | 유지 |
| 정규장(연속매매) | 09:00~15:20 | 유지 |
| 종가 단일가 | 15:20~15:30 | 유지 |
| 장후 시간외 종가 | 15:30~16:00 | **유지** |
| 시간외 단일가 | ~~16:00~18:00~~ | **폐지** |
| **애프터마켓** | **16:00~20:00** | **신설 · 실시간 체결** |

> 공지 원문: "장전후 시간외 종가는 기존과 동일하게 유지됩니다."
> → **없어지는 것은 시간외 *단일가* 뿐이다. 시간외 *종가* 는 남는다.** 둘을 섞지 말 것.

### 1.2 KRX 애프터마켓 상세

| 항목 | 값 |
|---|---|
| 거래시간 | 16:00~20:00 |
| 체결방법 | **실시간 체결** (종전 시간외 단일가는 10분마다 체결) |
| 가격제한 | **전일 종가 기준 ±30%** (전일 = 전일 KRX 정규장 종가) |
| 매매유형 | **애프터 지정가 / 애프터 최유리 지정가 / 애프터 최우선 지정가** — 3종뿐 |
| 시장가 | **불가** (공지: "시장 급변동 방지를 위해 시장가 주문이 불가합니다") |
| 대상 시장 | 유가증권·코스닥. **ETF/ETN, 투자경고 종목 등 시장관리 필요 종목 제외** |
| SOR | 가능. 거래소 직접 선택도 가능 |
| 수수료·세금 | 정규장과 동일 |

### 1.3 주문 존속 규약 — KRX 와 NXT 가 반대다

- **KRX**: 정규장 마감 후 미체결 주문이 **자동 취소**된다.
  애프터마켓에서 거래하려면 **16:00 이후 새로 주문을 넣어야 한다.**
  (공지 Q&A: "아니요, 유지되지 않습니다. 정규시장 마감 후 미체결 주문은 자동 취소됩니다.")
- **NXT**: 미체결이어도 **애프터마켓까지 주문이 유지**된다.
- **SOR 주문도 주문된 시장에 따라 자동취소될 수 있다.**

## 5. 이 문서가 뒤집는 기존 판단

- **cycle280(시세 채널 전환) 자문의 CRITICAL "저녁 시세 공백"은 성립하지 않는다.**
  그 판단은 `docs/kis/` 스냅샷(= 변경 전)을 근거로 "KRX 시간외 체결은 `H0STOUP0` 별도 TR" 이라고
  읽은 결과다. 09-14 이후 그 세션은 없고 애프터 체결은 `H0STCNT0` 로 온다.
  따라서 자문이 권고한 3창(08:55~15:33 KRX / 15:37~08:50 NXT)은 방향이 반대이고,
  원안 2창(08:00~08:50 NXT / 08:55~20:00 KRX)이 맞다.
  단 그 자문의 나머지 지적(41슬롯 `tr_id` 무관 카운트, `_ticker_to_session` 단일 키,
  grace 키 불일치, 등가 비교 9곳)은 채널 전환 배관 문제라 **여전히 유효하다**.
